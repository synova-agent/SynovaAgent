## Q3: 验收 — 入口 → 交互 → 结果

**入口**：CI **独立 job `k3-gate`（`name: K3 Merge Gate`）** 的 step「K3 merge gate (D923)」（每次 push/PR 都跑，**不跳过**；push 下的真实行为见 `ci.yml` 该 job 的注释块）；
人工：`bash scripts/control-tower/k3-merge-gate.sh --base <ref> --head <ref> --pr <n>`

**处理**：取变更集 → 三类匹配（policy globs + 精确枚举 + pickaxe）→ 三路解析 D#（**可归因**）
→ 读 `task-state/<D>.json` 的 `audit.verdict`（缺失则报告正文兜底）→ 归一 → 三态

**结果**：`K3-GATE: PASS | REJECT(<理由>) | DEGRADED`；`::error`/`::warning`/`::notice` 注解

**契约（铁律 47）**：
```
@input   — [--base --head --pr] | [--dir] ; [--state-dir] [--policy] [--verbose] ; 注入缝 SYNO_K3_GREP/SYNO_K3_GIT
@output  — 判定摘要 + 三类命中清单 + 三路 D# 归因；末行 K3-GATE: PASS|REJECT(..)|DEGRADED
@exit    — 0 绿 / 1 红（三类命中且无通过级结论）/ 2 降级（fail-closed，绝不等同通过）
@degraded— 扫描器/政策/结论源不可读 → stderr degraded + ::warning + degraded-events.log
@error   — .code = K3_GATE_SCAN_UNAVAILABLE | K3_GATE_POLICY_UNREADABLE | K3_GATE_STATE_UNREADABLE
```
