# D979 — FIX-011：共享治理文件的多卡归属机制

## Q0: 定位
- 域: mac（控制塔）
- 对象: `scripts/pre-commit-check.sh` 的 D328 判定段 + 共享治理文件迁移

## Q1: 调研
- 实测 24h 内 `D328` 拦 3 次：`ci.yml`→D954、`task-state/D954.json`→D954、`派单模板.md`→D931/D943
- 后果：FIX-003 后半（CI 清单注册）被迫移出；R1–R4 两轮无法落 main
- 根因：**共享文件有历史归属 ⇒ 新卡改它即判"并行劫持"**

## Q2: 范围
- 做: 机制（一对象一文件 / 显式多卡共享声明）+ D328 判定改造 + 两侧反例 + 迁移路径
- 不做: 放宽门禁换通过；不碰 `scripts/audit/**`、`src/**`

## Q3: 验收
- 入口: 任何卡的提交
- 处理: 授权卡改共享文件 ⇒ 通过；非授权卡 ⇒ 仍拒
- 结果: 共享治理文件可被正常维护，真劫持仍被拦
