### c) 决策

## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训
- **第一性原理**：门禁的输入里出现"非作者意图的标识符"（VCS 自动生成的 SHA）时，判据必须**不依赖它**——否则同一份代码因 SHA 变化得出不同结论，门禁本身就不可复现。
- **Anthropic 工程基线**：判据要**可证伪**（改坏即红）、**判别性夹具**必须有"反例侧"（本次自纠：⑱ 未给显式提交日期时同秒提交次序不定 ⇒ 去掉 `--first-parent` 竟偶然仍绿 = 假绿）。
- **仓内教训**：铁律 0-2 接线验收（机制建成必须被真调用）；铁律 11 静默降级禁止（豁免必须显式）；D328 三态退出码（0/1/2，2=无法判定且同样阻断）；D370 全角标点必须 `${VAR}` 显式边界（本次实测踩到：`$PARSED）` → `unbound variable`）；D814（`--first-parent` 未落地）；D911 A1（并入 main 历史不得提供 D#）；D964（BUILTIN_EXEMPT 口径）；记忆库 `memory/notes/proposed/2026-09-25-d954-ci-reds-base-ref.md`（D954 推断回退）。
- **决策参考**：第一性原理（输入决定论）+ Anthropic（可证伪 + 判别夹具）+ 开源实证（git 自身对"合成 merge 提交"的定义：其主题载荷是 object name，不是业务标识；`git log --first-parent` 是标准的"只看主干侧"语义）→ 结论：**合成 merge 主题整体不参与推断 + 正则加 hex 邻接边界 + 裸 SHA 词元判无效 + `--first-parent` + merge-base 范围 + 输出面脱敏**。
