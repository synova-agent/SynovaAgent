## Q3: 验收 — 入口 → 交互 → 结果
入口：`GET /api/settings/effective`（新增 L1 路由；`src/server.ts` 挂载）+ 既有 `GET /api/config/dump?orgId=`（第二消费者）
处理：读取 `settings.yaml`（workspace/home 两层）→ 按 registry 声明的 `applies` 分类解析 → live 键现读 / restart 键返回 boot 快照 / 未声明键强制 restart 并在启动时列清单
结果：① 改 live 键 → 不重启，下一次读取即新值，且两个消费者返回**同一新值**；② 改 restart 键 → 重启前 `effective` 仍为旧值 + `pending` 可见（**无半生效**），重启后 `effective` = 新值；③ 未声明键 `declared:false` + `applies:restart`，启动日志含未声明项清单
