## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训

  修法 = 未覆盖显式可见 + 该点**不写 pass**（不是静默丢弃，也不是一刀切 exit 2）。

- **windows-compat 模式 2/3**：PYBIN 三级探测是 win 域硬要求；本卡属 mac 域但脚本被 win 复用。
- **memory/ 教训**：D370 全角变量边界；D361 家族"检查没跑 == 检查通过"（② 正是此族）。
- 参考：Anthropic「可观测性优先 / 不把未判定当通过」+ 第一性原理（未跑 ≠ 通过）+ 收敛检查
  （不扩门禁语义、不动阈值、不越写集）⇒ **结论：只做判据宽度修正 + 诚实可见化，不动通过线。**
