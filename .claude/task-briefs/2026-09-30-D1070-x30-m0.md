### c) 决策参考系
① 第一性原理：日志的价值是**可复跑证据**，不是版本库内容——证据要可读、有界、可追溯，未必要进 git。
② Anthropic 工程基线：fail-closed + 机器可验契约 + 脚本化验证 → 归档要有硬上限与索引。
③ 开源实证：GitHub 合并后端不尊重 `merge=union`（D1065 实测 #880）→ append-only 文件入 git 必然制造 dirty。
④ 收敛：三者同向 → **有界快照+轮转，git 只存机制与快照索引**。
记录格式：参考：Anthropic/DeepSeek/第一性原理 + 结论＝有界快照（不进 git 主路径）。
