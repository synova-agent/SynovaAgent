## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训

  （`src/l1/qa-router.ts` 对 `userId`/`teamId` **零读取**）⇒ **不计入收益**，不得写成安全修复。
- **DevMode 才是真缺陷（复核员 J 格实测）**：「已认证 ⇒ 0 条」只在

  合法 JWT 路径下 `jwtAuthMiddleware` 自建上下文（`auth.ts:424`）⇒ 撤包裹仍 4 行。
