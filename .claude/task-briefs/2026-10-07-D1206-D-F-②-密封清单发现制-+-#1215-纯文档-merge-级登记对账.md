## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训
- 发现制（convention-over-registration）：DSH 上游测试靠 glob 自动纳入（`*.spec.ts` 同目录、无中央登记）；
  本仓 D526 定罪形态恰是「测试存在但未登记 ⇒ 永不执行」，登记制把"新增即覆盖"变成人工义务。
- memory 教训：**棘轮只减不增**是本仓既有纪律（gate-integrity-baseline.txt 头注释）；发现制若只剩"自动纳入"而无删除棘轮，
  会退化成「不检查」——故本卡为**双棘轮**：`FACE-TOTAL` 下界（删测试须显式下调）+ `QUARANTINE-TOTAL` 上界（新增隔离须显式上调）。
- #1215 依据：K3 2026-10-07 双卡报告 B 节「CT-34 上界」——CT-34（纯文档早退豁免）保留，但在 CI 侧补 merge 级对账。
- 决策参考：Anthropic（默认执行 + 显式豁免）/ 第一性原理（登记点=汇聚点=冲突点）+ 结论：
  **面内自动、面外登记、隔离留痕、棘轮双锁**。
