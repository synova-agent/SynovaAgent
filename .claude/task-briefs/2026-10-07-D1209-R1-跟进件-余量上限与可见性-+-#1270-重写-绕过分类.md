### c) 决策
- 余量：**动态打印**（stderr，可见其在涨）+ `# SLACK-CAP=10` 上限断言（超限红 ⇒ 逼周期性显式上调 floor）；**禁止自动上调**（会让棘轮失效）。
- gatekeeper：**能区分则区分**（信号① rebase/cherry-pick/am 进行中；信号② 与 marker 提交**同 subject 同 tree** 的纯重写副本）；命中 ⇒ 记 `suspected-rewrite`（**记录保留、可 grep、可审计**）；不命中 ⇒ 维持 `detected-bypass`（**不许静默漏判**）。消费侧双计数分离（suspected 不触发硬阻断，但仍打印可见）。

## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训
- 余量无界增长 = 棘轮「下界语义」的必然副作用（floor 固定、scan 单调增）⇒ 需两个旋钮：**下限**（净删除红）+ **上限**（余量超限红）。
- 「疑似 vs 确证」分离是审计学基线：误报不入确证阈值，但**保留在台账**（可追溯），不静默丢弃。
- memory 教训：V3.9「软机制 0% 有效」——故两条都做成**物理判据**（exit 码 + 提取真代码段执行的夹具），不靠注释提醒。
