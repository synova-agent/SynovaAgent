## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训
- 棘轮（ratchet）的正确语义是「**禁止把已经收紧的门槛放松**」——惩罚**使指标恶化者**，而不是惩罚**继承既有状态的旁观者**（后者会把合并序变成瓶颈）。
- 但放宽必须配**升级载体**（否则等于取消上限）：=> deadline 型登记（`SINCE=<date>`，超期升级为红）是标准做法。
- memory 教训：V3.9「软机制 0% 有效」+ **禁自动写台账**（自动上调=削弱棘轮）。
