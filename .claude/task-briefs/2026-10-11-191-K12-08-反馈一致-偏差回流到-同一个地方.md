# C 组 · 权限内核（**不可扩展** · 第①层地基）

## ★ 本组的结构：**四层分工**（CTO 2026-10-06 裁定 · 2026-10-11 找回并在 K12 落地）

> **来源**：`~/Synova-过程档案/70-架构与记录/2026-10-07-CTO-记录-企业一致性如何落到DSH预设模式-K11结构来源与现状.md`
> **借 DSH 的三条结构原则：分离 / 可覆盖 / 可拆**（**不借它的权限模型** —— DSH 没有权限模型）
> **权限模型自建**：**权限项＝可配清单；五档仅出厂默认、不进类型**

| 层 | 干什么 | 归属（卡） | 🔴 **本层不做什么** |
|---|---|---|---|
| **预设层** | 客户选哪套岗位包（**记住选择与默认**） | **RB-03 → K12-11** | **不判权限**（只记选择） |
| **解析层** | `resolveContext(identity)` 算出**本次**权限 | **RB-02 → K12-10** | **不执行**（只算） |
| **执行层** | 各拦截点按解析结果**放行/拒绝** | **RB-01 → K12-09** ／ **RB-04 → K12-12** | **不自己判断**（只读解析层） |
| **人在环** | 高风险动作**要人点头** | **RB-05 → K12-19** | **无人应答 ⇒ 拒**（fail-closed） |

**★ 结构正确性判据（可复用检验法）**：
```
**拆掉任何一层 ⇒ 系统更安全**（不是更危险）：
  · 拆掉**预设层** ⇒ 回落出厂五档（**不变更危险**）
  · 拆掉**执行层** ⇒ 无拦截能力 ⇒ **应拒全拒**
  · 拆掉**人在环** ⇒ 高风险动作**直接拒**（不是"没人管就放行"）
⇒ 若某一层拆掉后**更危险** ⇒ 说明这层没起到"纵深"作用 ⇒ **结构不对**
```

**边界（防"做完五张卡就算完"）**：
```
· **权限层**（能不能看）    ⇒ RB-01..05，**在本组**
· **内容层**（看到什么提示词/工具/知识）⇒ **RB-06 → K12-20**（🔴 **上线闸 = 第一个客户上线前必须完成**）
```
