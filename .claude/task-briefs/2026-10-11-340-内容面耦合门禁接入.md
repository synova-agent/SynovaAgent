**⑥ 还需要做什么（本卡全部工作）**：接 pre-commit → 接 CI → 夹具接线块如实 → 补"假绿"回归护栏。

**⑦ 🔴 本卡最重要的发现（型 B 假绿）**：门禁 local 模式**末行硬编码** `新增 0`
```
· 现象：造一条真实新增违规（src → extensions 取值）⇒ 逐条清单正确列出 `CC2 NEW …:1 (值)`、
  逐行汇总也写「新增 1」，但**末行**仍打印 `CONTENT-COUPLING: OK（新增 0｜…）` 且 exit 0
  （代码：`if new_all and MODE in ("ci","strict")` ⇒ local 落穿到最后一行硬编码 0）
· 后果：接入点若按 rc 判分支 ⇒ **本地一个字都不印**（实测：pre-commit 输出零提及）⇒
  「存量只告警」的**告警面在本地也不存在**，接入形同虚设。
· 修法：local **exit 0 契约不变**（只报数不判红），但末行**如实报 `新增 N`**；接入点改按「新增数」判分支。
· 但取数必须锁**末行**：整段 grep `新增 [0-9]+ | head -1` 会抓到 **CC1 那行的「新增 0」**
  （实测踩过 ⇒ 有新增却不报，等于又一层假绿）。
```
