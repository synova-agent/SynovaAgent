# line-fork-dispatch — 线/包专线派单

> **谁用**：CTO（或 CTO 专项会话）
> **产出**：① **派单件**（落 handbook）② **开工令**（可复制，**创始人转发**）
> 🔴 **本技能的用途**：**让 CTO"盯大方向"，把"线的执行"交给专线**（**减少 CTO 上下文膨胀**）

---

## 0. 🔴 三个判断（不做这三件，后面全歪）

### 0.1 该不该派？

```
 🔴 **派**：① 机械/重复性执行（落库、搬件、批处理）
  ② 需"长上下文 + 多轮往返"（如"一揽子收口一批卡"）
  ③ 与 CTO 当前上下文**不同域**（跨线/跨面）
 ✋ **不派**：① **只有 CTO 能裁的**（判据制定/优先级/跨线冲突）
  ② **要动 CTO 红线件的**（`施工项登记.ts`）—— **要么 CTO 自做，要么明确授权代笔**
  ③ **一句话能说清的**（**别为一件小事起会话**）
```

### 0.2 派给谁？

```
 · **按"面"命名专线**（创始人口径）：**K3 面 ⇒ K3 专线** ｜ **K12 面 ⇒ K12 专线**
 · 🔴 **一个专线 = 一个"面"**（**K 块 / 目录群 / 承载包**），**不是"一个任务"**
 · **跨面的任务** ⇒ **起"一次性任务组"**（**不叫 Kx 专线**）
```

### 0.3 续用旧专线还是新开？

```
 🔴 **续用**（**同一"面"的延续**）：① 上一轮结论件**已验收** ② 新任务**复用其工具/隔离树/机制**
   ⇒ **理由**：**复用 > 重建**（**两份实现必然漂移**——**今天在 `paths` 上吃过**）
 🔴 **新开**：① 上一轮**已收口并归档** ② **方法论不同**（如"审计"vs"实现"）
  ③ **上一轮上下文已满**（**长回执 + 多轮**）**且新任务不依赖其工具**
```

## 1. 派单件模版（**落 handbook `派单件/`**）

```markdown
# 派单件 · **<任务名>**

> **派出方**：CTO ｜ **执行方**：**<Kx 专线 ｜ 一次性任务组>**
> **日期**：<YYYY-MM-DD> ｜ **依据**：CTO 裁定 <编号>
> 🔴 **基准 ref（必读，别核错分支）**：**`gitea/local-main`**（工作集成分支）
>   · **as_of**：<起草时 sha>；**开工请重锚**（`git ls-remote gitea refs/heads/local-main`）
>   · 🔴 **不要核 `main`** —— `main` 落后 `local-main` **NNN commits**，**且其 `AGENTS.md` 无 §0 小节**
> 🔴 **上游已就绪**：<逐条列 —— 前置件/前置 PR 的 sha>

## 一、这是什么（**人话，先读**）
<3–6 行：这件事是干嘛的、为什么重要、跟什么有关>

## 二、🔴 做法（**步 1..N，可照抄**）
<每步给具体命令或具体动作>

## 三、🔴 判据（**逐条可跑**）
<给命令 ＋ 期望输出；数量类必须"可复跑"；三态 0/1/2>

## 四、🔴 停止条件（**何时不许自己决定**）
<① 计划外的红 ② 未预期的冲突 ③ 要改非本件范围 ④ 要动红线件>

## 五、边界 ＋ 工具提示
<❌ 不改什么（含路径）｜ 🔴 工具坑：gh 403 走 Gitea API；中文路径须 -c core.quotepath=false>

## 六、回执（**N 项**）
<① head sha ＋ CI ② 逐项结果 ③ 原始输出 ④ 未核处 ⑤ 红线自检>

## 七、状态
<本件由 CTO 产出；上游；下游>
```

## 2. 开工令模版（**同一条回复里给，创始人直接转发**）

```
你是 **<Kx 专线 ｜ 一次性任务组>**（**独立会话**）｜ 本轮：**<任务名>**

━━━ 〇、先拉任务书 ━━━
 · Mac `git clone http://127.0.0.1:3000/synova/synova-handbook.git`
 · Win `git clone http://192.168.1.7:3000/synova/synova-handbook.git` ⇒ `git fetch origin main`
 🔴 **任务书**：`派单件/<文件名>`

━━━ 一、你是谁、边界在哪（**分叉专线专属，必读**）━━━
 · 你是 **<Kx> 专线**（**分叉会话**）⇒ **产出 = 结论件/建议**，落本仓 `批次收口/_分叉/`
 · 🔴 **你不派工、不改卡、不改门禁、不落产品仓**（**那些归主线 CTO**）—— 分叉规程 §一
 · 🔴 **结论件必须带**：「**未经主线核**」标注 ＋ **as_of 锚**（产品仓 sha ＋ handbook sha）
 · 🔴 **推荐做法**：**先给"任务指令建议"** ⇒ **主线核后由 CTO 正式派出**

━━━ 二、这是什么（人话）━━━
<同派单件 §一>

━━━ 三、要做的（**逐条**）━━━
<同派单件 §二>

━━━ 四、🔴 判据 ＋ 停止条件 ━━━
<同派单件 §三 §四>

━━━ 五、边界 ＋ 通道 ━━━
<❌ 红线；🔴 D334 / D331 通道；禁 --no-verify / --force>
🔴 🔴 **开工先 `git fetch` ＋ 核远端 `local-main`**（**今天已有两例因 base 被推进而险出事**）

━━━ 六、第一个交付（**停下等放行** —— 除纯机械件）━━━
 🔴 **先出「设计/方案骨架」** ⇒ 交 CTO 过目 ⇒ 放行后实施
 （**纯机械件可免停点，写明"本件不用停"**）

━━━ 七、回执（**N 项**）━━━
<同派单件 §六>

**（完）**
```

## 3. 🔴 K12 专线"已跑通"的模式（**参考它，别重造**）

```
【它的做法（2026-10-13 实测有效）】
 ① **CTO 出"自读件"** 落 `批次收口/_分叉/<日期>-<线名>-CTO意见.md`
    ⇒ **专线自己拉 handbook 读**（**不需要 CTO 口述**）
 ② **专线出回执** 落 `批次收口/_分叉/<日期>-<线名>-<字母>回执-<主题>.md`
    ⇒ **带"未经主线核"＋ as_of 锚**
 ③ 🔴 **它有"补充核"的自觉**：**把"未核处"自己核了**，**含"推翻主线说法"**（**那次它对了**）
 ④ 🔴 **它会把"判不了"单列，禁并进"通过"**（**极重要**）
 ⑤ **主线验收后** ⇒ **把它的结论吸收进裁定台账** ⇒ **再派"实施卡"**
【⇒ 你要复制的就这五条】
```

## 4. 🔴 边界与红线（**派单件与开工令都要写**）

```
 ❌ **不改根件 `AGENTS.md`**（**除非明确授权**）
 ❌ **不动 `docs/synova/coordination/施工项登记.ts`**（**CTO 红线**）——
    **要动 ⇒ CTO 自做，或"CTO 明确授权代笔"（书面写在派单件里）**
 ❌ **不碰 `scripts/audit/**`**（**K3 红线**）
 ❌ **不改 `ci.yml` job name** ｜ ❌ **不动 `MAX_FILES` 阈值**
 🔴 **通道**：**D334**（`git merge gitea/<branch>`，"不改 hash，bypass 不裂"）｜
   **D331**（一次性补记：`.claude/bypass.log` 追加 `<ISO> | COMMITTED | pre-commit PASS (<理由>) | HASH=<完整sha>`）
 🔴 **严禁 `--no-verify`** ｜ 🔴 **严禁 `--force`**（**只用 `--force-with-lease`**）
```

---

## 5. 🔴 验收与回写（**CTO 侧的四步**）

```
 ① **读一手**（**不只看回执**）—— 拉仓 + 核关键判据（**给命令**）
 ② **逐项核**（**含"它没说的"）**
 ③ 🔴 **它指出的错要认**（**今天三次：机制不成立 / #505 真相 / 承载包口径**）
 ④ **落裁定台账** ⇒ **并更新 `CTO-当前态势.md`**
```

---

## 6. 🔴 防"上下文膨胀"的三条机制（**本技能存在的理由**）

```
 ① **CTO 不进 PR 流程**：rebase/冲突/推送/合并/卡内细节 —— **全归专线**
 ② 🔴 **"自读件"替代"口述"**：CTO 把意见**写成件**，专线**自己读**
   ⇒ **CTO 的上下文不因"解释"而膨胀**
 ③ 🔴 **"记账"只记指针**：裁定台账里写 **`件路径 ＋ sha ＋ 一句话结论`**
   ⇒ **不写复述**（**复述 = 上下文债**）
```

---

## 7. 自查（**交付派单件前逐条**）

```
 [ ] 派单件已落 handbook `派单件/`（**不是对话区**）
 [ ] 开工令**在同一条回复里给了**（**不等创始人问**）—— 缺它 = **未完成**
 [ ] **基准 ref 写清**（`gitea/local-main` ＋ as_of ＋ **"别核 main"**）
 [ ] **边界＋红线**写全（含 D334/D331 通道）
 [ ] **判据可复跑**（**数量类给命令，禁手写数**）
 [ ] **停止条件**给了（**计划外的红 / 冲突 / 越范围 / 动红线**）
 [ ] **回执项**给了（**含"未核处"**）
 [ ] 🔴 **派单件交付前过独立复核**（`subagent`，**只给它文档 + 一句"核它与实测是否一致"**）
       ⇒ **复核结论必须回写**（**不允许"复核了但没改"**）
```
