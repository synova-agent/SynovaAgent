# 决策：CLAUDE.md 退役为指针件 ＋ AGENTS.md 升 V7.0

> **日期**：2026-10-12 ｜ **决策人**：CTO ｜ **状态**：**已实施**（待 PR 合）
> **依据**：CTO 裁定 059 ｜ 2026-10-02《指令面与 GitHub 三层总方案》§3 第 1 步 ｜ 创始人 2026-10-12 令

## 一、背景

```
① 🔴 **CC 已退役**（D1146，2026-10-05）⇒ `CLAUDE.md`（**Claude Code 的配置文件**）**成为遗物**：
   · 最后提交 **2026-10-05**（**恰好是 D1146 那天**）⇒ **之后 7 天无人动**
② 🔴 **它与 `AGENTS.md` 大量重复**（**行级相似度 42.6%**）⇒ **口径分裂源**
③ 🔴 **它占注入预算 67%**：
   · `AGENTS.md` 28,189 B ＋ `CLAUDE.md` 43,692 B = **71,881 B > 65,536 预算（110%）**
   · ⇒ **DSH 的规则是"超预算时更宽的文件先被省略"** ⇒ **`AGENTS.md` 被系统性省略**
   · **实证**：本会话收到 `system-reminder`「**omitted AGENTS.md**」
```

## 二、考虑过的选项

| 选项 | 内容 | 判 |
|---|---|---|
| **A** | **保留 CLAUDE.md**，只往里加"分叉判别" | ❌ **预算已 110%** ⇒ 加了更糟 |
| **B** | **CLAUDE.md 改成"与 AGENTS.md 同内容"**（**靠 DSH 的"同内容只渲染一次"去重**） | ❌ **两个维护点 ⇒ 必然漂移** |
| **C** | 🔴 **CLAUDE.md 改"极短指针"（≤20 行）＋ 内容分流** | ✅ **选它** |

## 三、决定

```
🔴 **CLAUDE.md 退役为指针件**（**19 行 / 1,174 B**）：
 · 标"已退役 ＋ CC 退役依据（D1146）" ｜ **现行入口 = `AGENTS.md`**
 · **历史原文 → handbook `归档/CLAUDE.md-归档-2026-10-12.md`**（**原文照录，可追溯**）
 · **保留一行版本号**（**唯一原因**：`check-doc-truth.sh` 的 C3 判据改完前需在）
🔴 **AGENTS.md 升 V7.0**（**15,161 B**）：按"现状"重写（**包↔层／装卸两分／现行门禁 13 组／
   现行卡面 Q0-Q4／三层验证体系／分叉判别／决策参考框架**）
🔴 **引用同步（A 类 7 处必改）**：`check-doc-truth.sh`（C1 专家数/C3 版本一致 ⇒ **两件**）／
   `check-brief-vs-code.sh`（**改从 `AGENTS.md` 提取**）／ `weekly-selfcheck.sh` ／ **4 个测试 fixture**
```

## 四、依据

```
· **DSH 注入机制**（实测）：**字节预算是硬上限**；**超预算"drops whole broader files
  before truncating the most-specific file"** ⇒ `AGENTS.md` 被 omitted 即由此而来
· **"三件必须同批"**：新 `AGENTS.md` ＋ `CLAUDE.md` 指针 ＋ 引用同步 —— 否则
  `check-doc-truth.sh` / `check-brief-vs-code.sh` / `weekly-selfcheck.sh` **必红**
· **文档契约**（创始人 2026-10-02）：**主仓只放 A 入口重写式 / B 决策六段 / C 长期**
```
