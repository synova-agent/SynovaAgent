# 决策: 文档契约闸 3 判据加固 —— 补上 K3 复核测出的两类逃逸

状态: implemented
日期: 2026-10-07

## 一句话
把「闸 3 能被两条路绕开」补上：写成同名前缀的文件、以及用 git mv 搬进阻断区。

## 问题
D1193 把文档契约三闸接上线，并通过 K3 独立复核（CONDITIONAL PASS）。但 K3 自建夹具（不采信作者自测）
测出两类 P1 逃逸与一处 P1 缺口：
① 阻断条目 `X/**` 只匹配子树 ⇒ 把内容写成同名前缀**文件** `docs/plans.md` 即放行；
② 闸 3 取变更用 `--diff-filter=A`，而 `git mv` 被 git 记为 R(rename) ⇒ 把既有文档搬进阻断区可静默通过
（K3 实测三闸 PASS）；
③ §9.1 出口条件不可机器判定、`transition_hits` 只打印不落盘；且「存量 214」在合并当刻实测即 215、次日 226
—— 违反本仓「引用纪律」（数量一律以脚本实况为准，不得写进定义）。

## 决定
1. 阻断/过渡条目启用**前缀闭包**：`X/**` 同时命中 `X.<ext>`；边界收紧到 `.`，因此 `X-archive/` 不误拦；
   **白名单不启用闭包**（否则 `docs/**` 会放行根级 `docs.md`）。
2. 变更集统一带 `--no-renames`：rename 被拆成「删除 + 新增」，新路径必然进入新增清单；闸 1/2 也因此
   会重核「决策件换 lifecycle 目录」。
3. §9.1 删掉手写存量数字，改为**取数命令 + 可机器判定判据**（`git ls-files` 计数归零），并把
   `transition_hits` 落盘 `.claude/doc-contract-transition.log`（已 gitignore）；落盘失败**显式 warn 但不阻断**
   （铁律 11：不静默；但这是对账指标不是门禁）。
4. X1b（命名不同的同类目录）与 X3（`**/README.md` 在新目录播种）**登记为契约 §9.2 残余风险**，
   写明接受理由与复发时的处理方式，不静默丢弃。

## 考虑过的其他方案
- **无边界前缀匹配**（`rel.startswith("docs/plans")`）修 X1：拒绝 —— 会误拦 `docs/plans-archive/`，
  制造噪音 ⇒ 门禁被绕过（V3.9 教训）。
- **让匹配器猜同类名目录**（`coordination*`）：拒绝 —— 契约只点名具体路径，猜名字等于发明判据；
  改由 §3 明文要求「新增同类目录须显式登记阻断清单」。
- **X2 用 `--name-status` 解析 R 的目标路径**：可行，但要为 `--staged` 与 `--base` 各写一遍解析；
  `--no-renames` 更短且不引入新解析面（最小改动优先）。
- **R3 把 214 更新成 226**：拒绝 —— 数字必然再腐；改为去数字 + 落盘对账。
- **X3 直接收紧 `**/README.md`**：本轮拒绝 —— 机器判定「目录是否已存在」属新机制；先登记残余风险，
  复发再收（一次生成，非每错加机制）。

## 后果
- **好的**：K3 两条 P1 逃逸被堵且有**性质断言矩阵**（边界路径 × A/R/M 变更形态，共 34 条断言）；
  过渡对账有可取的数；契约不再含会腐的手写数字；残余风险显式可查。
- **要长期承担**：① `--no-renames` 让大改动 diff 的路径清单变长（无内容开销）；② 闭包把「同名前缀文件」
  也视为同类过程件 —— 若确有合法的 `docs/plans.md` 类需求，须走契约修订而不是绕过；③ X3 仍是已知缺口。
- **判据正确性仍须 K3 第二轮复核**（红线 R-6：改门禁者不得自判通过）——本件不得自宣「已合规」。
