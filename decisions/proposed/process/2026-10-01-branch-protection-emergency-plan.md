# 决策: 分支保护紧急预案（enforce_admins 关闭判据与恢复）

状态: proposed
日期: 2026-10-01

> **作者声明**：本件由 **Mac-CTO 亲自撰写**（契约 §4「做决定的人自己写，不代笔」＋ 裁定件决策三
> 「预案文本由你写」。提出人：工程线；裁定人：CTO）。

## 一句话

`main` 的保护平时**不许任何人绕过**；只有出现"修复本身被保护挡住、且没有别的路"这一种情况，才允许**临时**关掉管理员豁免，并且**24 小时内必须恢复**。

## 问题

`main` 现设 `enforce_admins = true`（管理员也受保护），12 项必需检查全绿才准合。
**好处**：零绕过，谁都不能"先合了再说"。
**代价**：当**保护本身**成为修复的障碍时（典型：某条必需检查自己坏了 ⇒ 永远是红 ⇒ 永远合不了修它的 PR），会形成**死锁**。
实测已有近似形态：`Control Tower Gate Tests` 的 CI 独有红 + Windows 腿 47 分钟，
今天已迫使 5 个 PR 反复重开（#915/#922/#924/#927/#929）。

**所以问题不是"要不要留个后门"，而是"死锁时怎么办、谁按、按了怎么收"。**

## 决定

**保留 `enforce_admins = 开`**，并立本预案。四条要素：

### ① 谁有权临时关闭
**只有 Mac-CTO（总 CTO）**。AI 线负责人、执行小队、Win 侧**一律无此权**。
理由：这是唯一能把"工程止损"和"治理约束"同时背下来的位置；下放即等于人人可绕过。

### ② 关闭的判据（**必须同时满足，缺一条不许关**）
```
(a) 存在一条**必需检查**处于**持续性红**（非 flaky：连续 ≥2 次 run 同一结论），
    或存在**不可绕过的结构性阻塞**（如必需 context 上游失败时消失——缺陷 B 型）；
(b) 该红/阻塞**恰好挡住修复它自己所需的那个 PR**（即"修它必须过它"）；
(c) 不存在替代路径：不得以"换个分支名/拆小 PR/等一轮 CI"能解；
(d) 已按 ③ 留痕，且**已把替代方案与风险各写一条**。
```
⇒ **任一条不满足 ⇒ 不许关**。宁可停手等一天，不可开一次性通道。

### ③ 关闭动作的留痕（**先写后做**）
关闭**之前**写入 `.claude/bypass.log` 同侧台账（或当期 CTO 工作台），逐条记：
```
执行者（哪个 session）｜ 名义（哪个 GitHub 账号）｜ 授权依据（② 的 a-d 逐条怎么满足）
关闭时刻（带时区）｜ 计划恢复时刻 ｜ 被绕过的检查名（逐个）｜ 本次要合的 PR 号
```
**禁止"事后补记"**。缺留痕 ⇒ 该操作**视为无效**，且按红线 R-8 通报。

### ④ 恢复时限与强制恢复
- **24 小时内必须恢复** `enforce_admins = true`；
- 恢复动作同样留痕（执行者 + 时刻 + 实际关闭时长）；
- **超 24h 未恢复 ⇒ 自动升级创始人**（不等 CTO 自觉）；
- 临时关闭期间**只准合"② 里声明的那个 PR"，一个都不许多合**。

## 考虑过的其他方案

| 方案 | 为什么不选 |
|---|---|
| **一直开 `enforce_admins = false`**（留常开后门） | 等于没有保护；且"临时"变"常态"是历史事故形态（审批配更易：`--no-verify` 泛滥就是这条路） |
| **彻底取消保护** | 与铁律 0-3「main 是唯一真相、禁直推」直接冲突 |
| **不改保护，坏了就等** | 今天实证：等的结果是 5 个 PR 反复重开、治理吞主线（1:4.9 的成因之一） |
| **把"关保护"写进 `SYNO_ALLOW_MAIN_PUSH` 逃生舱** | 见下节 —— **两者是不同的东西，不能合并** |

## 后果

**好的**：死锁有出口，且出口**有判据、有留痕、有时限**——不是"凭 CTO 心情"。
**坏的 / 长期承担**：
- 任何"临时关闭"都**降低当次变更的独立审查强度** ⇒ 关闭期间合并的 PR **必须补一次 K3 复核**（事后，不许免）；
- 本预案把"关保护"从**禁止**变成**有条件允许** ⇒ 判据必须经得起事后审（故 ② 写成可逐条对照的 a-d）；
- 若一年内触发 ≥3 次 ⇒ **说明必需集本身有问题**，应转为"重设计必需集"而不是继续用预案。

## 🔴 与 `SYNO_ALLOW_MAIN_PUSH` 逃生舱的关系（必须分清）

| | 本预案（关 `enforce_admins`） | `SYNO_ALLOW_MAIN_PUSH` |
|---|---|---|
| 作用对象 | **保护本身**（临时降级保护） | **单次直推 main** |
| 触发场景 | **必需检查自己坏了**，修它必须过它 | 常规内容想直推（**原则上不许**） |
| 权限 | Mac-CTO 按 ② 判据 + ③ 留痕 | **需创始人逐次显式批准** |
| 历史 | 本件新立 | ⚠️ **D570 曾把它当常规通道用过 = 违规**（既有裁定已定） |
| 关系 | **两条独立通道，不得互相替代**：不许"因为要直推所以关保护"，也不许"因为关了保护所以可直推" | 同左 |
