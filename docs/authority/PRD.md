## 1. 一句话定位

**Synova = 组织数字孪生诊断 + 持续增长导航系统。**
诊断是手段，增长是目的。核心问题：**这家企业的增长卡在哪里？现在该做什么？**
Agent，不是 ChatBot——驻扎企业，持续观测，主动发现，自动诊断，给出行动建议，跟踪执行。

> 创始人比喻（2026-08-20）：**把咨询公司的咨询体系变成 Agent——"24 小时驻扎的麦肯锡顾问"**。产品是企业的"免疫系统"，外部咨询师是"医生"。

## 2. 为谁解决什么问题

| 项 | 内容 |
|---|---|
| 目标客户 | 5–1000 人团队的中小企业（历史定位曾写 5-300，待创始人确认最终口径） |
| 问题 | 中小企业没有专职组织诊断能力：不知道人员/工具/流程/资本之间哪里出了问题；请不起麦肯锡 |
| 价值 | "组织医生"：持续监测 + 定期检查 + 行动建议 + 跟踪执行，而不是提完建议就走人 |
| 一句话 | 把麦肯锡级的组织诊断能力做成 AI Agent，让中小团队负担得起 |

## 3. 产品形态

- **独立 API 进程**（HTTP + MCP），配置 LLM API Key 即用，不依赖前端/桌面端/外部数据库
- **双轨部署**：国际轨 = NemoClaw MCP 生态；国内轨 = DomesticHub + 国产 LLM（DeepSeek/OpenAI 兼容）
- **数据安全分级**：L0 公开摘要 / L1 聚合信号 / L2 脱敏证据 / L3 原始数据（仅客户企业内可见）

## 4. 两大核心系统

1. **GA 按需诊断**：用户触发，6 阶段管道（访谈→数据→假设→根因→报告→交付），全部测量器 + 专家 → 综合诊断报告
2. **Sentinel 定时哨兵**：Cron 自动，基线对比 + 异常检测 → 证据池 → 信号聚合 → 交叉关联 + 严重度升级 → 专家 → 工单

## 5. 核心能力清单

- **7 维度 × 25 测量器（compute）**：纯数学函数，不碰数据库
- **专家体系**：多位领域专家（历史上 6→7→8 位演进；当前以 `expert/expert-registry.yaml` 为准）
  - ⚠️ **待查证**：AGENTS.md 声称 7 位、CLAUDE.md 声称 8 位——这是文档漂移实例，STATUS.md 有记录
- **本体层（企业知识图谱）**：22 节点类型 / 17 边类型；42 条因果边体系（从权威文档 01 演化）
- **信号聚合 → 专家路由 → ReAct 推理 + 交叉验证 → 综合诊断报告**

## 6. 客户验证（第一个付费客户）

**客户A**（2026-08-04 建档，档案：`docs/plans/codex/SYNOVA-客户A-客户项目档案-20260804.md`）

- 母婴亲子服务品牌，新生儿手足模纪念品，10 年历史，全国第一（生态位窄到无大竞争者）
- 集团架构：投资/生产/销售多主体；生产 16 人月处理约 3200 单；月新增客户约 3500 人；累计沉淀客户 20 万+ 未维护
- **单位经济（诊断结论：不规模经济）**：每 100 客成交净利仅 600 元（净利率 2.5%），单成交客户净利仅 10 元；营销费用占 45%，产量翻倍 = 人手翻倍
- **十年复盘三大失误**：① 收入进私账 → 无银行流水 → 缺钱时拿不到授信；② 最好年份（2024 营收 1500 万+）未做资本规划；③ 把红利当实力（2020-2024 增长约 90% 来自新生儿红利，2025 红利退潮半年报亏损）
- **2026-07 砍品新政**：砍 580 元以下低价引流品，聚焦高净值客户
- **获客故事（创始人口述 2026-08-20）**：客户主要基于**信任**；当时客户遇到问题找过各种答案，创始人用 **Synova 诊断体系作提示词注入**对客户公司业务做诊断，得出与外部咨询公司和高管**完全不同的判断，最终证明 Synova 是对的** → 客户签约并打款

> 意义：验证了"组织诊断"对真实企业的价值；目标客户画像 = 有增长瓶颈、靠直觉管理、无专业诊断能力的中小企业主。
