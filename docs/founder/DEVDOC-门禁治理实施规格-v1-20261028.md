## 0. 一句话任务与非目标

**任务**：把门禁从"人工举证驱动"改成"机器判定 + 服务端强制 + 可退役"，并堵上豁免自签发、空绿、旧树假绿三个洞。

- ❌ 不重写任何 P0 安全判定逻辑（本批只加登记与遥测）。

## 2. 目标架构（实施侧只需记住三条）

1. **能机器判定的绝不人工举证；判不了的用模板 + 抽检，不造门禁。**
2. **强制力只在服务端**（pre-commit 实跑 + Gitea CI）。客户端 hook 只算提醒。
3. **门禁三分类**：
   - `P0` 安全类：权限/跨企业隔离/Secrets/fail-closed/凭证/豁免与白名单变更保护 → **永不自动退役**。
   - `P1` 质量类：类型断言/参数校验/统一错误/未知枚举拒绝/并发上限 → 按「运行次数 + 命中数」评审退役。
   - `P2` 文书类：头部契约/README/设计哲学 → 取消举证，模板生成 + grep。

## 3. 工作分解（W1–W9）

### W1 ｜ 门禁登记与三分类
**写集**：`docs/authority/GATE-INVENTORY.yaml`、`scripts/control-tower/check-gate-inventory.*`（新增）
**要求**：
- 每个门禁条目补齐字段：`id, class(P0|P1|P2), owner, review_after, entrypoint, required_ci(bool)`。
- 本批只做**登记**，不改任何判定逻辑；分类名单 PR 中列出让 CTO 过目。
- 校验脚本：缺字段 / class 非法 / owner 为空 → exit 1；清单文件不可读 → exit 2。

### W2 ｜ 运行遥测入库（修复"零命中=没跑"）
**写集**：`.gitignore`、`gate-telemetry/**`（新增目录）、`scripts/lib/gate-telemetry.sh`（新增）、各门禁入口**最小侵入**埋点
**数据格式**（每运行一次写一条 JSON，**按日分片 + 文件名带 sha，避免多 agent 并行写同一文件撞车**）：
```
gate-telemetry/2026-10-28/CT-46-1ca0d4dfc-<pid>.json
{"ts":"...","gate_id":"CT-46","class":"P1","commit":"...","runner":"pre-commit|gitea|github",
 "ran":true,"duration_ms":1234,"hits":0,"result":"pass|fail|error","exit_code":0}
```
**要求**：
- `.gitignore` 移除对遥测目录的屏蔽；**保留** `.claude/bypass.log` 等运行期隐私产物不入库。
- 写遥测失败**不得**让门禁误判：`|| true` 并 stderr 提示（swallow-ok 注释）。
- 周汇总脚本 `gate-telemetry-report`：输出每门禁「运行次数 / 命中数 / 中位耗时」。

### W3 ｜ 豁免双人复核 + 日落（堵自我签发）
**写集**：`gate-exemptions/**`、`scripts/control-tower/check-gate-protection.sh`（仅加强校验）、`scripts/control-tower/check-exemptions.sh`（新增）
**Schema**（每份豁免必须含）：
```yaml
id: EX-2026-0001
gate_id: CT-46
paths: ["src/**"]
reason: 一句话
owner: <责任人>
author: <执行 agent>
reviewer: <必须 != author 的独立审计，如 K3>
review_evidence: <PR# 或审计件路径>
ruling_ref: <CTO 裁定号>
created_on: 2026-10-28
expires_on: 2026-11-27   # 默认 +30d，最长 90d
```
**判据**：
- reviewer 缺失 / reviewer==author / 无 review_evidence / 已过期 → exit 1（fail-closed）。
- 存量 86 份：批量打 `status: legacy`，**30 天过渡期内补字段**；到期未补 → 自动失效并在 CI 报红清单。
- 每周向创始人输出豁免清单（新增、即将到期、逾期）。

### W4 ｜ CI 空绿检测（skipped 不算过）
**写集**：`.gitea/workflows/local-gates.yml`、`.github/workflows/ci.yml`、汇总门脚本
**要求**：
- 关键 job（控制塔门禁测试、集成契约、黄金案例、Vitest 两片）必须输出 `test_count=N` 到 `$GITHUB_OUTPUT`。
- 汇总门校验：`test_count>0` 且步骤结论为 success；**skipped 一律 fail**。
- 条件跳过若属正当（如未触及路径），必须在 summary 明示「未运行原因」，且该 job 不计入"已通过"清单。

### W5 ｜ 集成新鲜度（不许在旧树上宣布通过）
**写集**：`scripts/control-tower/check-mirror-freshness.sh`（新增）、周报
**关键拓扑约束**：**GitHub runner 访问不了内网 Gitea**，所以新鲜度校验放 **Gitea 侧 / Mac 本机**，不要写进 GitHub CI。
```bash
GH=$(git ls-remote origin refs/heads/main | awk '{print $1}')
LM=$(git rev-parse gitea/local-main)
[ "$GH" = "$LM" ] || { echo "镜像落后 $(git rev-list --count $GH..$LM) 提交"; exit 1; }
```
**要求**：任何"集成通过"结论必须带 `head_sha`；镜像落后时周报标黄，禁止用旧树结论对外汇报。

### W6 ｜ 判据自检三件套（修"判据自己错"）
**写集**：`scripts/lib/gate-assert.sh`（新增）、各新判据接入
**要求**：每条判据声明
- 正例能命中（有夹具）；
- 反例必红（变异夹具）；
- **退出码白名单**：`0=通过 1=真红 2=判据故障`，其它一律按 2 处理；**严禁把 128 当 0**。
- 历史已知坑（`git grep A..B`、A12 自指）写入 `docs/authority/gate-pitfalls.md`，新增判据须先读。

### W7 ｜ L0 脚手架与模板（文书成本归零）
**写集**：`templates/code/**`（新增）、`scripts/dev/new-file.*`（新增）、`package.json` scripts、`scripts/pre-commit-check.sh` 追加 grep 兜底
**命令**：
```bash

pnpm new module measurement-trends    # 生成 src 模块 + 配对测试件
```
**模板原则（克制，防头注膨胀）**：
- AI 只写三段真契约：`@input` / `@output` / `@degraded`（**禁止占位符 TBD**）。

- 目标头注 ≤12 行（现有个别文件 34 行，禁止回升）。
- pre-commit 兜底：三段缺失 → exit 1。**hook 只提醒，不做强制**（客户端不可靠）。

### W8 ｜ 双预算与取消"不适用举证"

### W10 ｜ Unicode 同形字分级门禁（整合 D738 + 研究#13 + 本次 .ts 全角发现）
**写集**：`scripts/control-tower/check-unicode-confusable.*`（新增）、`docs/authority/GATE-INVENTORY.yaml`（追加条目 `CT-UNICODE`，class=P0）、`scripts/pre-commit-check.sh` 与 `.gitea/workflows/local-gates.yml` 接入、`gate-telemetry/**` 埋点（复用 W2）
**背景**：本仓库存在系统性全角字符污染（实测 main 仓 899/1451 受控 `.ts` 含歧义字符；`ct/p3m7-pr5` 的 cron/cycle 范围 1,341 处，已确认 0 在变量名/裸代码、cron 表达式 ASCII 干净）。已规划但未接线：D738（bash `$VAR` 全角边界常驻扫描，PR #544 未合）、研究规格外部审计器 finding #13（乱码 `\uFFFD` 检查）。本项将三者**合并为一道分级门禁**，避免门禁膨胀。
**判定分层**：
- **CT-UNICODE-A（P0 阻断）**：标识符 / 裸代码位出现同形字（视觉模仿 ASCII 但编码不同，如西里尔 `а`、希腊 `ο`、全角字母）→ 拦截。此为真危险（Trojan Source / 变量名冒充），人眼与 grep 均漏。
- **CT-UNICODE-B（P0 阻断）**：任意位置出现双向控制符（U+202A–U+202E、U+2066–U+2069）→ 拦截（经典 Trojan Source 向量）。
- **CT-UNICODE-C（P0 阻断）**：任意位置出现 U+FFFD 替换字符或乱码标记 → 拦截（编码损坏证据，研究#13）。
- **CT-UNICODE-D（P2 仅提醒）**：注释 / 字符串字面量内的全角标点（U+FF01–U+FF5E）→ **不阻断**，仅报告行号清单。本仓库中文注释/文案属正常，故仅观感。
**范围（关键约束）**：**只查本次 PR 的 diff 新增行**（`git diff --unified=0 <base>...HEAD`；pre-commit 用 `git diff --cached`），**不扫全仓库**。否则 22k 历史全角字符会卡死所有 PR。存量污染单列"遗留清单"，不阻断、不要求即时清理。
**Scanner 自身约束（D370/D738 教训）**：扫描脚本必须 UTF-8 严格解码（`errors='strict'` 或等价），**禁止 cp1252 解码**（Windows 下 UnicodeDecodeError→误 degraded）、**禁止 `$VAR（` 全角边界**（bash 下变量名吞全角→ `unbound variable`）。扫描器自身故障按 W6 退出码白名单归 `2`（判据故障），**绝不可归 0（假绿）**。
**豁免**：D 档（观感）默认放行，无需逐文件豁免；A/B/C 档如需豁免，走 W3 双人复核 + 日落（P0 永不自动退役）。
**接入**：输出 `test_count=N` 接入 W4 空绿检测；带 `head_sha` 接入 W5 新鲜度；埋点接入 W2 遥测。
**非目标**：不重写既有 D738 扫描逻辑为独立门禁（其意图并入本项，PR #544 关闭不再单独合）；不扩大为"禁止一切非 ASCII"（会误伤合法中文）。
