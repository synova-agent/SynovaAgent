```

 🔴 **必须做完**：见 §三 模块表（**完成标准列**为硬判据）

## 二、🔴 三条硬判据（**全局适用，防"假收口"**）

```
 ① **"端到端" ＝ 真实入口 ⇒ 真实路径 ⇒ 真实产出** —— **种子（SEED）直写库不算**
 ② **每条完成标准必须配"反例必红"**（改坏/摘掉一处 ⇒ 判据必红）
 ③ **每条完成标准前置自检：判据件是否存在**（不许把判据建在 NOT_IMPLEMENTED 的探针上）
 ④ 🆕 **复用两级口径（FDE 研究 v2 裁 1）**：**"骨架在（代码存在）" ≠ "实证在（判据真跑过）"**
