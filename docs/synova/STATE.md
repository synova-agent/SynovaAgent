## 1. 我们在做什么（30 秒）

**SynovaAgent** = 组织数字孪生诊断 + 持续增长导航系统。
**核心问题**：这家企业的增长卡在哪里？现在该做什么？
**形态**：独立 Agent 进程（HTTP + MCP），驻扎企业，持续观测 → 主动发现 → 自动诊断 → 行动建议 → 跟踪执行。**不是 ChatBot**。
