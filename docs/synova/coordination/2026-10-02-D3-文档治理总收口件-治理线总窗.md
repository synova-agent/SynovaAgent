### 2.2 修复：`.gitattributes` 加 union（**已落地，见本窗 diff**）

```gitattributes
docs/authority/DOCS-REGISTRY.yaml merge=union
```
（含背景、实测、残余风险、前置条件四条注释，见 `.gitattributes` 本窗新增块）

**先红后绿夹具（沙箱，可原地重放）**：

```bash
W=$(mktemp -d); cd $W; git init -q .; git config user.email t@t; git config user.name t
mkdir -p docs/authority
printf 'documents:\n  - id: DOC-0001\n    path: A.md\n\n' > docs/authority/DOCS-REGISTRY.yaml
git add -A; git commit -qm base
git checkout -qb A; printf 'documents:\n  - id: DOC-0001\n    path: A.md\n\n  - id: DOC-0002\n    path: B.md\n' > docs/authority/DOCS-REGISTRY.yaml; git commit -qam A
git checkout -q master; git checkout -qb B; printf 'documents:\n  - id: DOC-0001\n    path: A.md\n\n  - id: DOC-0003\n    path: C.md\n' > docs/authority/DOCS-REGISTRY.yaml; git commit -qam B
git checkout -q A; git merge B            # ← 红
git merge --abort; printf 'docs/authority/DOCS-REGISTRY.yaml merge=union\n' > .gitattributes
git config merge.union.driver "git merge-file --union %A %O %B"
git add -A; git commit -qm attr; git checkout -q B; git merge A   # ← 绿
```

| 阶段 | 原始输出 |
|---|---|
| **红**（无规则） | `Auto-merging docs/authority/DOCS-REGISTRY.yaml` / **`CONFLICT (content): Merge conflict in docs/authority/DOCS-REGISTRY.yaml`** / `Automatic merge failed`（冲突标记数 = 1） |
| **绿**（有规则） | `Auto-merging …` / **无冲突**；合并后内容含双方条目，**id 数 = 3**、冲突标记 = 0 |

⚠️ **夹具自身踩过一个坑（留痕）**：首版把 `.gitattributes` 只提交在 A 分支 ⇒ B 分支工作树里没有该文件 ⇒ **属性未生效、仍红**。
**规训：规则必须落在共同祖先（或双方都有的提交）上**——本仓把规则加在 main 上后，所有"merge main"的分支自然继承。
