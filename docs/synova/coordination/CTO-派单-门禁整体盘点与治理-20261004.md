## 三、判据：每条门禁必须给四样（**缺一不算盘完**）

```
① 载体       —— 文件:行号（或 CI job 名 + 触发器）
② 执行门禁   —— 谁调用它？是【真阻断】还是【advisory】？（`|| true` 一律算 advisory）
③ 判别性夹具 —— **改坏即红**。给得出夹具 = 真门禁；给不出 = 纸老虎
④ 最近复核日 —— 拿不出 ⇒ 标"从未复核"
```

**退役判据（用创始人 2026-10-02 定的铁律生命周期元规则）**：
```
a. 载体已不存在
b. 使命已完成
c. 连续两季"零违反且无执行门禁"（软约束 = 无约束）
⇒ 退役 ≠ 删除 ⇒ 移入 CHANGELOG（可追溯）
```

**分类输出要求**：
```
🔴 A 类 纸老虎（判据恒绿 / 无夹具 / `|| true` 假阻断）  ⇒ 建议删或修
🟡 B 类 重复（两条查同一件事）                        ⇒ 建议并
🟢 C 类 真承重（有夹具、改坏即红）                     ⇒ 建议留
```
