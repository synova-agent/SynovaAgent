   <线 id / 点 id> 的什么阻塞**

④ DSH 边界：<不适用（多数）／涉及则查四类清单>
⑤ 架构合规：<不涉及 src/ ／ 涉及则过三类否决> ｜ 模式库：<ctrl-tower-change / windows-compat / contract-template>
