## §〇 归属与依据（**v3 新增，缺此段 = 派单无效**）

```
① 归属：线 <id> · 点 <id>（或显式标：前提清单第 <n> 项 / 线外工作项 T-D<n>）
② 格子现状：五态 = <缺/写了没接/接了跑不通/能跑未验证/健康> ｜ 实测命令 + 时间：<...>
③ 依据（权威件回执）：读了 <全名 + 版本/日期>；结论 <逐条 ①…②…>
   —— 过「引用四规则」（数字查未核实册 ｜ file:line 查取码登记 ｜ 取舍查权威索引 ｜ 判据穿生产入口）
④ DSH 边界：<必须自建/用 DSH/参考自研/可裁剪> —— 查 CTO-DSH派单台账 §一 四类清单
⑤ 架构合规：三类否决 = <过/否> ｜ 三问机器判定方式 = 加了吗<...>、接上了吗<...>、生效了吗<...>
⑥ 红线：三红线 <逐条> ｜ 不该做 8 <逐条> ｜ G1 `@deepseek-ai` 零命中 <已核>
⑦ 判据：穿生产入口的用例 = <命令/场景> ｜ 四件套 <verify/.json 证据(附实跑数)/真实入口/改坏即红>
```

### 🔴 §〇-补 · 复现证据块（**v3.1 新增，缺此块 = 派单无效**）

> **来源**：经验教训 **L-031**（CTO 自己在 B-1 卡上栽的：`timeout` 候选清单写错 4 个文件、
> 引 `00-最终方案:68` 行号已漂 2 行、"命中 38 个文件"是一次带限 grep 且执行方复现为 59）。
> **根因**：`pre-dispatch-check` 技能第③条（"技术声称亲自复现"）**早就存在**，脚本也在——
> **缺的是"卡里必须贴出证据"这个物理字段**。技能是软机制；**字段才是执行体**。

```
⑧ 复现证据块（本卡每一条 file:line / 每一个数字，逐条给命令 + 原始输出 + as_of）
   —— 格式：
   [E1] <声称>            ← 例：timeout 的 1:1 对应物是 src/llm/timeout.ts
        命令: <可原样复跑，禁带未说明的过滤管道>
        输出: <原始输出（贴关键行；长输出给头部 + 行数）>
        as_of: <YYYY-MM-DD HH:MM>  断面: <repo HEAD / tag>
   [E2] …
   🔴 三条硬规矩：
     ① 判"某物不存在"**不得用带过滤的管道**（L-033）—— 须给不带过滤的枚举 + "扫了多少个对象"
     ② 涉及"哪个文件是本体"的判断，必须给**机械理由**（谁 import 它 / 谁调用它），不是语义直觉
     ③ 引 `file:line` 必须写明**断面**（行号会漂：D524 教训 + L-031 实例）
```
