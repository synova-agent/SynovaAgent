⇒ ② **`docs_only=false`**（全 10 job 跳步数 = 0、重步都在跑）⇒ **早退根本没被触发** ⇒ ⒜/⒝ 无法由叠加探针产出。
（该 run 已按省载**取消**；上表为取消前快照。注：`created→updated` 的 13s 是状态刷新间隔，**不是** ⒝ 的耗时读数，不能当 ⒝ 证据。）

**根因（与 CTO 预设的失败条件不同，须据实修正）**：不是"仍在用 main 的 workflow"，而是 ——
`docs_only` 由 `git diff --name-only origin/main...HEAD` 判定，而叠加分支**相对 main 带着 `ci.yml` 的改动** ⇒ 该文件不匹配 `\.(md|json)$|task-state/|\.claude/` ⇒ `docs_only=false`。

**不可能性证明（一句话）**：`docs_only=true` 要求 head 相对 main **只含 doc 面文件**（即不含 `ci.yml`）；
而 run 使用 T3 的 workflow 要求 T3 的 `ci.yml` 出现在 `base(main) + head` 的合并结果里。
两者同时成立 ⟺ **T3 的 `ci.yml` 已在 main 里**。
⇒ 叠加探针在数学上不可能产出 ⒜/⒝；这是**平台语义**，不是实现问题。
