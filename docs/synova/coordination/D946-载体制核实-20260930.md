## 一、载体判定：`.agent-presets/` 在运行态已死，活载体是 profile bundle patch 层

  每个 `@local/dsh-preset-*` 的 `package.json` 只有一行实质内容 `"dsh": {"bundle": {"patch": "./cordis.patch.yml"}}`，源文件在 `/Users/wane/src/dsh-preset-bundles/<id>/cordis.patch.yml`（`package.json:5-16` 的 `file:` 依赖）。
- **运行态活证据**: Cordis Inspect（host / `@deepseek-ai/dsh-agent-preset` / `listConfigs`）返回 **17 行**，`patchId` 分别为
