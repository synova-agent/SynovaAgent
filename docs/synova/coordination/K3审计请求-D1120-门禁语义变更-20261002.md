## T-3 · `DOCS-REGISTRY` 查重（union 的必要配套）

**背景**：本窗已落地 `.gitattributes` `docs/authority/DOCS-REGISTRY.yaml merge=union`（机械项，非门禁语义）。
**实测反例（union 的副作用）**：两侧修改同一 entry 同一行时 **union 不报冲突**，产出**重复键**：

```
  - id: DOC-0001
    path: A.md
    status: draft
    status: active      ← 重复键，静默合入
```
**而 `doc-registry-gate.sh` 无查重**（`grep -nE "dup|重复|uniq|seen"` 零命中）。

**提案（拟改既有闸，不新增门禁条目）**：在 `scripts/doc-system/doc-registry-gate.sh` 内加"登记表内 id 唯一 + 同一 entry 内键唯一"两条断言，三态退出码 `0/1/2`。

**先红后绿夹具（已备）**：
| 用例 | 输入 | 期望 |

| 正例 | 现状 46 条（id 唯一） | exit 0 |
| 反例 1 | 注入重复 id | exit 1 + 点名 id |
| 反例 2 | 注入同 entry 重复键（union 产物形态） | exit 1 + 点名文件:行 |
| 反例 3 | 文件缺失 / 不可解析 | exit 2（**fail-closed，绝不与通过混同**） |

**请求 K3**：judge 夹具判别性（是否"改坏即红"）+ 是否误伤（例如 `ARCH-*` 与 `DOC-*` 混排是否会被误判）。
