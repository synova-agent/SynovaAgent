**两侧同一套 DSH 源码**（Mac 与 Win 各持一份，版本须一致）——**按机器写路径，勿照抄对方绝对路径**：

> ⚠️ **实测更正（CTO 2026-09-23）**：DSH **源码树内既无 `config/` 顶层目录、也无任何 `agent-presets` 目录**（`find <源码树> -type d -name agent-presets` 零命中）；`standard` 预设源**只存在于已安装的 DSH 包**里。所以 `--standard-from` 要指向**安装包**路径，不是源码树。此条先前写错，已按实测改正。

**跨机版本对账（两侧各跑一次，输出须一致）**：
```bash
git -C <DSH源码树> rev-parse --short HEAD          # 期望两侧均 46a7f68b（rc.1；唯一源 docs/synova/coordination/DSH-断面.json）

```
→ 不一致 = 两侧借鉴/对比基准不同，**先拉平源码树再谈其他**（这一条填补下方 G4 的一半：机器级可自证，仓库级仍缺强检查）。
→ Win 侧落位预设时，`--standard-from` 指向**本机源码树的 standard 目录**，不要指向 Mac 路径。

### 7.2 新增纪律（4 条，跨机同样适用）

1. **负面断言必须写明搜索范围**（"零命中"= 在哪个范围内零命中）
2. **判断面必须用 `git ls-files`，grep 必须限定 `src/`**（源码树 `lib/` 被 `.gitignore` 忽略：`git ls-files '*/lib/index.js'` = 0，但磁盘上存在 307 个 → **工作树干净 ≠ 没有产物**）
3. **计数必须带命令 + 排除项**（同一对象三个数就是三个口径：`*/lib/index.js`=307 / 全部 index.js 排除 node_modules=711 / 未排除 types=710）
4. **路径必须写全两层**：DSH 源码树是 `packages/<组>/<包>/…`（如 `packages/mcp/mcp-client/src/transport.ts`、`packages/settings/settings/src/index.ts`），**不是** `packages/<包>/src/…`

### 7.3 队长预设必须带 Agent Teams（D931 修复）

- 根因：原预设挂的是 legacy `delegation`（子代理），**Agent Teams 三件套没挂** → 队长物理上只会开子代理，小队变摆设。
- 修复（`docs/synova/presets/install-squad-lead.sh`）：`delegation` → `agent-team` + `tool-agent-team` + `ui-agent-team`，**`maxMembers: 4` 把"成员≤4"物理化**。
- **Win 侧落位后必须 grep 自证**：
  ```bash
  grep -cE "^- id: (agent-team|tool-agent-team|ui-agent-team)" ~/.dsh/.agent-presets/synova-squad-lead/agent.cordis.yml   # 期望 3
  grep -c "^- id: delegation" ~/.dsh/.agent-presets/synova-squad-lead/agent.cordis.yml                                      # 期望 0
  grep -n "maxMembers" ~/.dsh/.agent-presets/synova-squad-lead/agent.cordis.yml                                            # 期望 4
  ```
- ⚠️ **预设是 session 启动时加载**：落位后**必须重开 session** 才生效。
- ⚠️ 该修复在 **PR #727**（`fix/d931-squad-lead-team`）；若 Win 拉平的 main 里 `install-squad-lead.sh` 无 `agent-team` 字样，说明 #727 未合并 → 先按 7.3 手动补，或等合并。
