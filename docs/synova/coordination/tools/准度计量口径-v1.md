## 证据链三要素（卡面 §⑥「可复核」）
| 要素 | 口径 |
|---|---|
| 取自哪段时序 | `metric_readings`（2-1a 真表）指定 org+metric 的日度**非降级**行；窗口 = [首观测日, 末观测日] |
| 与什么比 | 前半窗均值（early） vs 后半窗均值（late），同口径同度量前后对照 |
| 结论怎么算出来 | `trend = late − early`；**valid ⇔** `trend ≥ 0.02` ∧ 两半窗各 ≥ 5 行 ∧ 相邻观测日间隔 ≤ 3 天 |

## 三条硬规则
1. **不给结论优先**：任一前提不成立 ⇒ `verdict=invalid` 且 `trend=null`（禁假绿）；
2. **时序完整门**：观测日缺口 > 3 天即 invalid（"抽掉一段照样给结论" = 口径被改坏，判据必红）；
3. **供数口径**（沿 2-1b 裁 A3）：标定/趋势供数行必须非 degraded（`degraded=0`）。

## 判据管线（接线）
临时库（os.tmpdir，不写主树/主库）→ 真实 `reconcileSchema`（2-1a）→ 真实 `createMetricSink`（2-1b，幂等+R4 降级语义）→ 口径函数 → 独立重算自证（纪律8）→ 抽段反例（卡面 §⑥ 反例）。

## 参数（冻结于探针常量）
`MIN_HALF=5` ／ `MAX_GAP_DAYS=3` ／ `MIN_TREND=0.02`。改参数 = 改口径 = 须过独立复核。
