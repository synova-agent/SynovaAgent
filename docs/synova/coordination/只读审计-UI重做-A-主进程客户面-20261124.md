## §1 模块锚（九项之①）

- **模块**：主进程客户面（Electron main 侧会出现在客户屏幕上的文字）
- **服务的真实客户／用户动作**：老板**看托盘菜单**、**收到系统通知**、**在登录页输入账号**
- **本批完成后有什么用**：把这三处"会印在客户脸上但一直没人审计"的文案全部列清，并把禁词命中逐条标出，供 T4/T6 修

- **长期边界**：读 `electron/main.cjs`、`electron/preload.cjs`、登录页及其服务端提供方；**不改任何文件**（除本任务产出的报告）
- **明确不做**：不改代码、不改 UI、不启动生产库、不碰客户数据、不改 `scripts/**`、不评估技术架构
- **验收入口**：产出一份报告，**每条客户可见字符串都有 `path:line`**
- **尚未确认**：`/app/login.html` 的实际文件位置（`main.cjs:140` 指向 `SERVER_URL/app/login.html`，需自行定位服务端静态目录）
