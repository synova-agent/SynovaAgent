## §1 🔴 机制事实（先定事实，再谈方案）

### 1.1 注入机制（DSH 源码实测）

`packages/context/agent-instructions/`：
```ts
// src/config.ts:12-13
DEFAULT_INSTRUCTION_FILE_CANDIDATES       = ['AGENTS.md', 'CLAUDE.md']
DEFAULT_LOCAL_INSTRUCTION_FILE_CANDIDATES = ['AGENTS.local.md', 'CLAUDE.local.md']
// src/config.ts:25 最大单文件字节；:43 maxSourceBytes；:44-45 两候选清单
```
README 关键三条（原文）：
> ① **基线消息 = 用户全局 `$DSH_HOME/AGENTS.md` ＋ 项目链（从项目根到会话工作目录，broad-to-specific）**
> ② **「Sibling files whose content matches after trimming render once, so a `CLAUDE.md` that duplicates its `AGENTS.md` is not repeated.」**
> ③ **字节预算是硬上限**；**「drops whole broader files before truncating the most-specific file」**；超预算会发**可见的 `Workspace instruction budget …` 通知（列明被省略/截断的路径）**；**渲染字节永不超 `maxBytes`**

### 1.2 我方的指令面占用（实测）

### 2.1 🔴 预算约束是硬天花板（**"8 份够不够"的真答案**）

```
A 批 8 份 × ≤4KB = 32KB；B 批 5 份 × ≤4KB = 20KB
而域级件的可用余量 = 7,117 B（≈1.7 份）
⇒ 不瘦身 ⇒ 域级件要么被"更宽的文件先省略"挤掉，要么把根件挤出预算（更糟）
⇒ 瘦身目标：L1 总占 ≤55% ⇒ 腾出 ≈28 KB ⇒ 容纳 A+B 共 13 份
```
**复用 DSH 的真机制**：**"内容相同的兄弟文件只渲染一次"** ⇒ 退役 `CLAUDE.md`（改为指针）**天然省 26 KB**，无需删内容。

## §5 🔴 我此前结论的**逐条更正留痕**（防"越来越相反"）

| # | 我说过的 | 实测真相 |
|---|---|---|
| 1 | 「`CLAUDE.md` 与 `AGENTS.md` 重复 20 个标题、几乎整个复本，各注入一份 ⇒ 41.6KB 吃 4 次」 | ⚠️ **半错**：标题有 20 个同名，但**行级相似度仅 42.6%**（10,845 vs 26,492 字符）⇒ **不是复本**。且 DSH **同内容只渲染一次** ⇒ "吃 4 次"不成立 |
| 2 | 「`scripts/control-tower` 只 8 文件」 | 🔴 **错**：**78 个顶层文件 / 84 跟踪**（我那条 `find` 写错了） |
| 3 | 「各线 bundle 缺 PERSONA」 | ⚠️ **半错**：各线 persona **内嵌在 `cordis.patch.yml` 的 `prefix:`**；我的包额外有 `PERSONA.md` 作规格源 |
| 4 | 「8 份 `AGENTS.md` 够了」 | ⚠️ **不完整**：**预算只剩 7 KB** ⇒ **不瘦身装不进**；应按"判据"定数（我给出 8+5） |
| 5 | 「`CLAUDE.md` 可直接退役」 | 🔴 **差点酿祸**：它是 **3 处门禁脚本的硬依赖**（版本一致门禁 / 流程约束提取 / 报错文案）⇒ **须跨线协调** |

**方法论自省**：以上 5 条中 **3 条**的根因是**同一个**——**只看"看起来像"的层面（标题/目录名/文件数），没跑到"内容/依赖/预算"这一层**。
⇒ **判据（我自缚）**：凡"某文件/目录是什么、有多大、能不能删"，**必须实测到内容与依赖两级**，不许凭名字推。
