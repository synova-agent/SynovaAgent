## 一、现行判据（**不合格**，要换掉的那条）

原卡（#987/#988，batch0b 五支，已合 `4a35bd7cc`）Done 里写的是：

```
grep -rl "action_effect_lag" extensions/ontology/edge-types/ | wc -l   ⇒ 55
# 以及等价的形式：WITH_FIELD_NONEMPTY=55
```

**为什么不合格（判据纪律 B：修复前 baseline 上必须红）**：
- 该判据只问「键**在不在** / 值**非不非空**」。`"unknown"` **非空** ⇒ 满足。
- 于是它**分辨不出**「时滞值已定」与「显式写了个 unknown」——
  **而后者恰好是本批 55 条里的 50 条**（实测：`unknown` 50 · 5 条有值）。
- 换句话说：这条判据**在被测物什么都没修好时也会绿**（只要有人把 `"unknown"` 写进去）。
  ⇒ 它不是判据，是**格式检查**。

**实测证据（main `4a35bd7cc`）**：
```
$ git grep -h '"action_effect_lag"' origin/main -- extensions/ontology/edge-types/ | sed 's/.*: //' | sort | uniq -c
  40 "unknown",      ← 40 + 10 = 50（40/10 的拆分是 CRLF 行尾差异，非两个值）
  10 "unknown",
   2 "3-6_months",
   1 "immediate",
   1 "1_month",
   1 "1-3_months",
```

## 二、提案判据（**待裁**）

### 2.1 主判据：**落在权威枚举内的条数 > 0**

权威枚举（源：权威文档15 第一章 §3.4，**六个值，不含 `unknown`**）：
```
immediate | 1_month | 1-3_months | 3-6_months | 6-12_months | >12_months
```

**可复跑命令（提案原文，待 K3 复核其语法正确性）**：
```bash
# 认为"有值"的定义 = 值严格落在权威枚举内
IN_ENUM=0
for f in $(git ls-tree -r --name-only origin/main -- extensions/ontology/edge-types/); do
  v=$(git show origin/main:"$f" | python3 -c "import json,sys;print(json.load(sys.stdin).get('action_effect_lag',''))" 2>/dev/null)
  case "$v" in immediate|1_month|1-3_months|3-6_months|6-12_months|'>12_months') IN_ENUM=$((IN_ENUM+1));; esac
done
echo "IN_ENUM=$IN_ENUM"      # 期望 > 0
```
**实测现值**：`IN_ENUM = 5`（`immediate` 1 · `1_month` 1 · `1-3_months` 1 · `3-6_months` 2）

### 2.2 分辨力证明（**§三-B 承重**）

| 状态 | `IN_ENUM` | 判据 |
|---|---|---|
| **修复前**（batch0b 合并前，字段整个不存在） | **0** | 🔴 **红** |
| 修复后（`4a35bd7cc`） | **5** | 🟢 绿 |
| **反例：只写 `"unknown"` 不写任何枚举值** | **0** | 🔴 **红** ← 现行判据在这一点上会**假绿** |

⇒ 新判据**分辨得出**「有人只填 unknown」这种形态 —— 这正是它要防的。

### 2.3 附加条款：**未知必须是 `unknown`，不许是 `TBD`**

目的：禁止用不同拼写绕过"未知"的识别。**可复跑**：
```bash
# 非枚举值必须逐字等于 "unknown"
git grep -h '"action_effect_lag"' origin/main -- extensions/ontology/edge-types/ \
  | sed 's/.*: //' | sed 's/,$//' | sort -u
# 输出必须 ⊆ {"unknown"} ∪ 权威枚举；出现 "TBD" / "" / 其他拼写 ⇒ 红
```
**现值**：唯一非枚举值是 `"unknown"` ✅

   **本件只改"判据"，不改"值域"** —— 两件事不要捆在一起裁。

   「W3 时滞 —— **字段已立（55/55）**；**值待标定（50/55 = unknown，5/55 有值）**」；
   #987/#988 的完成度按 **L1 静态（字段存在）**，**不是 L3/L4**。
   ⇒ 本判据只证明「**过程在动**（有真值了）」，**不证明**「时滞已修」。
3. **不提议**同时改 `transfer_function`（W2）的判据 —— 它的现状**不同**：
   `transfer_function` 有**真消费者** `scripts/audit/check-gates-v2.py:858`（Gate 6），
