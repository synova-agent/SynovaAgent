## 三、为什么不复用（R8 展开 + 两条"看起来能复用"的边逐条否证）

### 3.1 能不能复用既有 ontology 边？逐条否证（`#1290` §③-3 点名的三条候选）

| 候选（ontology 侧） | 语义 | 为什么**不能**承载「上级目标 → 子目标」 |
|---|---|---|
| `DECISION_AUTHORITY`（`decision_authority.json`） | 决定**谁有权**分配资源 | 端点 `allowedFrom: ["pool/governance"]` → `allowedTo: ["pool/capital"]`（`decision_authority.json:5-6`）⇒ **端点空间完全不同**，不是"语义不精确"而是**写不进** |
| `SIGNAL_UPWARD_PASS`（`signal_upward_pass.json`） | **信号**向上传递（过滤损耗） | 端点 `external/baseline → pool/sensing`（`:5-6`）⇒ 同上；且语义是"信息通道"而非"目标承继" |
| `INCENTIVE_ALIGNMENT` | **激励**对齐 | 端点与语义均指向"人-激励"，目标承继关系会被读成激励信号 |

**并且**：这三条边**都在运维中的下游清单里**（`edge-consumption-map.json` 的 `consumed_by`）——复用会**改写既有边的语义并连带污染**其消费方；这正是 R8 的理由原文（"**避免污染下游 `consumed_by`**"）。

### 3.2 🔴 新发现：**存在第三套边词表**（`SOG`），且它**已经有 GOAL↔GOAL 的边**

`packages/sog-core/src/sog-core-schema.ts` 是**另一套**（与 `extensions/ontology/edge-types/` **互不相通**的）节点/边词表：

```
$ git show origin/main:packages/sog-core/src/sog-core-schema.ts | sed -n '262,264p'
  [SOGEdgeType.CORRESPONDS_TO]:  { from: [SOGNodeType.EVENT, SOGNodeType.DOCUMENT],                                     to: [SOGNodeType.EVENT, SOGNodeType.DOCUMENT, SOGNodeType.GOAL] },
  [SOGEdgeType.CONSUMES]:        { from: [SOGNodeType.AGENT, SOGNodeType.PROCESS],                                          to: [SOGNodeType.FINANCIAL] },
  [SOGEdgeType.ALIGNS_WITH]:     { from: [SOGNodeType.GOAL, SOGNodeType.TEAM, SOGNodeType.PERSON, SOGNodeType.PROCESS],     to: [SOGNodeType.GOAL, SOGNodeType.TEAM, SOGNodeType.PERSON, SOGNodeType.PROCESS] },
```

**这看起来像"已有 GOAL→GOAL 边"，但四重理由都不能复用**：

1. **语义不同**：`ALIGNS_WITH` 是**对称的一致性对齐**（`alignmentType: 'direct' | 'indirect' | 'conflicting'`，`:212-215`），不是**单向的父子分解**——用对称边表达层级会在查询侧无法区分"上级↔下级"与"同级对齐"。
2. **两套词表不互通**：`SOG` 有自己的 `EDGE_ENDPOINT_MAP`（`:255`）与 `validateEdgeEndpoints`（`:289`）；ontology 侧另有一份（`src/l4/ontology-loader.ts:100-106`、`:137-142`）。`#1290`/`#1316` 的落点是 `graph_triples.predicate`（自由文本）+ ontology 词表，**不是 SOG 词表**。
3. **落到哪张表也不同**：`SOG` 是"节点属性图"口径（`GoalProps.goalType: 'mission'|'vision'|'okr'|'north_star'`，`:123-124`），与 `src/growth/` 的 `Goal` 25 字段体系**不是同一物**。
4. **`SOGNodeType` 有 `GOAL` 但无 `PLAN`**（`:22-39`）⇒ 边 B 在 SOG 侧**根本没有端点**。

⇒ **结论**：`ALIGNS_WITH` 不能复用；但这**必须写进提案**（否则 K3 会问"SOG 不是已经有 GOAL→GOAL 了吗"，而那正是最容易被挑出的第三个问题，见 §九）。
