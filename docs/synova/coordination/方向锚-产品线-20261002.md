## 附一 · 本窗核心：**"能注册"与"已生效"的差距**（院方用我们自己的实测）

| 扩展点 | 实测（院方） |
|---|---|
| 加一个**专家** | 能注册，但 **6/6 全部 `degraded=true`**（`PROMPT.md` 不在扫描清单里） |
| 加一条**边** | 能加，但**写库零校验** —— 实测可写入 `NONEXISTENT_EDGE` 并落库 |
| 加一个**字段映射** | 能加，但 `targetNodeType` 命中率**存疑**（⚠️ 有第二口径，**标【待核】，不得当结论用**） |
| 加一个**循环** | 能加，但 `loadCycles` 在**目录缺失时静默返回 0** |
| 加一个**哨兵** | 能注册 45 个，但 **20/45 根本不查 store** |

> **共同形状：能注册，但没接线；没接线，但不报错。对非技术用户，这是最坏的体验——他以为自己配好了。**

**⇒ 本窗要产出的判据（形态由你定）**：
非技术用户改完，系统必须能用一句话告诉他 —— **「你这条改动，生效了／没生效，因为 X」**。
