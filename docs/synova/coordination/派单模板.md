| 类 | 任务类型 | 下一跳 | 为什么 | 实例 |
|---|---|---|---|---|
| **一** | 产品功能 / 切片（要定接口、契约、数据流、写集） | **先 📋 dev-doc 出 spec（含编码指令）** → 再 🛠 编码实现 | spec 是必须产物，否则编码各写各的 | D577、D556、D-1 通知模型步 2-4 |

**多执行方派单的发送规则（D712 型）**：**都发，但不同时**——
1. 先发**做事方**（并行开工，各自只拿与自己相关的部分，避免互相等）
2. 后发**复核方**（如 K3）——复核的输入物是做事方的产出，早发没意义

**代码归属 ≠ 测试机器归属**：跨平台验证时，按"**谁拥有该目录**"定归属（如 `electron/` = Mac DSH），但"**在哪台机器跑**"按平台定（Windows 实测必须在 Win 机器上跑，由 Win 侧执行但不算 Win 的代码域）。

## 〇-b、命名规范（D940 立，2026-09-24 —— 当天撞号 3 次后固化）

> 立此节的直接事故（`task-state/D940.json` note）：`D921` 卡号被覆盖、`D935` 卡号 + worktree 与他人撞、`D936` 被重复使用。
> 撞名的代价不是重命名：`.synova-wt-squad-b5` 预存在目录无 owner/分支 → `git worktree add` 直接 `fatal: already exists`（撞名第 4 次实例）。

### 1. 三者对应（同一卡号在三个位置必须一致）

| 位置 | 规范 | 正例 | 反例 |
|---|---|---|---|
| **卡号** | `D<数字>`（大写 D；登记文件 `task-state/D<数字>.json`） | `D940` → `task-state/D940.json` | `d940.json`、`D0940` |
| **worktree 名** | `.synova-wt-<侧前缀>-<卡号小写>-<主题>` | `.synova-wt-squad-d940` | `.synova-wt-940`、`.synova-wt-squad-b5`（无卡号） |
| **分支名** | `<type>/<卡号小写>-<主题>` | `fix/d940-name-allocation` | `d940`、`fix/name-allocation` |

- `<type>` ∈ `feat` / `fix` / `chore` / `docs`（铁律 34）；`<主题>` 用 kebab-case，短而具体。
- **卡号在 worktree 名 / 分支名中一律小写**：git 分支名大小写敏感，而 macOS/Windows 文件系统大小写不敏感 → 大小写混用 = 同一实体两种写法 = 撞名隐患。
- **卡号不可改，主题可改**；改主题时 worktree 名与分支名**三处一起改**（只改一处 = 三者失配）。

### 2. 侧前缀（硬性要求，不是装饰）

| 侧前缀 | 归属 | 例 |
|---|---|---|
| `cto-` | CTO 侧发出的卡 | `.synova-wt-cto-d940-<主题>` |
| `squad-` | 小队（Agent Teams）执行的卡 | `.synova-wt-squad-d940-<主题>` |

- **只有这两个前缀**。不存在第三个 —— 要新增由 CTO 裁定并写进本节，**禁自造前缀**。
- 侧前缀的用途是"一眼看出谁发的号"→ **缺侧前缀即不合规**（`.synova-wt-d940` → 退回重命名）。

### 3. 谁发号（禁自起号）

- **唯一发号入口**：`bash scripts/control-tower/alloc-task-id.sh "<任务名>"`（先登记后使用）。**手写号 / 先占号后补登记 = 违规**。
- **跨域由对应侧发**：任务落在另一侧（或另一台机器）的域 → 由**该侧**执行分配器发号，并把号 + 分配器**原始输出**回执给派单方；派单方**不得**自行编号。
- **发号后立即校验**（取号 + 命名两道一起验）：
  ```
  bash scripts/control-tower/check-name-allocation.sh \
    --id D### --worktree .synova-wt-<侧前缀>-d###-<主题> --branch <type>/d###-<主题>
  ```
  退出码三态：`0` = 三者一致且未被占 / `1` = 冲突（**点名冲突位置**）/ `2` = 校验器自身失败（**不得与 0 混同**）。
- 该校验命令的**原始输出**必须贴进下面两处（本模板自带的两道清单）：
  - 「写前核实 ⑤ 写集重叠检查」
  - 「写后自检 ② D# 未占用」
