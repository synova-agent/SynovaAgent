# 哨兵体系 / 信号与观测 — 模板骨架 + 本类默认值

> **路由依据**：README §〇 —— 哨兵域改动按同一把尺子归类：**切片/架构型 ⇒ 类一（先 dev-doc spec）**；**根因清楚的缺陷/治理型 ⇒ 类二（直接派）**；**纯实测取证 ⇒ 类三**。
>
> **本类默认值**：
> - 归属：哨兵适配器 `extensions/sentinels/`（文件驱动）+ `src/sentinel/`（Runner / SignalAggregator / Registry）；数据流 = 定时 Cron → `Sentinel.check()` → Finding → 专家 → 工单
> - 必答（三问加严）：① 消费者是谁（哪个进程真的读它）② 在哪一层/哪个文件（读取点给 `file:line`）③ 用哪条命令证明**它在跑**
> - 验收：真实数据流走通（**禁** mock 管线，铁律 12）+ compute 契约（铁律 47）+ 三路径测试（铁律 48）
> - 写集：一个哨兵 = 一个目录（manifest / tags / compute 成一个整体）；**不碰**无关哨兵目录与 `scripts/audit/`
>
> 下方骨架**逐字沿用** `派单模板.md` 原文（零改写）；分册间差异只在上方本类默认值。
