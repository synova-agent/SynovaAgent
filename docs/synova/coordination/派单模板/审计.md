# 类三 · 验证 / 证据 / 审计 — 模板骨架 + 本类默认值

> **路由依据**：README §〇 路由判定表 **类三**「验证 / 证据（不是"实现什么"，而是"去实测并落盘证据"）」→
> 下一跳 = **直接派执行方，无 spec**；实例 = **D712 桌面端重验**。
>
> **本类默认值**：
> - 多执行方（D712 型）：**都发，但不同时** —— ① 先发做事方（并行开工，各自只拿与自己相关的部分）② 后发复核方（K3）——复核输入物是做事方产出，早发没意义
> - 跨平台：**代码归属 ≠ 测试机器归属**（`electron/` = Mac DSH；Windows 实测必须在 Win 机器跑，由 Win 侧执行但不算 Win 的代码域）
> - 交付：证据落 `docs/synova/product-lines/evidence/<任务号>/`，每条断言贴**命令原始输出**（禁 `head`/`tail` 截断断言）
> - 验收：判别性（「删掉即报红」）+ 反证优先（与声称不符 ⇒ 明写「不通过（附原始输出）」，不替执行方辩护）
> - 红线：不改 `scripts/audit/**`、不写审计标准、禁自我审计（审计结论只认 K3 报告）
>
> 下方骨架**逐字沿用** `派单模板.md` 原文（零改写）；分册间差异只在上方本类默认值。
