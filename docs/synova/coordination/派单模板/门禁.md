> 下一跳 = **直接派执行方**（DSH 域内可派并行 CTO；🛠 编码）；实例 = D706 / D707 / D664 / D708。
>
> **本类默认值**：
> - `scripts/` 门禁 + coordination 文档 + 预设技能 = **Mac DSH 专属**（TASK-ROUTING §四）；派单文档本身即准 spec，再走 dev-doc 是空转
> - 写集：逐文件（含 `tests/control-tower/<name>.test.sh` + `tests/control-tower/<name>.test.py`）；**不碰** `src/` 产品代码 / `scripts/audit/` / `docs/synova/audit-reports/`
> - 验收：三态退出码（0 通过 / 1 业务阻断 / 2 检查失败=同样阻断）+ **「删掉即报红」判别性夹具**（禁 grep 型静态判据当验收）
> - 共享治理件：改动前查 `写前核实 ⑤` + `派单前置 owner 在飞检查`；**热点文件（`ci.yml` / `scripts/pre-commit-check.sh` / `ownership.yaml` / `派单模板.md`）永远单写者**
> - 并发：重型验证（vitest / 全量门禁 / 黄金门禁）**串行 ≤1**
>
> 下方骨架**逐字沿用** `派单模板.md` 原文（零改写）；分册间差异只在上方本类默认值。
