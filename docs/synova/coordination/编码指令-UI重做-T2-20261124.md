## §4 关键契约

1. **纯 CSS 批**：只改 `electron-renderer/src/styles/global.css`；**不得**改 `.tsx/.ts`。
2. **令牌优先**：新增颜色必须走既有 CSS 变量（`:root` / `.theme-light`），**不写裸色值**（除 `color-scheme` 关键字）。
3. **两态都要对**：深色与浅色主题下都不得出现白盒孤岛或不可读正文。
4. **`color-scheme` 必须声明**，且两态取值合法（深色 `dark`、浅色 `light`；若用单值须说明理由）。
5. 新增自定义属性按铁律 47 在 CSS 顶部注释用途与两态取值。

## §11 变更理由（为什么是纯样式批，不是"白盒+窗口"）

v1 卡把「白盒」「正文可复制」「排版不塌」「窗口最小尺寸」塞成一批，被复核判为**切片不实**（铁律 1／`squad-discipline` §八.21：按用户可见行为切片、每片独立可验收可回退）。且窗口参数在另一个文件、另一个用户动作（拖窗口）。
