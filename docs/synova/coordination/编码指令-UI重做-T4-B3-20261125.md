## §4 关键契约

1. **词典单一真源**：所有映射进 `lib/words/`（如 `index.ts` 导出 `t(key)` 与常量表）；**组件不得内联硬编码中文映射表**。
2. **不改数据形状**：`interface`/`type` 不改；`dsh-run-store.ts`/`contracts.ts` 不碰（契约 §3.3）。
3. **不改真值语义**：`outcomeStatus` 等状态位**不由前端推断**（契约 §2.1）；本批只改文案。
4. **错误文案四要素**：人话原因 ＋ 影响面 ＋ 下一步 ＋（技术详情入口），见 §5.6/§5.1。
5. **豁免只作用于判定层**：`ESC`/示例邮箱/示例 URL 不改词，只在 allowlist 记「§2.7-G 豁免」。
