## §3 目标行为

1. **可见控件**：`TitleBar` 左侧出现「收起/展开」按钮（图标 + `aria-label` + `aria-expanded`），**收起后仍在原位置可见**（这是 B2 的核心：不能"收起来就找不回来"）。
2. **一键两态**：同一个 action 同时被按钮与 `Ctrl+B` 调用（**不得两套逻辑**）。
3. **宽度过渡**：收起后内容区宽度增加（≥ 收起前后差值），过渡 ≤ 200ms；`prefers-reduced-motion` 时不动画。
4. **状态保持**：重启/切视图后保持上次收起态（persist 到 `app-store`，只 UI 状态）。
5. **死项清零**：`TitleBar` 的假按钮与 `ExpertAttribution` 的死项**删除**（铁律 37），不留空壳。
6. **可访问性**：键盘可达（Tab → Enter/Space），`aria-expanded` 随状态变化。
