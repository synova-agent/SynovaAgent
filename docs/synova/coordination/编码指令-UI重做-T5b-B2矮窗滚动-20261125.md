  - 若必须动 `global.css` 的 `.panel-left{overflow:hidden}` 才能实现 ⇒ **停**（见 §7 停点 2），先报 CTO
- **明确不做**：不改导航项/分组/文案；不改 `app-store`；不改数据形状
- **验收入口**：真机 1000×500 下滚动 + 点击

## §3 目标行为

1. `1000×500` 外框下，左栏内容区**可纵向滚动**（`scrollHeight > clientHeight` 且能滚到底）。
2. 滚到底后「本次分析」入口**完整可见**（`getBoundingClientRect().bottom ≤ 面板可视底`）。
3. 该入口**可点击并触发导航**（真实点击，不是只判可见）。
4. **展开态（1280×800）零视觉变化**：不出现多余的滚动条、宽度不变。
5. 焦点可达（Tab 能进入左栏并滚动，`scrollIntoView` 生效）。

---

## §4 关键契约

1. **只改组件**：优先在 `LeftPanel` 内部建立滚动容器（内联样式或已有类），**不改 `global.css`**。
2. 不改导航项的结构、顺序、文案。
3. 滚动不应破坏 B2 已有的收起/恢复与状态持久（收起后滚动条消失属正常）。
