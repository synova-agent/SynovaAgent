## §1 模块锚（九项之①）

- **模块**：旧网页版（D96）的退场
- **服务的真实客户／用户动作**：客户**打开 Synova**（桌面客户端）
- **本批完成后用户能做什么**：不受影响地继续用桌面端；同时**不再有人被文档或误启动带到那个登不进去的旧界面**
- **与闭环的关系**：这套界面在浏览器里**根本登不进去**（契约失配＋密码框 `disabled`），却仍被 3 份部署文档写成"客户第一步"、被 Electron 回落路径当作兜底 ⇒ 它是**活的误导源**
- **长期边界**：退役后**只有一个客户界面**（Electron renderer）＋**一个登录面**（`DshLoginPanel`）
- **写集（全部逐个明列，禁止目录级通配）**：见 §3 的 34 文件表 ＋ §4 的 7 个消费者文件 ＋ §5 的 3 份文档
- **明确不做**：不改 `/api/auth/login` 等 API 契约；不改 `electron-renderer/**`；不改 `DshLoginPanel`；不改 `scripts/audit/**`；不删 `docs/**` 下任何历史件
- **验收入口**：`/`、`/login`、`/app/*` 全部不可达；桌面端正常
- **尚未确认**：无
