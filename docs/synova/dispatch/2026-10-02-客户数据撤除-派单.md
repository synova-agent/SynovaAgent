### 3.1 生成路径清单（**两条来源都要**）

```bash
# ① 路径名命中（当前树 + 全历史）
git -C D:/synova-backup.git log --all --pretty=format: --name-only --diff-filter=ACMR \
  | sort -u | grep -F -f keywords.txt > paths-by-name.txt
# ② 内容命中（当前树快筛；历史由 filter-repo --replace-text 承接）
git grep -l -f keywords.txt origin/main | sed 's/^origin\/main://' > paths-by-content.txt
cat paths-by-name.txt paths-by-content.txt | sort -u > paths-final.txt
wc -l paths-final.txt      # 预期 ≳ 167
```

### 3.2 重写

```bash
pip install git-filter-repo
# ② 路径级：从**全历史**删除这些路径
git -C D:/synova-backup.git filter-repo --force \
  --paths-from-file ../paths-final.txt --invert-paths
# ③ 内容级：在剩余历史里把客户名替换为中性占位（replace.txt 每行 <原文>==><替换>）
git -C D:/synova-backup.git filter-repo --force --replace-text ../replace.txt
```

### 3.3 推送（**这是不可逆点**）

```bash

# ❌ 不要：git push --mirror（会删掉远端不在本地镜像里的 ref）
```
