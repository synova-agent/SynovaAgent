## 根因 2 🔴 `DOCS-REGISTRY.yaml` 与 `bypass.log` 同型，但缺 `merge=union`

# 【派单 B】给 K3 · D# 推断缺陷（送审）

> **形态**：K3 独立复核（**我不是终审**）。**本件所有证据都可复算。**

## 一句话

`scripts/control-tower/merge_writeset_gate.py` 的 **D# 推断**会被**人手写的 merge 提交主题里的"外部卡号"**带偏 ⇒
**声明写集解析成另一个任务的** ⇒ 合法文件被判"夹带" ⇒ **fail-closed 阻断**（门禁**拦错了对象**）。

## CI 实测（原始输出）

```
❌ 结论: block — 检测到 14 个写集外文件（夹带）
   任务: D1109 | 分支: docs/govl-line1-anchor
   D# 推断来源: commit-subject → D1109
   声明写集 6 条:
     · scripts/control-tower/simulate-ci.sh            ← 这是 #939(D1109) 的写集
     · tests/control-tower/simulate-ci.test.sh         ← 同上
     · .claude/task-briefs/2026-10-02-D1109-…          ← 同上
     · task-state/D1109.json                          ← 同上
     · memory/notes/implemented/2026-10-02-d1109-…    ← 同上
   夹带文件 14 个
```
（取值层级：**job 级**；job id `110727163972`，run `36971814159`）

## 判别性对照（**能证伪**）

在**治理线支的 checkout** 里跑（`git worktree add --detach <tmp> 48b48c6ad`）：
```
--did D1112  ⇒  ✅ pass — 提交文件集 ⊆ 声明写集（无夹带）
默认（不传）  ⇒  ❌ block — 14 件夹带
```
⇒ **判别成立**：**差别只在 D# 推断**。

## 机制（读源码得到）

`merge_writeset_gate.py`：
```
DID_RE = re.compile(r"(?<![0-9a-fA-F])[Dd]\d+(?![0-9a-fA-F])")     # :181 任意位置抠 D#
推断顺序：⓪ --did 显式 → ① 分支名 → ② 向前遍历提交 subject          # :269
三条"跳过"规则：^Merge <sha> into <sha>$ / ^Merge pull request # … / "bypass COMMITTED 登记"
```
⇒ 治理线那条**人手写的** merge 主题：
`merge: 并入 origin/main（#939 D1109 simulate-ci 缩量）—— 解 bypass.log 追加冲突`
**三条跳过规则都不命中**（不是 VCS 合成主题）⇒ 抠出 `D1109` ⇒ **赢了它自己的 D1112**。

## 影响面

**任何"分支名不含 D# + 人手 merge 主题里提到别的 D#"组合都会中** ⇒ 该支的**全部合法文件被判夹带**。

## 请 K3 判的三问

1. 这条阻断**误判是否成立**（我的判别实验是否足够）
2. 修法应取哪种：**① 只认规范式 `^type(D####)`** ／ **② 不把 merge 主题里的"提及"当自己** ／ **③ 其他**
3. 是否需**回退**受它影响的已合并件（若有）

**最小抽验面**：在任一含"人手 merge 主题带外部 D#"的支上跑一次默认参数与 `--did` 对照。
