三、8(a) 判定（§7 C 判据：自启成功 + 退出后回收 两段都成立才算 PASS）
--------------------------------------------------------------------------------
自启成功段：**成立** —— `[electron] boot mode=dev` → 后端被 Electron 拉起（18790 owner = node.exe）
            → `GET /api/healthz` **HTTP 200**（boot 2.4s，body 见 C-8a-result.json.healthz）
            → console 无 `后端自启 degraded` / 无 `spawn 失败`；启动前 18790 无 LISTENING ⇒ 不是 reused。
回收段：    **成立** —— CDP `Browser.close` → Electron 退出（exitCode=0）→ 后端 pid 消失
            → 18790 `LISTENING pid = null` → 无 `src/index.ts` 残留进程。

进程链实测（C-8a-transcript.txt §7 C.3）：
    4320 node.exe（后端本体，监听 18790）            ← Electron 的**孙**进程
    └─ 2920 node.exe（tsx CLI 再 exec 的一层，Electron 的直接子进程）
       └─ 17552 electron.exe（Electron 主进程）
⇒ §7 C.3 的表述「该 PID 父进程 = Electron」在实现上对应"**直接子进程**的父 = Electron"：
  tsx CLI 会再 exec 一层 node，所以监听 18790 的那一个是孙进程。判据按"链回到 Electron"取
  （parentChainReachesElectron），比"直接父子"更真实。stop() 用 taskkill /T 回收整棵树，实测已回收。

四、「dev 里没有 Electron-ABI 原生模块」——可复算证据
--------------------------------------------------------------------------------
dev 的 node_modules 由 `npm ci`（系统 Node）安装，原生模块是**系统 Node ABI**；
Electron ABI 的同一模块**只在打包产物里**被造出来：

  · build-synova.cjs:69-73   打包钩子内才 `prebuild-install -r electron -t <electronVersion>`（better-sqlite3）
  · build-synova.cjs:143-147 注释明写 CI 用 `npx @electron/rebuild -f -w better-sqlite3`（"electron-v130 预编译"）
  · build-synova.cjs:170-172 "electron-builder 打包前会把项目 node_modules 原生模块 rebuild 为 Electron ABI，
                             此处复制即 ABI 一致（包内 Electron node 模式执行）"

实测（C-runtime-abi-transcript.txt，可复跑 `node …/verify-runtime-abi.mjs`）：
  · electron.exe + ELECTRON_RUN_AS_NODE=1（Electron 33 的 node v20.18.3，modules=130）
    → require('better-sqlite3') = **ERR_DLOPEN_FAILED**（模块按 modules=137 编译）
  · 系统 node.exe（v24.16.0，modules=137）→ require('better-sqlite3') = **OK**
  · 同一 argv 起真实后端：系统 node ⇒ /api/healthz **200**；electron-as-node ⇒ 进程带 ERR_DLOPEN_FAILED 退出

⇒ 复算命令（任一）：
    node docs/synova/product-lines/evidence/1456-dev-self-start/verify-runtime-abi.mjs
    git show HEAD:build-synova.cjs | Select-String -Pattern "prebuild-install -r electron|electron ABI|npmRebuild"
