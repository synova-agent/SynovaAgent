## 0. 交付面与契约

| 件 | 路径 | 说明 |
|---|---|---|
| 回环 HTTP MCP | `src/mcp/http.ts` | Streamable HTTP（stateless），只监听 `127.0.0.1:<随机端口>`；`POST /mcp` |
| 工具面 | `src/mcp/tool-definitions.ts` | `SIDECAR_TOOLS` 只含 1 个只读工具 `synova_context_get`；`assertSidecarToolAllowed(name, mode)` 复用 `McpError` 语义 |
| 数据面 | `src/runtime/dsh/tools.ts` | 合成 `ContextSnapshot`（②/③/④ 三条）、参数白名单/伪造拒绝、一次性 token 存储 |
| 独立 golden | `tests/runtime/dsh/fixtures/synova-context-get.json` | 期望值来源，不从被测输出反推 |
| 测试 | `tests/runtime/dsh/readonly-tool.test.ts` | 8 个用例（MCP 客户端真实连接） |

**强制只读的唯一声明点**：`src/mcp/http.ts` 的 `const SIDECAR_MODE: McpMode = 'read-only'`；`tools/list` 用 `filterToolsByMode(SIDECAR_TOOLS, SIDECAR_MODE)`，`tools/call` 先过 `assertSidecarToolAllowed(name, SIDECAR_MODE)`。

**身份注入**：每个 run 由路由签发一次性 token（`ToolTokenStore`，绑定 `enterpriseId/userId/scope/runId`，默认 TTL 10 分钟，run 终态即撤销）；工具入参 schema 不含任何身份字段；出现 `enterpriseId/userId/orgId/scope/evidenceId` ⇒ `FORGED_IDENTITY`，出现 `path/cwd/dir/root/...` ⇒ `FORGED_PATH`。

**输出**：`content[0].text` 为 JSON，至少含 `layer/$id/cycleVersion/sentinelRun/period/defVersion/evidenceId/status/visibility/source` 与 `count`。
