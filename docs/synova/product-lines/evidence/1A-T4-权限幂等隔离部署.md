## 4. 部署脚本（合成目录实跑，不实机回滚）

在 `%TEMP%\1a-deploy-synthetic`（合成 home/sessions/storages + 仓库 profile）实跑：

```
CMD=powershell -File scripts/dsh-sidecar/backup.ps1 -DshHome <synthetic>/home -BackupDir <synthetic>/backups
EXIT=0
{"code":"BACKUP_OK","files":6,"verified":6,"ok":true,"target":"…\\backups\\synova-sidecar-20261115-102845"}

CMD=powershell -File scripts/dsh-sidecar/restore.ps1 -BackupDir <backup> -TargetDshHome <synthetic>/restore-home
EXIT=0
{"code":"RESTORE_OK","files":6,"verified":6,"ok":true}

CMD=powershell -File scripts/dsh-sidecar/rollback.ps1 -DshHome <synthetic>/home -PreviousInstallDir <installed rc.1 dir>
EXIT=0
{"code":"ROLLBACK_OK","previousInstallDir":"C:\\Users\\Administrator\\AppData\\Local\\Programs\\DeepSeek Harness","ok":true}

VERIFY restoredSession={"synthetic":true,"session":"s1"}
VERIFY pointer=…\\Programs\\DeepSeek Harness
```

脚本纪律：

- `backup` 复制 `profiles/sessions/storages/run` 并写 `manifest.json`（相对路径+bytes+sha256），**逐文件复核**；源目录缺失/校验失败 exit 1；默认生产 home 需 `-AllowProduction`，否则 exit 2；
- `restore` **先校验 manifest 再落盘**；目标有存活 supervisor ⇒ 拒绝（`RESTORE_SIDECAR_RUNNING`）；恢复后再次逐文件校验；
- `rollback` 只写 `<DshHome>/install-dir.txt` 指针（校验目标目录含 `DeepSeek Harness.exe`、supervisor 不在运行），**不安装/不停进程/不碰真实安装**。
