## 3. 选择器新增 `--shard <i>/<n>`

- 语义：在既有「选择集」之上做分片过滤（与 `--platform` 正交）；
- 映射表声明分片总数 `shards.count`；`--shard n` 与映射表不符 ⇒ 显式 degraded + 全量回退；
- **参数校验 fail-closed**（不静默给空）：`4/3` 越界 → exit 2；`abc` 非数字 → exit 2；`1`（缺 `/n`）→ exit 2；
- 分片内 0 选中 ⇒ stderr `[D1061-SHARD] … selected_in_shard=0` + CI `::notice`（**显式可见，非静默跳过**）；
- `--list` 增列 `SHARD <id> :: <suite>` 与 `SHARDKEY count <n>`（可核派生）。

## 4. ci.yml 接线

```yaml
matrix:
  os: [ubuntu-latest, windows-latest]
  shard: [1, 2, 3]
  exclude: [{os: ubuntu-latest, shard: 2}, {os: ubuntu-latest, shard: 3}]
name: Control Tower Gate Tests (${{ matrix.os }}${{ matrix.os == 'windows-latest' && format(', shard {0}/3', matrix.shard) || '' }})
```
- **ubuntu 保持单分片且 job 名不变** ⇒ 必需检查 `Control Tower Gate Tests (ubuntu-latest)` 不受影响；
- windows 变为 3 个 job：`(windows-latest, shard 1/3)` / `(2/3)` / `(3/3)`；
- windows 选择 = `--changed … --platform windows --shard <i>/3`（子集 ∩ 本分片）。
