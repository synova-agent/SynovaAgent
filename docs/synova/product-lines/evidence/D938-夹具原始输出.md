### 1.1 全角标点危害矩阵（bash 3.2.57 = macOS /bin/bash = 控制塔实际执行环境）

逐字符实测 `set -u; FOO=bar; echo "$FOO<c>"`：命中 `unbound variable` = 该字符被 bash 当作变量名字符。

```
$ bash --version | head -1
GNU bash, version 3.2.57(1)-release (arm64-apple-darwin25)
$ for c in （）：，。；、) ; echo "set -u;FOO=bar;echo \"\$FOO$c\"" | bash ; done   # 逐字符
  全角 （ → rc=1 （unbound：真危害）
  全角 ） → rc=1 （unbound：真危害）
  全角 ： → rc=1 （unbound：真危害）
  全角 ， → rc=1 （unbound：真危害）
  全角 。 → rc=1 （unbound：真危害）
  全角 ； → rc=1 （unbound：真危害）
  全角 、 → rc=1 （unbound：真危害）
  ASCII ) → rc=0 （无害，对照组）
  ASCII : → rc=0 （无害，对照组）
  ASCII , → rc=0 （无害，对照组）
  ASCII . → rc=0 （无害，对照组）
  ASCII ; → rc=0 （无害，对照组）
$ 非 set -u 时的静默吞字（字节级）: FOO=bar; echo "[$FOO）]" | od -c
0000000    [ 274 211   ]  \n                                            
0000005
   → 输出 [ BC 89 ] = 全角「）」剩后 2 字节：首字节被 bash 当变量名吃进 → 文本损坏（无 set -u 也坏）
[exit code: 0]
```
