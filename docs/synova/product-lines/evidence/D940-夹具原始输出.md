## 7. 夹具设计要点（为什么这样写才对得上契约）

1. **密封性**：全部用 `mktemp -d` 临时 git 仓 + **本地 bare 仓当 `origin`**，离线、不连真网、
   不依赖真仓 tracking ref（真仓当前**有** `origin/docs/d942-cto-fixation`，"未 fetch"在真仓**不可复现** ——
   与 c1 独立实测同结论）。
2. **判别性（旧实现下必红）**：每条新断言都钉住"发放了被占号"或"没点名冲突位置"这两个旧行为；
   §8.1 给出改前基线的 5 条红。
3. **接口口径**：与 c1 逐条对齐后写（拒绝语义=rc≠0+逐字点名；5 个位置标签；
   rc=2 三触发条件；`degraded:` 字面量；`--json` 键形）。夹具只钉**契约**，不反向猜实现。
4. **防空转**：金丝雀 = 同一夹具只改 id，占用必须 rc=1、空闲必须 rc=0；两者相等即"恒返回同一值"= 红。
   另有两处**夹具前置自校验**（`branch -r` 看不见 d942 + `ls-remote` 看得见 + worktree 已登记），
   构造失败即红，不让后续断言空转。
