## 五、与 c2 的接口契约（6 条，已对齐并落地）

`拒绝语义`（rc≠0 + 逐字点名，绝不自动跳号）｜`点名形式`（短名 + 全 ref 同行，可 `grep -F`）｜`远端读法`（`git -C "$TS_TOP" ls-remote --heads origin`）｜`注入缝不新增`（`SYNO_ALLOC_NO_BRANCH` 关整族分支名、`SYNO_ALLOC_NO_WORKTREE` 关 worktree 族；降级不吃缝）｜`rc=2 触发条件`（无参 / `--id` 非法 / 选项缺值 / 未知选项 / 委派脚本缺失）｜`degraded:` 字面量。

**c2 抓到的返工（已修，不掩盖）**：`--json` 的 `conflicts[]` 曾把 `ls-remote` 原始行（含 sha+tab）塞入且括号内重复。**根因在 alloc 侧**：漏取 `ls-remote` 行的第 2 字段（`<sha><TAB><ref>`），`short=${ref#refs/heads/}` 对整行不生效。修法：`ref_name="$(... | awk '{print $2}')"` + `--json` 元素按契约剥 ` (全 ref)` 后缀。**此前的短名匹配是"原始行恰好含短名"的侥幸通过**——同属假绿面，已加注释留痕。
