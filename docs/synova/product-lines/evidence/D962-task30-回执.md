**Windows 差异说明（平台方言 + 路径）**：
- **G10**：内联 python 用 `open('$CRITERIA_MAP')`，而 `$CRITERIA_MAP` = `$(git rev-parse --show-toplevel)/…`
  是 **Git-Bash POSIX 路径**（`/d/a/…`）→ **原生 Windows python 打不开** ⇒ JSON 读取抛异常（被
  `except Exception: pass` 吞）⇒ glob 集空 ⇒ G10 走"无映射跳过" ⇒ 红分支不触发。（macOS/Linux 的 python 认 POSIX 路径 ⇒ 本机绿。）
- **G12**：`glob.glob()` 在 Windows 返回**反斜杠路径** ⇒ 后续 `[ -f "$B" ]`（Git Bash 内建）失配 ⇒ 集空。
- **修**（写集内）：① 新增 `_TO_PY()`（`cygpath -w` 转换，**无 cygpath 的平台原样** ⇒ macOS/Linux 行为不变），
  凡把路径喂 python 一律经它（G10 criteria-map 改用 **env 传参**，避免反斜杠被当转义；G12 的 `SCOPE_TSV/EXCL_TSV` 同）；
  ② G12 窗口 python 输出归一化 `f.replace(os.sep,'/')`。
**本地验证**：`g10-cp3` PASS ｜ `g12-day-window` PASS（14/0）｜`ct-test-gate` PASS ｜ CI 口径整跑 `rc=0 stderr=0`。
