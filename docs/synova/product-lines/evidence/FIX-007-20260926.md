## 4. 顺带修正（同一行内的显示缺陷）

修前零命中时输出 `绕过检查: 00 次`（`grep -c` 无匹配 exit 1 + `pipefail` ⇒ `|| echo 0` 追加第二个 0 → "0\n0" → 去非数字后 "00"）。
修后改为 `$(grep -c PATTERN "$LOG" 2>/dev/null || true)`（`grep -c` 自带的 "0" 即结果，不再叠加）⇒ 输出 `绕过检查: 0 次`（数字比较行为不变）。
