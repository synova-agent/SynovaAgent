### 口径 A —— 「代码具备采集通路的表」（**机械可判**，推荐作为默认口径）

> **表 T 是采集表 ⟺ `src/**/*.ts`（排除 `*.test.ts`）中同时存在**
> **① `CREATE TABLE [IF NOT EXISTS] T` 且 ② `INSERT [OR REPLACE|OR IGNORE] INTO T`。**

```bash
# 复跑（一行）
cd <repo> && DB=<DB>; for t in $(sqlite3 $DB "SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE '%fts%' ORDER BY name;"); do \
  d=$(grep -rl "CREATE TABLE IF NOT EXISTS $t\b\|CREATE TABLE $t\b" src/ --include="*.ts" | grep -vc '\.test\.'); \
  i=$(grep -rl "INSERT INTO $t\b\|INSERT OR REPLACE INTO $t\b\|INSERT OR IGNORE INTO $t\b\|REPLACE INTO $t\b" src/ --include="*.ts" | grep -vc '\.test\.'); \

  echo "口径A = $(wc -l < /tmp/kj-A.txt) 张"
```
