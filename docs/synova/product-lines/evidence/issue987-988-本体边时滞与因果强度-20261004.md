### 1.5 ⚠️ 夹具 D 顺带暴露的**存量缺陷**（不在本卡写集，仅登记）

夹具 D 让 `augments.json` JSON 语法坏掉后，**生产装载器静默丢弃该边类型**，且 **`degraded` 仍为 `false`、`errors` 仍为空**：

```
EDGE_TYPES_LOADED=54
DEGRADED=false          ← 应为 true
ERRORS=[]               ← 应为非空
```

根因：`src/l4/ontology-loader.ts:52-62` 的 `readJSON()` catch 里只 `log.warn` 后 `return null`，退化信号**未回传**给
`loadOntology()` 的 `degraded`（注释自称"跳过损坏文件"）。⇒ 违反**铁律 11/31（降级信号传播）**。

**本卡不修**（`src/l4/ontology-loader.ts` 不在写集）。**登记为独立缺陷，请产品线决定是否立卡。**
