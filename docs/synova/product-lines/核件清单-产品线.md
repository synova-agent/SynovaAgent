## 二、判据类

| # | 条款 | 命令 | 事故样本 |
|---|---|---|---|
| **D1** | **判据必须能改坏即红**：命令本体要有 `exit 1`，`echo` 读数**不算判据** | 造坏值 ⇒ 脚本须 `exit≠0` | #1138 v1 的 `echo "IN_ENUM=$IN_ENUM"` **永远 exit 0**（K3 P1-9） |

## 三、抽取-实跑（D2 的可复跑骨架）

```bash
# 从文档里抽出第一个 ```bash 块并实跑（fence 定位，不用脆正则；本窗口正则已栽一次）
extract() { python3 - "$1" "$2" <<'PY'
import sys
s=open(sys.argv[1],encoding='utf-8').read()
i=s.find(sys.argv[2]); j=s.find('```bash', i); k=s.find('\n```', j)
print(s[j+7:k] if (i>=0 and j>0 and k>j) else 'echo EXTRACT-FAILED; exit 9')
PY
}
extract <doc.md> '<marker>' > /tmp/chk.sh
bash /tmp/chk.sh <good-ref>   # 须 exit 0
bash /tmp/chk.sh <bad-ref>    # 须 exit ≠0
```
