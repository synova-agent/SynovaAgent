## 一、决策矩阵模板（第一章交付物定义）

| 信任来源维度 | 具体表现 | 演示如何强化 |
|---|---|---|
| 同行案例 | 结构同构的真实企业（客户A） | 三层共鸣第二层演绎 + 共性时刻 |
| 数据证据 | 实时诊断、证据链、42 边因果 | 六阶段 SSE + 报告证据链 |
| 专家/权威 | 方法论出处（第一性原理） | 通用循环开场 |
| 现场体验 | 亲自触发诊断、看数据变化 | 互动环节 |
| 安全可信 | 本地部署/权限/脱敏 | 脱敏演示 + 数据边界话术 |

| 威胁因素维度 | 具体表现 | 演示如何规避 |
|---|---|---|
| 准确性质疑 | "你怎么知道是对的" | 预埋黄金数据集/交叉验证 |
| 数据安全 | "我的数据会不会泄露" | 脱敏演示 + 本地部署 |
| 行业适用 | "我那个行业能用吗" | 跨行业翻译 + 行业模板切换 |

## 二、迭代协议

```
画像初稿 → 信任假设 → 剧本初稿 → 三刀挑战 → 画像修正 → 信任修正 → 剧本定稿
     ↑___________________________|（每章回补环）
```

规则：每章产出后执行"回补检查"——若本章发现画像/信任假设缺陷，更新第一章并记录 v2 版本，禁止线性推进。

## 三、信任决策曲线模板（第二章使用）

| 分钟 | 观众状态（怀疑/好奇/将信将疑/信任） | 判断信号 | 应对策略 |
|---|---|---|---|
| 0-3 | 怀疑（"又一个工具"） | 开场是否点头 | 共性时刻1 + 稻盛语境锚定 |
| 3-10 | 好奇（"阿米巴还能这么用？"） | 是否共鸣 | 通用循环 + 阿米巴数字化桥接 |
| 12-18 | 将信将疑（"和咨询有什么区别"） | 是否认同咨询经历 | 咨询后遗症识别 + 差异对比 |
| **25（检查点1）** | 将信将疑→信任 | 是否提问/看手机 | 信任→保持；怀疑→跳中间进报告 |
| 30-42 | 信任（"这能用在我这"） | 是否对号入座 | 报告+脱敏+跨行业翻译 |
| **45（检查点2）** | 信任巩固 | 冷场与否 | 冷场→加强互动对号入座 |
| 56-60 | 行动（"一对一聊什么"） | 是否登记预约 | 一对一钩子 + 资料包 |
