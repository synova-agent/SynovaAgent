# B线 盛和塾演示叙事研究 — 研究方案 v1.3 FINAL

> 2026-08-01（v2 修订：60 分钟）| 定位：把"产品能做什么"翻译成"全场老板 60 分钟内信什么"，产出三层共鸣演示剧本、三刀预埋与应答、数据脱敏与对话式控制评估、P0-block/risk 终判、双预案物料包

---

## 零、研究背景

1. **演示性质**：盛和塾 8 月演示是产品首次面向真实目标客户的"信任考试"
2. **观众假设（待验证）**：广东地区，产销一体、外贸型企业较多，产值 5000 万–5 亿区间（创始人猜测，第一章画像验证环节确认）
3. **观众构成**：现场可能跨行业——演示必须让绝大多数老板感同身受（第一性原理：资源投入→经营产出→价值回流→溢出利润的循环对任何行业成立，只是运行方式不同）
4. **案例资产**：客户A=产销一体+几百家月子中心 B2B2C 渠道+免费引流转化+按单生产交付的完整样本——与观众**结构同构**（行业不同、结构相同），是证明"方法论通用"的最强素材
5. **A 线证据**：主链路走通（SSE 六阶段诊断→四层报告→仪表盘）；GA 验证、进化、黄金数据集门禁、报告素材四大缺口待演示定级
6. **数据边界需求**：演示案例为真实企业，核心数据必须对第三方脱敏；创始人希望"通过对话控制输出边界"（如"我在给第三方演示，把核心财务数据隐掉"）

## 一、研究问题

- **Q1 信任决策**：这类创始人凭什么信一个系统？哪些证据类型强化信任、哪些因素摧毁信任？
- **Q2 剧本**：60 分钟（创始人确认）如何设计成"三层共鸣"（通用循环共识+阿米巴语境→案例演绎→跨行业对号入座）？如何让中途入场者 30 秒内建立上下文？
- **Q3 三刀**：会被问的最尖锐问题是什么？如何在提问前把答案预埋进演示？
- **Q4 数据边界**：客户A演示数据如何脱敏？"对话式控制脱敏"现状、缺口与可行性？
- **Q5 缺口**：演示触达功能点中，哪些 P0-block、哪些 P0-risk、哪些 P1？
- **Q6 结构同构**：客户A（母婴产销一体）如何桥接外贸制造观众？跨行业共鸣机制如何落地？

## 二、定位与边界

**做什么**：迭代式三层共鸣剧本、三刀预埋与应答、数据脱敏与对话式控制评估、P0-block/risk 终判、演示物料包与双预案、决策矩阵（画像）。

**不做什么**：新功能实现（含对话式脱敏实现——只评估需求与可行性，转交 Dev Doc）、定价决策（标注"需创始人确认"）。

## 三、研究方法（核心升级项）

1. **迭代协议**：`画像初稿→信任假设→剧本初稿→三刀挑战→画像修正→信任修正→剧本定稿`。每章完成即回补第一章，多轮迭代，禁止返工式线性推进
2. **决策矩阵交付物**：第一章"画像"= 矩阵（信任来源 × 威胁因素）+ 行业适配维度（广东产销一体/外贸/5000万-5亿）；第二章每环节标注强化/规避
3. **三层共鸣设计**（剧本主线）：通用循环共识层（池-阀-流-溢出+五断裂点开场）→ 客户A演绎层（结构同构案例）→ 跨行业翻译与对号入座层（翻译句机制+共性时刻）
4. **共性时刻机制**：3–5 个任何行业老板都有的画面（订单波动/客户集中/回款账期/老板救火/现金流溢出为负），每画面停留 10 秒 + "你们公司有没有这个现象？"
5. **翻译句机制**：每讲完一个案例环节配"把月子中心换成你的渠道，把纪念品换成你的产品，断裂点一模一样。42 条边不变，变的只是参数"
6. **预埋点设计**：每个三刀问题配预埋点（分钟+环节+部分答案）；提问时 GA 说"第 X 分钟已展示过一部分，现在看得更深"
7. **信任决策曲线**：分钟时间轴旁加怀疑→好奇→将信将疑→信任曲线；双检查点（0:25 / 0:45——已信任→加速；仍怀疑→切换策略）
8. **独立接入点**：每个关键节点（诊断启动/报告生成/仪表盘）30 秒自解释，且**行业中立**（先说"这是哪个环节、在哪个循环上"）
9. **冷启动预案**：预录视频+静态截图包，30 秒无缝切换+自然过渡台词
10. **叙事节奏调整预案**：区分技术故障与兴趣信号弱；打断/看手机→跳中间步骤直接结论/换贴近老板的案例
11. **P0 双态终判**：P0-block=演示前必修；P0-risk=功能存在但效果待验证（演示前监控不阻塞，演示后按反馈定优先级）
12. **对话式脱敏核查**：代码级核查脱敏现状 + 对话指令→工具调用→脱敏级别切换的可行性
13. **行业模板演示点**：展示"引擎通用、行业模板是数据不是代码"（现有 6 行业模板，加行业=加文件）

## 四、研究任务（前置 0 + 6 章）

- **前置 0｜研究设计基线**：决策矩阵模板、迭代协议、信任曲线模板、预埋点表、共性时刻表、独立接入点表、三刀应答模板——所有章节共享母版
- **第一章｜创始人画像与信任决策矩阵（迭代中心）**：广东产销一体/外贸/5000万-5亿假设验证（5 问）；决策矩阵（信任来源×威胁×行业适配）
- **第二章｜60 分钟三层共鸣演示剧本**：分钟时间轴 + 三层结构 + 稻盛/阿米巴语境 + 咨询后遗症回应 + 共性时刻 + 独立接入点 + 信任决策曲线（双检查点 0:25/0:45）
- **第三章｜三刀问题、预埋点与应答**：≥5 问（含"对我行业适用吗""你怎么知道结论是对的""没数据怎么办"等），每问三件套 [预埋点/应答稿/诚实降级]
- **第四章｜演示数据脱敏与对话式控制**：现状证据表（Anonymizer/PIIScrubber S1-S4 全链路）+ 对话式控制缺口与可行性 + 客户A演示数据脱敏规范（含外贸敏感性补充）
- **第五章｜演示交付物缺口与 P0 终判**：触达清单 × 现状 → P0-block / P0-risk / P1 表
- **第六章｜演示物料包与双预案**：冷启动视频/截图包、现场故障预案、叙事节奏预案、QA 卡、脱敏数据包、跨行业翻译句库

## 七、验收标准

1. 决策矩阵明确，第二章每环节标注强化/规避 + 行业适配
2. 剧本分钟级可执行；三层结构完整；每关键节点 30 秒自解释且行业中立；信任曲线含双检查点（0:25 / 0:45）
3. 共性时刻 ≥3 个（每个含画面/对号入座问题/翻译句）
4. 三刀 ≥5 问，每问含预埋点+应答稿+降级路径
5. P0 三态（block/risk/P1）逐项有理由
6. 冷启动包 30 秒切换；叙事节奏预案可操作
7. 脱敏章：现状证据表 + 可行性结论 + 客户A数据规范；实现缺口转交 Dev Doc
8. 跨行业翻译句库覆盖现场可能行业（外贸/制造/服务/零售/SaaS 等）
9. 每章自检 5 问；推测与经验假设分离；迭代回补记录在案

## 八、局限

- 剧本为纸面推演，真实预演需创始人安排环境（标注"待现场验证"）
- 广东外贸画像为创始人猜测，需画像验证确认；偏差大则剧本调整
- 对话式脱敏为代码级可行性评估，实际体验待 Dev Doc 实现后验证
- 定价/商务话术不在范围，标"需创始人确认"
