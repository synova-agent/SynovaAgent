# 第二章 60 分钟三层共鸣演示剧本（v2）

> 2026-08-01（画像验证后修订）| 时长从 30 分钟扩为 60 分钟（创始人确认）；结构：三层共鸣 + 稻盛/阿米巴语境 + 咨询后遗症回应 + 一对一收尾

## 设计原则（惊艳点）

1. **第 0 分钟就共鸣**：开场用共性画面 + 稻盛和夫语境锚定（"经营要看数字背后的实相"——盛和塾老板共同语言）
2. **阿米巴共鸣**：Synova 的"部门溢出" = 稻盛哲学的数字化体检——每个小组织的溢出是正是负，就是阿米巴在数字世界的投影
3. **让老板动手**：现场触发诊断、看数据跑起来
4. **咨询后遗症主动化解**："请过咨询的都知道：报告厚、人走了、知识也走了。"——主动说出他们的痛，再讲差异
5. **数据在，信号丢了**：财务软件/SaaS/OA 都有 → 不是没数据，是没人把散落的数字串成因果（呼应信息茧房研究）
6. **每讲一个案例环节必带翻译句**（行业不预设 → 翻译句库是全场的共同语言）
7. **收尾为一对一埋钩子**：会后每人约 10 分钟一对一，演示只负责"让每个人带走一个疑问"

## 分钟级时间轴（60 分钟）

### 0:00–0:03｜开场：共性时刻 1 + 稻盛锚定

- **动作**：投出"现金流溢出连续 3 个月为负"图表；问全场："这个画面见过吗？"
- **关键台词**："稻盛和夫说，经营就是要看清数字背后的实相。今天我们一起看一个系统怎么做到——而且它看的不是报表，是钱、客户、人三个循环。"
- **独立接入点**：本节点自解释（"这是真实企业的现金流信号"）
- **信任曲线**：怀疑 → 好奇

### 0:03–0:10｜第一层：通用循环共识 + 阿米巴数字化

- **讲什么**：画出"资源投入→经营产出→价值回流→溢出利润"循环 + 五断裂点
- **阿米巴桥接**："你们熟悉阿米巴——每个小组织独立核算。这个系统把它数字化的体检了：每个部门的溢出是正是负，一秒钟看清。"
- **关键台词**："所有生意都是这一个循环，行业只是运行方式不同。卡住，一定在五个位置之一断了。"
- **预埋点 1**："42 条边"一句带过（为"结论怎么来"埋线）
- **信任曲线**：好奇 → 将信将疑

### 0:10–0:12｜共性时刻 2（订单波动/客户集中/回款账期）

- **动作**：举手互动——"60% 订单来自两三个客户？""账期从 30 天拖到 90 天？"
- **目的**：不同行业老板同时点头

### 0:12–0:18｜案例：客户A结构 + 咨询后遗症识别

- **讲什么**："先讲一个真实案例，它和各位是同一类企业：有工厂、有销售、有运营、几百家渠道获客、按单生产。行业不同，结构一样。"
- **咨询后遗症**："在座请过咨询的都知道那个流程：访谈一个月、报告三百页、合伙人走了、知识也带走了。"
- **展示**：客户A业务结构图（脱敏）
- **信任曲线**：将信将疑（"你到底不一样在哪"）

### 0:18–0:22｜42 边可视化 + "数据在，信号丢了"

- **展示**：3–5 条因果边（渠道质量→获客成本→现金流溢出）
- **关键台词**："各位都有财务软件、有 OA、有 SaaS——数据都在。但没人把散在五个系统里的数字串成因果。不是数据不够，是信号丢了。"
- **预埋点 2**："凭什么信它"（机制可视化）

### 0:22–0:30｜现场诊断启动：六阶段实时流转

- **动作**：登录 → 新建诊断 → 触发六阶段 SSE
- **展示**：访谈→数据→假设→根因→报告→交付，发现卡片逐个浮现 + 证据链
- **独立接入点**：诊断启动节点 30 秒自解释
- **信任曲线检查点（0:25）**：若老板们看手机/无提问 → 加速到报告；若追问 → 保持节奏

### 0:30–0:33｜共性时刻 3（老板救火）

- **关键台词**："系统发现：渠道转化在漏，但销售团队把精力投到了新渠道——你的团队是不是也在忙着救火？"

### 0:33–0:38｜报告四层 + 行动闭环

- **展示**：report.html（CEO 摘要→证据链→行动建议→专家层）+ dashboard.html（健康卡片/Goal）
- **关键台词**："报告分四层……诊断不是目的，行动才是。结论会变成可跟踪的 Goal。"
- **预埋点 3**："结论怎么来" + "跟咨询有什么区别"

### 0:38–0:42｜脱敏演示 + 对话式控制

- **展示**：脱敏前后对比（客户A/报价区间/核心财务隐藏）
- **关键台词**："真实数据、核心已处理——客户是谁、报价多少看不到。边界可以用一句话控制。"
- **演示对话**（预录或现场）："我在给第三方演示，把核心财务数据隐掉。"（注：对话式控制尚未实现时按第四章降级方案——预录演示+诚实话术"这是设计中的能力，今天默认最高等级脱敏"）
- **预埋点 4**："数据安全吗"

### 0:42–0:48｜第三层：跨行业翻译 + 行业模板切换

- **动作**：翻译句库逐行业演示（外贸/制造/服务/零售/SaaS）
- **展示**：行业模板切换（现有 6 行业）
- **关键台词**："把月子中心换成你的渠道，把纪念品换成你的产品——断裂点一模一样。42 条边不变，变的只是参数。"
- **互动**：请 2–3 位不同行业老板对号入座
- **共性时刻 4**：客户集中/回款账期（全场共鸣峰值）

### 0:48–0:53｜黄金数据集 + 交叉验证（为什么信）

- **展示**：10 个真实案例回归 + 客户A回测（脱敏）
- **关键台词**："每次升级，10 个真实案例必须给出可解释的同一答案，变了必须有理由。"（诚实性脚注：此机制当前未接入发布门禁——对应 A 线 C-G1 / P1-2；台词按"机制+测试套件"表述，不宣称"自动执行"，追问时用三刀1 诚实降级）
- **预埋点 5**："你怎么知道是对的"最终答案

### 0:53–0:56｜数据散落路径 + 团队使用

- **讲什么**："你的数据散在五个系统？我们从访谈/导入开始，数据在哪就接哪。老板看结论、中层用工作台、GA 确认纠错——嵌进你们的例会节奏。"
- **目的**：解除"数据乱"+"团队不会用"顾虑

### 0:56–1:00｜收尾：一对一钩子

- **关键台词**："60 分钟讲了循环、案例、机制。真正的问题是——你的企业断在哪？会后我们一对一，每人十分钟，我们一起看一个最可能卡住你的位置。"
- **动作**：资料包（决策矩阵+自测清单）+ 预约名单 + 现场体验二维码

## 信任决策曲线（60 分钟版，双检查点）

| 时间 | 状态 | 若偏离预期的应对 |
|---|---|---|
| 0-3 | 怀疑→好奇 | 共性时刻1 无效→换"回款账期"画面 |
| 3-10 | 好奇→将信将疑 | 阿米巴桥接无人共鸣→加快进入案例 |
| 12-18 | 将信将疑（咨询后遗症） | 无人认同咨询经历→省略该段，直接差异对比 |
| **25（检查点1）** | 将信将疑→信任 | 信任→保持节奏；怀疑→跳过 30-33，直接进报告 |
| 30-42 | 信任→行动 | 打断→跳中间步骤（叙事节奏预案） |
| **45（检查点2）** | 信任巩固 | 冷场→加强互动对号入座 |
| 56-60 | 行动 | 一对一钩子收集 |
