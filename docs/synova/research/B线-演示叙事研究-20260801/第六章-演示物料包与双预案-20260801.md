# 第六章 演示物料包与双预案

> 2026-08-01 | 内容：冷启动包、现场故障预案、叙事节奏预案、QA 卡、翻译句库、数据包清单

## 一、冷启动包（30 秒无缝切换）

| 物料 | 规格 | 用途 |
|---|---|---|
| 演示视频 v1 | ≥12 分钟：六阶段诊断+报告+脱敏+行业翻译（预录，含脱敏案例） | 系统故障主备选（60 分钟演示浓缩兜底） |
| 静态截图包 | 10-15 张：循环图/42边/六阶段/报告/仪表盘/脱敏前后 | 视频不适用时的降级 |
| 过渡台词 | "今天现场网络不太理想，我们先通过这段视频看完整诊断流程——都是真实企业的真实数据。结束后我们逐个环节深聊。" | 无缝切换 |
| 切换触发 | 现场信号：SSE 3 分钟内无进展 或 服务器无响应 | 决策点 |

## 二、现场故障预案（技术类）

| 故障 | 判定 | 动作 |
|---|---|---|
| 服务器起不来 | 启动失败/端口占用 | 冷启动视频包 |
| LLM 无响应 | 诊断停在 Phase 1 | 等 30 秒→切视频包；会后补跑 |
| 报告加载失败 | report 页空 | 切静态截图包（报告页） |
| 投屏/网络问题 | 设备侧 | 备用笔记本+离线视频文件 |

## 三、叙事节奏调整预案（心理类）

| 兴趣信号 | 判定 | 应对动作 |
|---|---|---|
| 0:25 检查点1 仍在怀疑 | 无提问/看手机 | 跳过 22:00-33:00 中间段，直接进报告结论 |
| 中途打断问"多少钱" | 关心商务 | 切换三刀 6 应答+收尾加速 |
| 打断问"我行业" | 关心适用性 | 立即切行业翻译段（42:00 前置） |
| 冷场（无人响应互动） | 共鸣不足 | 换共性时刻画面（回款账期最普适） |
| 老板离席 | 价值未建立 | 会后一对一补救（资料包+预约） |
| 咨询后遗症段冷场 | 共鸣未建立 | 省略该段，直接进"驻场 vs 项目制"对比 |
| 一对一环节 | 会后人流分散 | 提前登记预约名单，每人 10 分钟，开场问"你最卡的位置是哪个" |

## 四、QA 卡（30 秒标准应答）

| 问题 | 一句话应答 |
|---|---|
| 你们是干什么的？ | "给企业做增长诊断的 Agent——每天帮你看现金流、客户、组织的健康，断在哪告诉你。" |
| 和 ERP 什么区别？ | "ERP 告诉你发生了什么，我们告诉你为什么、下一步怎么办。" |
| 数据安全？ | "数据在你这，出网前四层脱敏；演示里你看到的真实数据就是处理后的样子。" |
| 你们有客户吗？ | "客户A是我们深度服务的案例，今天演示的就是它的结构——脱敏后。" |
| 多少钱？ | "今天不谈合同；你可以先带走一份自测，验证结论再谈。" |

## 五、翻译句库（跨行业共鸣核心）

| 客户A要素 | 通用 | 外贸/制造 | 服务/零售 | SaaS/科技 |
|---|---|---|---|---|
| 月子中心渠道 | 渠道合作 | 展会/客户/平台 | 门店/加盟 | 分销/代理 |
