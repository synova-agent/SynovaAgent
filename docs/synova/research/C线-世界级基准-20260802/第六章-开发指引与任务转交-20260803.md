## 二、开发任务清单（按优先级）

> 契约优先（铁律 47/48）：每个任务开工前在 task brief 定义输入/输出/降级契约 + 测试（正常/降级/边界三路径）。

### T0-P0｜反馈→规则闭环（N13）——唯一必须开发的 P0

**对应标准**：S5-1（反馈→规则更新闭环）、T-3（模型校准周期）、S0-2（闭环验证）——同一链路

**为什么（必须修的三句话）**：
1. C 线把"进化能力"定为产品核心承诺——"系统沉淀、持续进化"是与咨询/培训赛道的本质差异（第四章 R6）
2. A 线实证：`feedback-collector` 可写入（被 `routes/workspace-data.ts` 消费），但 `middle-evolution-engine` **零生产调用**——反馈进得来、进化出不去，闭环断裂
3. 不修则"企业级持续学习"是叙事不是事实；演示可不讲（红线 1），但客户A部署后第一个季度就会暴露（S0-2 改善基线依赖它）

**规格位置**：权威文档17-开发者任务地图 v2 §N13（现成规格，无需重新设计）

| 属性 | 值 |
|------|-----|
| 文件 | `src/loops/middle-evolution-engine.ts`（修改） |
| 接线链 | `src/growth/feedback-collector.ts`（写入）→ `src/loops/middle-evolution-engine.ts`（消费，当前零调用） |
| 目标状态 | GA 纠错 ≥3 次同类型 → 自动触发诊断规则更新 |
| 验收（文档17） | GA 连续 3 次标记"哨兵X误报"→ 自动调低哨兵X的权重 |
| 验收（C线级） | 反馈写入→规则更新**端到端跑通**；周级闭环（S5-1 目标值） |
| 预估 | 1 天 |

**测试要求**（铁律 48）：正常路径（3 次纠错触发权重调整）/ 降级路径（collector 不可用→log.warn+返回空，铁律 24+31）/ 边界（2 次不触发、阈值精确在 3）

### T1-P1-A｜GA 验证闭环接线（S5-2 / A线 C-G2）——部署期

**为什么**：GA 是"人机闭环"的仲裁方——没有 GA 验证/否决，反馈数据的可信度没有保障，N13 自动调权的基础不成立。现状 `src/l3/ga-collaboration.ts` 仅被 `src/agent/interactive-card.ts:13` 弱引用，GA 无法真正验证/否决结论。

**规格**：无既有开发节点（权威文档17任务地图未覆盖）→ **Dev Doc 需先写设计再排期**（契约优先）；设计依据=权威文档05（Agent主动交互）+ 权威文档13（增长导航）

| 属性 | 值 |
|------|-----|
| 文件 | `src/l3/ga-collaboration.ts`（已有 `GAFeedbackHandler`，类型 correct/flag/rediagnose 齐全） |
| 接线目标 | 接入 GA 工作台/报告交互入口（消费 GA 动作→落库→可被 N13 消费） |
| 验收 | GA 可对诊断结论执行验证/否决，动作可逆（仲裁）且落库 |
| 预估 | 1-2 天（含设计） |

### T1-P1-B｜方向监测接线（S1-5 / S1-6）——部署期

**为什么**：A 线 B7/B8 实证 `src/loops/direction-monitor.ts` 与 `middle-evolution-engine` 一样零生产调用——"何时该诊断"（权威02）与"中层进化"（权威13）是诊断自主性的核心，**写了没接**。这直接决定"持续运行"不是空转。

**规格**：权威文档02（方向监测引擎：四个感知断裂点检测、NCI 子模块）+ 权威文档13（中层导航）；任务地图无节点，需 Dev Doc 写接线设计

| 属性 | 值 |
|------|-----|
| 文件 | `src/loops/direction-monitor.ts`（已有，找生产入口接线） |
| 接线目标 | loop-scheduler 或 sentinel-service 中触发方向监测，信号→诊断管道 |
| 验收 | 方向失效信号→触发诊断 <24h（S1-5）；中层偏离信号→1 个经营周期内进入诊断（S1-6） |
| 预估 | 1-2 天（含设计） |

### T1-P1-C｜报告导出（S2-5）——需先设计

**为什么**：C 线新发现缺口——"可带走性"是 SMB 老板的权力工具（带得走的证据→说服合伙人/高管），但 A 线/B 线均未含报告导出设计，`report.html` 的导出完整性未审计。

**规格**：无 → **研究/设计先行**（交付物 PDF/HTML 导出 + 可转发）

| 属性 | 值 |
|------|-----|
| 验收 | PDF/HTML 可导出、老板可转发高管 |
| 预估 | 设计 0.5-1 天 + 实现 1 天 |
