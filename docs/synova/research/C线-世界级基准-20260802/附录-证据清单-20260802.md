## 四、证据使用规则

1. **引用分级**：对外演示/宣传只引用"强/中"证据；"弱/过时"仅作内部量级参考
2. **推导隔离**：所有 [推导] 值（如 3 天 TTFV、6-15 万定价带）不得表述为"行业标准"——话术必须带"我们的目标/设计推导"前缀
3. **时效**：静态数据超 12 个月未复核即标"证据过时"（方案五.4）；重大产品变更（如 Agent SDK 计费规则）即时更新
4. **反查**：每个演示数字可反查到本章编号（E-xx）→ 第一章文件 → 原始来源
