## 0. 这份指引是什么、不是什么

**是**：DOC-0114 的借鉴层操作化。0114 回答"哪些模块死守/借 DSH/搬走/删除"（架构级四色）；本指引回答"**具体借 DSH 的哪一段代码、落到 Synova 哪个文件、修哪条产品线缺口、怎么验收**"（锚点级借鉴卡），并给出 224 包**逐一处置表**保证无遗漏。

**不是**：Stage 3 迁移命令。入场券三条（客户A首季数据 / DSH 脱离预览 / R9 收益验证）今天一条都不满足，本指引全部产出在"零依赖"前提下生效。

> ⚠️ **术语澄清（D808，2026-09-17 起）**：本文出现的"零依赖"一律指 **零包依赖**——不 `import`/`require` `@deepseek-ai/*`、不建 re-export 桥接（§10.2）。**"零依赖"≠"禁止抄码"**：抄码（含整段搬实现）自 2026-09-17 起**允许且鼓励**（§10.1，M3）；抄进来的代码即自有代码，不构成 DSH 依赖。§3 标题"零依赖"、§6 G5 均按此口径读。

**为什么需要 v2**：① 0114 基于	rc.5（8-20），上游 15 天跨 3 个版本线（rc.5 → 0.1.2-alpha.2 → 0.1.3-alpha.1），API 面仍在动（版本号 rc→alpha 重置 = 破坏性变更窗口敞开）；② 0114 的借鉴清单是方向级（D1-D9），不到代码锚点；③ 0116 六卡之外存在图纸内部缺口（§4 写了"借鉴 cron 冷恢复"但六卡无此卡）。

## 6. 五条硬守卫（借鉴不翻车的全部纪律）

1. **G1 零桥接引用**（M3 口径）：借鉴 = 读 DSH 源码自研，**或直接抄码进本仓**（抄进来即自有代码，可改可测）；**禁**的是 `import`/`require` `@deepseek-ai/*` 与 re-export 壳。验证命令：`grep -rn "@deepseek-ai" src/ packages/ --include="*.ts" --include="*.json" | grep -v node_modules` 零结果（**2026-09-17 实测 0 命中**；建议固化为 `scripts/check-no-dsh-deps.sh` 并入 npm run check 族）。壳判定照铁律 46（非 import/export/注释的有效代码行 = 0 = 纯桥接）。
2. **G2 独立 PR + 接线审计**：每卡单独 PR；grep 调用方 + 集成测试走真实路由（4 次接线失败史）。
3. **G3 守卫物理化 · 回写验收点 + 绑定证据**（**2026-09-17 起，M2**）：每卡必须回写到 ≥1 个 26 线验收点，并生成**绑定该点 id 的证据文件**；**未回写、或无绑定证据者，该卡不计通过**——禁止"为借鉴而借鉴"（engine-core 事故教训：无验收标准的迁移 = 欺诈温床）。三个物理动作见 §11.1。
4. **G4 grep 物理证明 + 可回退**：声称借鉴完成必须 grep/测试物理证明（铁律 47）；每个机制带 enable/disable 开关。
5. **G5 Stage 3 前零运行时依赖**：入场券三条不满足前，`package.json` 不引 `@deepseek-ai/*`、运行时不靠外部 DSH 包承载；DSH 方向变了随时弃坑，核心零伤。**与 M3 不冲突**：禁的是"依赖 / 桥接"，不是"抄码"——抄进本仓的代码是我们的代码。判据：删掉 `node_modules/@deepseek-ai` 后本仓仍能构建、仍能跑测试。

## 12. 落点归属：`modules` 归属规则 + `product-lines.yaml` 同步（元断言 M1）

### 12.1 规则（R1–R6，即刻适用）
- **R1 单一归属**：一个落点（文件/目录）必须归属到**恰好一条**线的 `modules`；两条线都要 = 先裁决归属，再开卡。
- **R2 归属判据 = 该落点服务的验收点所在线**（不是"代码像哪一层 / 在哪个架构目录"）。先答一句："这张卡让哪条 V1 断言的 `fail_when` 不再成立？"——答不出 = **无落点，退回设计**。
- **R3 `modules` 值必须是真实存在、且能被 git pathspec 命中的路径前缀**——`calc-progress.py` 用 `git log --since=<证据日期> --name-only -- <modules>` 做 A1 惰性失效；**写错路径 = 该线的失效检查静默空转**（物证见 §12.2）。
- **R4 新增目录 / 新落点必须同 PR 同步 `product-lines.yaml`**（线集增删只有创始人能改，但**落点归属**是技术事实，可由卡主在 PR 内落位）——否则 M2 无从回写。
- **R5 不得整目录挂靠**：混合目录（如 `src/services/` 30 文件跨多线）按**文件或子目录**粒度归属。
- **R6 未归属 = 不得开卡**（开了也过不了 M2）。
