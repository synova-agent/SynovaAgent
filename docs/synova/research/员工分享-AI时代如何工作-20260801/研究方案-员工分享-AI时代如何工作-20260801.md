# 员工分享《AI 时代如何工作》研究方案 v1.0

> 2026-08-01 | 定位：让客户A员工"看清时代→找到方向→拿到方法→约定开始"——部署已签约（产品协议+战略顾问协议），**不推销**，落点是"用起来→及时反馈→立即迭代"的使用约定——≈142 分钟（可裁剪至 120/135，见模块总表时长说明），四幕叙事弧（认知→意义→行动→信念）

## 一、研究背景

1. 客户A已与 Synova 签署产品协议，创始人另签战略顾问协议——部署是既定事实；分享不推销产品，重点是"部署后的使用约定"：Synova 用起来→有问题及时反馈→立即迭代，Synova 未来是企业最聪明的大脑
2. 部署后除诊断与增长导航外，还需帮助公司找到可 Agent 化的节点（客服/运营/会所对接/日常办公）；日常工作要求**全员配置 WorkBuddy + ima**——WorkBuddy 是个人办公智能体（腾讯云 CodeBuddy 团队 2026-03 发布），ima 是腾讯智能知识库，Synova 接入企业 ima 作为知识源
3. 组织变革是分享的一部分（模块三）：主线公式（业绩=客户数×转化率×客单价）、利润中心/成本中心现实、三个方向的打法（会所宝量翻倍/销售合伙人/培训体系）、部门打散为任务制、单一运营中心、全员用 AI；变革内容以创始人（战略顾问）口径为准
4. 部署机制新规定（2026-08-02 创始人口径）：① token 预算制（每人每月 200-500 元，按任务/模型定额，默认 DeepSeek API）；② 安全基线（资金/API Key/个人信息/公司信息不上公网，宝宝数据绝对红线——依据《个人信息保护法》）；③ 每周分享会（下周起人事排期，人人分享 WorkBuddy 用法）；④ 公司文档统一规范化进 ima；⑤ 三个基本功（配 API Key / GitHub 找 Skill / 自制 Skill，实操见附录）
5. 创始人实战经验（2026-08-02）织入"四门工程"延伸模块：无约束跑偏→CLAUDE.md 铁律（先有效后失效）→Loop 数十版→Graph 控制塔（稳定）——落点"能物理硬性约束的，就不要让 AI 自律；Agent 是实习生，允许犯错、相伴解决、共同成长"，控制塔架构图可现场演示
6. 分享对象是员工（非技术岗为主），需要"人话+互动+幽默"，但底子必须是权威、真实、科学——符合 Synova 证据纪律
7. 引用梁文锋融资问答实录（PDF 118 条）原文，作为时代判断的权威支点
8. 时间窗口：分享在近期举行，≈142 分钟完整版（现场时间紧可裁剪至 120/135，裁剪方式见模块总表时长说明）
