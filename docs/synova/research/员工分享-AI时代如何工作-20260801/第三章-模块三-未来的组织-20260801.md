# 第三章 模块三：未来的组织——人+Agent、聚焦主线（15 分钟）

## 目的

让员工看到组织形态的演化方向（人+Agent），并理解客户A即将发生的组织变革：主线公式（业绩=客户数×转化率×客单价）、利润中心/成本中心的现实、三个方向的打法、部门打散为任务制的变革方向，以及"全员用 AI、人人提效"的要求。**AI 不是变革的原因，是变革的加速器。**

## 脚本

### 第一段：组织形态的四个阶段（3 分钟）

【讲 0:00】"公司的组织形态，一路在变：
- **人力组织**：老板一个人扛，人走经验走（很多小公司是这样）
- **工具组织**：上 ERP、上 OA——工具记录数据，但知识还是在人脑里
- **人+Agent 组织（正在发生）**：人提课题，Agent 执行，人验收——**知识第一次真正留在公司**
- **纯 Agent 公司（极端，会先出现在特定行业）**：一家客服公司可能只有 3 个人 + 100 个 Agent；一家内容公司可能就 5 个人 + 50 个 Agent。甚至极端情况下，一家公司就是一个 Agent 网络。

【互动 0:02】"你们猜，哪种行业会最先变成'纯 Agent 公司'？……（引导：标准化程度高、重复工作多的行业）对——越重复、越标准，越先被 Agent 化。但今天的主角不是纯 Agent 公司，是你们自己的公司。"

### 第二段：三个关键机制（5 分钟）

【讲 0:03】"人+Agent 的组织，靠三个机制转起来：

**机制一：知识资产化。** 把老师傅怎么干活写下来——配置、规则、知识库。阿米巴是 1964 年稻盛和夫在京瓷搞的：把公司拆成小集团，每个小集团独立核算、全员参与。它的本质是什么？**把经营判断变成组织机制，而不是某个人的脑子。** AI 时代，这件事第一次能真正落地——因为 Agent 可以读配置、守规则、按知识库干活。

**机制二：委托结构。** 人提课题 → Agent 执行 → 人验收。中层过去是'传话的'，未来是'验收和纠错的'——这更值钱，不是更没价值。

**机制三：共同成长。** 越用 Agent，它越了解你的公司；你越用，越知道它的边界。它持续进化，你们的配合也越来越顺。"

【幽默 0:06】"现在的组织有时候像传话游戏——老板说一句，传五层，最后面目全非。人+Agent 的组织是老板说清楚，Agent 抄下来，每层都在原话基础上干活，还能回溯'哪一层传错了'。"

### 第三段：客户A的主线——克制、聚焦、打散重来（7 分钟）

【讲 0:08】"公司怎么管？先给一个判断：**管理没有唯一答案。** 梁文锋的 DeepSeek 是什么公司？天才密度极高、愿景驱动、没有 KPI、一半时间自由探索——那是他们的活法，是那一类公司的活法。客户A是另一家公司：业务不同、员工不同、打法不同，**不能照搬**。

但梁文锋有一件事，我认为所有公司都该学：**围绕主线的克制。** 他的原话：
- #25：'我们只做 AGI 的主线……它不在这个主线上面，我们不会去做。'
- #49：'我们非常聚焦……就意味着我们要做的事情很少。'
- #7：'你越克制，可能就越容易做成。'（他说自己起点低、资源少，靠的就是克制）
- #11-12：'克制是一种战略……能够增加我们做成的概率。'

为什么他这么能打？不是因为他什么都做，恰恰是因为他**只做一件事**。想打胜仗，第一条就是聚焦。"

【讲 0:10】"客户A的主线是什么？一句话公式：**业绩 = 客户数 × 转化率 × 客单价。** 公司的每一分钱、每一个人，都要回答同一个问题：**你在让这三个数里的哪一个变大？** 回答不了这个问题的事，就是该砍的事；回答得了的人，就是该多给资源的人。"

【讲 0:11】"说一个现状，这句话可能让一些人听着不舒服，但它是变革的起点：**我们公司现在，是十几个销售代表的利润中心，在养着三四十个人的成本中心。** 设计、自媒体、财务、还有其他岗位——**不是说大家没有用**，是结构失衡了：打仗的人太少，补给的人太多。企业不是人越多越好，是**对准主线的人**越多越好。这是战略顾问的判断，也是老板的决策。"

【讲 0:12】"所以围绕主线，定了三个方向的打法：
1. **存量做深**：现有合作的会所一家不动，免费礼品（宝量）投放翻倍——把转化漏斗的入口做大
2. **增量做广**：大量招聘销售合伙人——把'客户数'这条腿跑起来
3. **支撑做厚**：建公司自己的培训体系，让销售能力提升、让新人快速上岗，实现**招-用-育-留闭环**。这背后是'杨三角'：组织能力 = **会不会**（员工能力）× **愿不愿**（员工思维）× **容不容**（员工治理）。招、用、育、留解决'会不会'，主线激励解决'愿不愿'，任务制解决'容不容'。

同时，**两个人抽出来做第二曲线**——查尔斯·汉迪说过：第一曲线到顶之前，就要种下第二曲线。剩下的人，全部聚焦第一曲线。"

【讲 0:13】"变革怎么做？四个字：**打散重来。** 打破现在的部门墙，所有人回到一个运营中心，围绕主线的任务来组织——**任务制、临时小组**：这个月打'会所宝量翻倍'的战役，就临时组一个小组，打完散，下个任务再组。部门是静态的，任务是动态的。

【幽默 0:13】"任务制小组就像剧组：拍完一部戏就散伙，下一部戏再组——但每个剧组都要出票房。"

【讲 0:13】"要求只有一条：**人人用 AI，人人提效率。** 先把第一曲线快速稳住、做厚，然后越来越多的人，才有资格进第二曲线。这不是裁员，是把每个人都放到离主线最近的位置。"

【互动 0:14】"回到你们自己：你现在的岗位，落在主线公式的哪一环？客户数、转化率、还是客单价？（请 1-2 人回答）……如果一时找不到落点，没关系——变革要解决的正是这个：让每个岗位都能看见自己为主线的贡献。"

【衔接】"变革的方向有了，但为什么是现在、还要多快？下一模块讲：领先半年，可能就是永远追不上的鸿沟。"
