# 第六章 模块六：日常工作提效——工具、预算、基本功与安全基线（23 分钟）

## 目的

把方法论落到客户A的具体岗位。部署已签约（不推销），本模块讲六件事：① 人人配置 WorkBuddy + ima（日常标配）；② 公司 token 预算制（每人 200-500 元/月，默认 DeepSeek API）；③ 公司文档统一规范化进 ima；④ 三个基本功（API Key / GitHub 找 Skill / 自制 Skill）；⑤ 每周分享会机制；⑥ 安全基线（四条红线 + 宝宝数据绝对红线）。

## 脚本

### 第一段：定位——部署已签约，今天讲怎么用（3 分钟）

【讲 0:00】"先亮个底：Synova 和客户A已经签了产品协议，创始人还签了战略顾问协议。**今天不是推销，是告诉大家部署之后怎么用。**

部署之后是三件事：
1. **Synova 管全局**——诊断和增长导航，那是老板的驾驶舱
2. **WorkBuddy + ima 管日常**——今天开始，每个人都要配这两个工具，这是公司的要求
3. **Agent 化节点管重复劳动**——把你们从重复劳动里解放出来

【讲 0:02】"先看地图（展示岗位×节点表）——这不是全部，是个起点："

【讲 0:02】"而且注意：公司组织正在从部门制转向任务制（模块三讲过）——所以下面不按部门讲，按'活儿'讲。岗位会变，活儿不会消失。"

### 第二段：全员标配——WorkBuddy + AI 额度 + ima（6 分钟）

【讲 0:03】"为什么人人要配？记住一句话：**WorkBuddy 是你个人的手和记忆，ima 是公司的记忆，Synova 是公司的脑。** 三者一起，就是前面讲的'人+Agent 组织'的最小单元。

第一个，**WorkBuddy**——你的个人 AI 工作助理。它和我们手机里的 DeepSeek、豆包最大的区别，就是模块一讲的那句话：**它是员工，不是顾问**。你给它一句话任务，它自己拆解、调工具、操作文件、交付结果；它还有定时自动化——'每天早上 9 点把前日订单汇总发我'，它真能到点干活。

第二个，**你的 AI 额度**——一条公司规定：**公司会从每个人的工资结构中，安排一部分专门作为 AI 额度（token）发放，每人每月 200-500 元不等**，按任务性质和所用模型定额。默认配置 DeepSeek API——文本模型，性价比最高；要用多模态模型（看图、看视频）会贵一些，额度相应上调。**这不是商量，是公司规定。** 对每个人都有好处：别人家的员工自己花钱买会员，你们的公司直接发额度——**把它花在刀刃上，就是你对公司最好的回报。**"

【讲 0:06】"第三个，**ima**——公司的 AI 知识库。战略规划、会议纪要、运营报表都会沉淀在这里。**Synova 就接在 ima 上**，做诊断、做导航、做企业最聪明的大脑——但有一条安全线：**你看得见什么，它才读什么**，不会越权。

配合 ima，还有一条公司规定：**公司文档统一规范化管理**——统一命名、统一格式、统一归档进 ima，谁产生、谁上传、谁负责。规矩一句话：**文档不归档，等于没发生过。** ima 里乱，公司的大脑就乱；ima 里整齐，大脑才聪明。"

【互动 0:08】"现在把手机拿出来，打开 WorkBuddy（没装的扫这个码，微信小程序也行），给它说一句你明天要干的第一件事。ima 账号公司统一开通，AI 额度本周到账。本周目标就一个：**配好工具、拿到额度、用起来。**"

### 第三段：节点地图——你岗位上的两档用法（7 分钟，逐岗位）

【讲 0:09】"工具配好了，干什么？我们按'活儿'过一遍，每个都给'两档用法'——简单重复的用一句话委托（效率型），复杂问题用课题公式（研究型）。这些活儿将来会组成不同的临时小组：

**客服岗**
- 效率型：常见问题自动应答草稿、投诉自动分级、回访提醒。"把本周投诉按类型归类，标出重复出现 3 次以上的问题"
- 研究型："为什么这个月差评比上个月多？"（套课题公式深挖）

**运营岗**
- 效率型：订单汇总、生产排期提醒、库存预警、物流异常跟踪。"每天早 9 点把前日订单和发货异常汇总发我"
- 研究型："产能瓶颈到底卡在哪个环节？"

**会所对接岗（我们的特色环节）**
- 效率型：月子中心合作台账、入驻新生儿登记、礼品派发追踪、对账单核对、续约提醒。"核对本月各会所对账单，标出差异超过 5% 的"
- 研究型："哪类会所的合作质量最高？为什么？"

**日常办公（所有人）**
- 会议纪要、周报、数据汇总、日程、知识库问答、文档初稿——这些就是 WorkBuddy 的主战场。"把今天会议整理成三件事+责任人+截止时间""

【互动 0:14】"每人想一个自己岗位上最重复的活。不用说出来——等会收尾的约定清单里，就有它。"

### 第四段：三个基本功——配 Key、找 Skill、造 Skill（2 分钟）

【讲 0:16】"还有三个基本功，今天只讲是什么，详细步骤在会后资料里（人手一份）：
1. **配 API Key**：给 Agent 一把'钥匙'，它才有资格调用模型和工具。记住：**Key 就是密码**——不共享、不截图发群、丢了立刻作废重配
2. **去 GitHub 找 Skill**：Agent 的'技能包'很多是开源的，在 GitHub 上按任务搜——'数据分析 skill'、'客服回复 skill'——下载配置就能用，不用自己造轮子
3. **把自己的活变成 Skill**：把你每周重复做的事写成'触发词 + 步骤 + 验收标准'。今天讲的'配置文件思维'就是它的雏形——写三次，你就有自己的第一个技能包"

### 第五段：怎么开始 + 每周分享会（2 分钟）

【讲 0:18】"起步三个动作：先配工具（本周内）、选一个节点、套公式跑两周。记住**先小后大，先易后难**——先从'每天早上的报表'开始。

另外还有一条机制：**第一周完成部署，从下周开始，每周一次分享会——人事排期，每个人轮流上台讲 5 分钟：我怎么用 WorkBuddy 干活的。** 讲你配了什么、踩了什么坑、省了多少时间。分享不是表演，是互相抄作业。记住：**从今天起，这家公司就是人+Agent 共同成长的公司。**"

### 第六段：安全边界——四条红线 + 宝宝数据（3 分钟）

【讲 0:20】"最后一条铁律，也是公司的安全基线。先背四条红线——**资金、API Key、个人信息、公司信息，一律不允许出现在公网。** 用大白话讲：
- 不把金额、对账单、报价发到公开的群、网盘、论坛
- 不把 API Key、密码截图发到群里
- 不把员工、客户、宝宝家庭的信息喂给公网免费工具（手机上的免费 App 也一样）
- 不把公司未公开的经营数据上传到没有授权的平台

再加一条比四条都重的：**宝宝的数据。** 我们做的是新生儿纪念品——宝宝照片、手脚模型、出生信息、家庭联系方式。这不是普通信息，《个人信息保护法》写得清清楚楚：**不满十四周岁未成年人的个人信息属于敏感个人信息**，处理要监护人同意、要专门保护。**宝宝数据，是绝对红线中的红线——传出去不是扣绩效的问题，是法律问题。**

习惯上还有三条：**能脱敏就脱敏**（名字写'王女士'、金额写'约 5 万'）；**新工具先拿假数据试**，确认安全再用真数据；**出了问题不删日志**——立刻报告，我们帮你查。Synova 默认最高等级脱敏、按权限读 ima；你们自己用 WorkBuddy 时，同样守这条线。工具越强，边界意识越要强。"

【互动 0:22】"谁来复述安全基线的四条红线？……（请 1 人回答）对：资金、API Key、个人信息、公司信息——再加一条压舱的：宝宝数据，绝对红线。"
