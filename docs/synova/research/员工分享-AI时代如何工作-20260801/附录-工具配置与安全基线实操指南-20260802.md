## 一、三个基本功

### 1. 配置 API Key（以 DeepSeek API 为例）

【教程】通用流程（各平台大同小异）：
1. 在模型平台官网注册开发者账号（如 DeepSeek 开放平台）
2. 进入"API Keys / API 密钥"页面，点击创建新 Key，复制保存（只显示一次）
3. 回到 WorkBuddy 等 Agent 工具的"设置 → 模型/API"，填入 Key 并选择默认模型
4. 测试：让 Agent 完成一个简单任务，确认能正常调用

【安全】Key 的三条铁律：
- Key = 密码：不共享、不截图发群、不写进公开文档
- 发现泄露：立即作废重配（平台一键撤销）
- 只授予最小权限：能用只读就不用读写

### 2. 去 GitHub 找适合自己任务的 Skill

【教程】三步找技能包：
1. 打开 GitHub，搜索关键词：`agent skills` + 你的任务词（如 `agent skills customer service`、`agent skills data analysis`、`agent skills meeting notes`）
2. 筛选标准：Star 多、最近有更新、有 README 说明用法
3. 下载/复制技能包 → 按 README 放入 Agent 的 skills 目录 → 在 Agent 里启用测试

【提示】技能包就像手机 App：先看评分和更新，再装；装完先在假数据上试，确认安全再用于真实工作。

### 3. 把自己的工作变成 Skill

【教程】一个 Skill 就是三件套，模板如下：

```
名称：XXX 技能（如"周报汇总"）
触发词：当我说"帮我写周报"，启动本技能
步骤：
  1. 收集本周工作记录（来源：ima 本周归档/WorkBuddy 任务记录）
  2. 按模板整理：本周完成 / 数据变化 / 下周计划 / 需要支持
  3. 输出草稿给我，我确认后再定稿
验收标准：
  - 数据与来源一致
  - 不超过一页
  - 有问题标注"待确认"，不编造
```

【方法】先做三次重复工作 → 把步骤写下来 → 就是你的第一个 Skill。写清楚就是资产。

## 二、安全基线清单

【公司规定 + 安全】四条红线（不允许出现在公网）：

| # | 红线 | 例子 |
|---|------|------|
| 1 | 资金 | 对账单、金额、报价、成本 |
| 2 | API Key / 密码 | 各类密钥、登录凭据 |
| 3 | 个人信息 | 员工、客户、宝宝家庭信息 |
| 4 | 公司信息 | 未公开的经营数据、客户名单、合同、供应商 |

【安全】宝宝数据绝对红线（依据《个人信息保护法》第 28/31 条）：
- 不满 14 周岁未成年人个人信息 = 敏感个人信息，处理需监护人同意 + 专门保护
- 宝宝照片、手脚模型、出生信息、家庭联系方式：不进公网、不进免费工具、不上传未授权平台

【安全】三个习惯：
1. 能脱敏就脱敏：名字→"王女士"，金额→"约 5 万"，会所→"某月子中心"
2. 新工具先拿假数据试，确认安全再用真数据
3. 出了问题不删日志，立刻报告

## 三、ima 文档统一规范

【公司规定】三条：
1. 统一命名：`类型-主题-日期`（例：`会议纪要-会所季度复盘-20260802`）
2. 统一归档：所有工作文档进 ima 对应目录，不散落在个人电脑/微信
3. 谁产生、谁上传、谁负责：文档不归档，等于没发生过

【提示】ima 里的文档质量 = Synova 大脑的知识质量；权限由公司统一管理（你看得见什么，Synova 才读什么）。

## 四、每周分享会参考模板（5 分钟/人）

【公司规定】下周起人事排期，人人轮流。讲四件事：
1. 我这周让 Agent 干了什么（一句话任务示例）
2. 我怎么配置的（工具/Skill/API）
3. 踩了什么坑、怎么解决的
4. 实测省了多少时间

【提示】分享不是表演，是互相抄作业；讲得最糙的往往最有用。
