# Win 侧手册（仓内镜像）

## 为什么要这个目录
**Win 侧只能读远程仓库**；而 Mac 侧有大批文档在 **库外档案仓**（`~/Synova-过程档案/`）
与**院方目录**（`~/山河研究院/`）—— 不镜像 = **两端基准不同步**。

**实测事故（2026-10-11）**：产品宪章 v8.1 与 K4 审计定稿此前**都不在仓内** ⇒
Win 侧 CTO 只能拿到卡面、拿不到卡面所依据的**架构基准与裁决依据**。

## 同步纪律（AGENTS.md 同款）
1. **凡两侧执行者都要读的件，必须进仓库**（唯一通道 = Gitea）
2. 镜像头必须注明：**权威源在哪 · 冲突以谁为准 · 谁负责同步**
3. 院方原件（宪章等）**不得在仓内单独修改**；改 ⇒ 同步镜像并注明
4. **派单件必须自检**：清单里列的每一条，在 clone 里都能读到吗？读不到 ⇒ 同步断了，**停下报告**
