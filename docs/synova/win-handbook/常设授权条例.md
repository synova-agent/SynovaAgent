# 常设授权条例（**替代逐件派单 —— 各线的作业面授权**）

> **为什么有它**：CTO 成为瓶颈的根因是【一件一件事的派—收—验】。
> 本条例把授权从【任务】改为【作业面】：各线在自己的域内**自派单、自收口、自合并**，CTO 只做三件（判架构/定判据/裁优先级）+ 抽查。
> **授权是可收回的**：抽查不过 ⇒ 收紧该线授权。
> **生效**：创始人 2026-10-04 批准。

---

## 〇、Token 与身份的确定结论（创始人 2026-10-04 裁定）

```
✅ **不新建 token。** 依据（实测）：
   · gh 认证 = tangbaobao520，token = ghp_（classic PAT），scopes = `repo`
   · **repo scope 已含 push 与 merge PR** ⇒ 各线现在就有合并权限（它们已在用同一 token push）
   · 组织只有 1 个账号 ⇒ 身份统一是【既存事实】，不因"允许合并"而新增风险
⇒ 维持单账号 + **政策授予自合并**。
   记录层无法区分"谁合的"这个限制【本来就在】（它们所有提交已是同一账号）。
   若 K3 审计将来要求记录级独立性 ⇒ 届时上 GitHub App 安装 token（不在本轮）。
```

|---|---|---|---|---|

| **文档格式与登记** | ✅ 自决 | ✅ 自决 | ✅ 自决 | — |
| **线内小卡（自开自收）** | ✅ 自开（条件见 §二） | ✅ 自开 | ✅ 自开 | 抽查 |

**红线（三线通用，违反 = 事故）**：
```
· 不碰 scripts/audit/**（K3 域）· 不写审计标准 · 不自审
· 不改 ci.yml 的 job `name:`（12 必需 context 的唯一产出者）
· 禁 --no-verify · 禁 git stash（铁律 0-3）· 禁 force push 共享分支 · 禁直推 main
· 提交走 scripts/control-tower/synova-commit
```

## 二、自开卡的条件（**四条件同时满足才可自开，否则上报**）

```
① 属本线域（文件级：见 §五 域清单）
② **判据可机器判**（附可复跑命令；不得用 grep 型作验收 —— 判例 V-02）
③ 不改架构 / 接口 / schema
④ 不与在飞 PR 写集重叠（开工前自查：`gh pr list --state open --json files`）
🔴 满足四条 ⇒ 自己开卡、自己做、自己收口、自己合并。**不必经我。**
```

## 三、自合并条件集（**四条件同时满足；缺一即等**）

```
① CI 12 检查全绿（`gh pr checks <n> --json name,bucket` 且 **pending=0** —— 判例 V-05）**
② 与在飞 PR **零写集重叠**（除 .claude/bypass.log —— 它有路径级豁免，见 #1030）
③ **已过独立复核**（fresh context、非作者、非编码者 —— 判例 V-03）
④ **串行**：一次只合一个；合完等 GitHub 重算再合下一个（判例 M-06：本地干净≠GitHub 干净）
🔴 合并后在 PR 正文追加一行（**唯一强制留痕**，便于抽查）：
   `MERGED-BY: <线名> @ <ISO时间> | AUTH: 常设授权-v1 | 条件: ①②③④ 自检通过`
```

## 四、回执形状（**统一三信号，CTO 只抽查这三项**）

```
每条回执必须给出【三信号】，其余可自由：
  ① 判据通过率：Done 判据逐条 通过/未通过 + 可复跑命令
  ② 例外清单：我【没做到】的（主动列，不许藏）—— 这是最重要的信号
  ③ 在飞/卡数：本线当前在飞 PR 数 + 未收口卡数（判有无无界堆积 —— 判例 P-07）
⇒ 我只看这三项 + 每周抽 1–2 件深入核。
```

## 六、我的自我约束（**各线有权拒收我的卡**）

```
· 我发的卡若违反 P-02（写形态而非目的）/ P-03（断言不变性）/ V-02（grep 作验收）
  ⇒ **各线有权拒收并要求我改卡。拒收不追责。**
· 我不进 PR 流程，除非：① 架构变更 ② 判据变更 ③ 优先级变更 ④ 跨线冲突
· 我发卡必须附：边界 + 判据 + 红线 + 上报条件（缺一即卡不合格）
```

## 七、授权收回（**可执行的收紧条件**）

```
以下任一 ⇒ 该线授权降一级（自合并 → 逐件报我）：
  ① 抽查发现【主动列例外】缺失（藏问题）
  ② 自合并违反过条件集（哪怕一次）
  ③ 无界堆积（在飞数超上限而不处置）
  ④ 上报形态违规（"这个怎么办？"式提问，判例 P 族）
⇒ 恢复：连续 2 周抽查通过 + 主动自曝一件自检不合格实例
```
