```

正确公式:     base = 16 + json_size + 2  ==  8 + u32[1]
自证判据: 抽出的内容 sha256 必须等于 asar 头自带的 integrity.hash
  · 我的公式 ⇒ sha256 不匹配（读到的是上一文件末尾的 `。\n` = e3 80 82 0a）
  · 正确公式 ⇒ sha256 匹配 ✅
⇒ 由 `ver-dsh` 独立发现（它给了正确基址 `base = 8 + u32[1]`，我复核成立）
```
