# 决策 Note — D1063 客户名中性化（公开仓库去标识）

## 1. 触发

公开仓库 `synova-agent/SynovaAgent` 上，客户身份信息散布在我方自有文档/代码中（`docs/synova/research/**`、`docs/plans/**`、`CHRONICLE.md`、`docs/authority/PRD.md` 等）。

## 2. 分级

| 类 | 内容 | 处置 |
|---|---|---|
| **A** | 客户资料本体（访谈原始记录/访谈提纲/诊断报告/创始人行为分析/合同/制度方案/黄金数据集） | **出库**（PR #1108/#1109，16 件） |
| **B** | 我方文档里提到客户名 | **中性化替换** |
| **C** | 代码/测试/注释里把客户当验证案例 | **中性化替换** |

## 3. 替换口径（含一处必须的保护）

```
哇呢宝贝                    -> 客户A
wani-baby / wane-baby      -> client-a
金总                        -> 客户A负责人
受保护（不改名）: data/golden/wani-baby-v1.json
                 data/golden/checksums/wani-baby-v1-checksums.json
                 wani-baby-v1
```

**为什么保护**：文档里以**真实路径**引用黄金数据集；全量替换会把路径改成不存在的文件，触发「文档真相」检查（D1 硬检查）——本批第一次推送就是这样红的（PR #1121/#1122）。

- 历史 blob 仍可匿名下载（重写历史另卡）
