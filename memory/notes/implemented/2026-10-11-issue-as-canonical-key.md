理由: |
  创始人问：「撞号问题不能像 GitHub 那样，以写入的 issues 编号为准么，自动生成的……现在的仓库没有这个么」
  ⇒ **Gitea 有这个能力**（实测：issue 号自动生成、连续递增、全局唯一 = 数据库主键，现 204 个 issue）
  ⇒ **但我们没用它**：登记件 73 项里带 `issue` 字段的 = **0**；62 项只在 `source` 备注里提到 issue 号（文字，非主键）
  ⇒ 于是**同时跑两套编号**：自动的（不会撞）＋ 手写的（会撞），而**真源是手写那套** ⇒ 撞号必然（本次 K12 `1-9` × K4 `1-9`）。
  另：面板 ↔ 登记件靠**标题里的 `[K12-XX]` 前缀**人工对应 ⇒ 改标题即断链（脆弱）。
