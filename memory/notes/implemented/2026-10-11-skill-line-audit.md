# 技能内容（`.synova/skills/line-audit-and-cards/SKILL.md`）

| 节 | 内容 |
|---|---|
| 0 | 开场三件事（读宪章 / 读机器真源 / 读现状）+ 三条红线 |
| 1 | **第 0 步 定范围**：列现状 → 抄宪章条款 → 求交集（漏项/冲突项/错归属），含 K4 实例 |
| 2 | **第 1 步 事实采集**：三条硬纪律（量 ref 不量工作树 / 带 as_of / "已交付"二元化）+ 采集清单 + 并行分工 |
| 3 | **第 2 步 归属重定**：逐项三问（哪一块 / 条款号 / 保留·改·撤·拆） |
| 4 | **第 3 步 卡面重写**：🔴 **六字段逐项定义（写什么+判据+反例）** ＋ **§〇 七问逐项定义（含范例）** |
| 5 | **第 4 步 批次划分**：三条理由（依赖链/写集冲突/上限即纪律） |
| 6 | **第 5 步 开工令**：**八节模板**（地址/卡面三处/任务/agent team/独立复核/形态/AGENTS 合规/合并权+红线+回执+冷启动） |
| 7 | **独立复核写法**：只给【交付物+一句话】，出四项，必须回写 |
| 8 | **常见坑 9 条**（全为实测事故：正则首匹配改错对象 / `\b` 不生效 / 推空分支当成功 / `--limit 100` 假数 …） |
| 9 | 收尾留痕五件 |

# 关键设计
- **六字段** = Q0 定位 / Q1 调研 / Q2 范围 / Q3 验收 / 架构层 / 写集；**Done 标准**为第 7 项（缺它不准开工）
- **§〇 七问** = ① 一句话 ② 解决什么问题 ③ 做完的推动 ④ **不做行不行** ⑤ 现在有什么基础 ⑥ 还需要做什么 ⑦ DSH 借鉴方式（照搬/参考自研/自研）；⑧ 文件位置 附于其后
- 每问都给了**写什么 + 判据 + 范例 + 反例**（如 ④「不做行不行」要分**禁令级 vs 欠账级**）
