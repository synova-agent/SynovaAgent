## A3 补修（2026-09-27，同分支 fix/a3-g10-g11-fakegreen-20260927 / PR #862）

A3 落地后实测：G10 一"真跑"就暴露两类自身缺陷，补修三件（均在同一 PR 内，未新开机制）：

1. **glob→ERE 转换缺陷**（scripts/pre-commit-check.sh，G10 段）：
   旧式 `sed 's/\*/.*/g; s/?/./g'` 把 `scripts/**/*.{sh,py}` 转成 `scripts/.*.*/.*.{sh,py}`
   ——（a）`**/` → `.*.*/` 要求 ≥2 层路径 ⇒ 匹配不到 `scripts/pre-commit-check.sh`（**D 区实测零命中**）；
   （b）`{sh,py}` 未转 alternation ⇒ 字面花括号永不匹配。修法（最小）：`**/`→`(.*/)?`、`{a,b}`→`(a|b)`，
   其余（`*`→`.*`、`?`→`.`、非锚定匹配）不动。实现要点：`(.*/)?` 的还原必须放在 `*`→`.*` **之后**
   （用占位符 `@DSTAR@`），否则新插入的 `*` 会被二次替换成 `(..*/)`（实测）。
2. **domain-neutral 路径豁免**（裁定⑧口径，禁写成"只针对账本"）：豁免 = `ownership.yaml:207` 的
   domain-neutral 路径豁免，**全量 14 项不变**（.claude/bypass.log / .claude/gate-hits.log /
   .claude/task-briefs/** / task-state/** / memory/notes/** / .codex/** /
   docs/synova/product-lines/evidence/** / .gitignore / AGENTS.md / CLAUDE.md / LOOP.md /
   knowledge/shared/README.md / docs/authority/DRIFT-LEDGER.md / docs/authority/system-registry.json）。
   这些路径的变更**不参与**「条件区域」判定（理由与 ownership.yaml 该行 D758/D774/D782 同源：
   它们的变更跟着触发方走，不构成"这条 PR 属于哪条线"的信号）。锚定 `^...$` + 点号转义，杜绝前缀误扩。
   绿腿**逐个点名**被豁免的文件（防豁免本身变成新的静默跳过面）。
   **已知边界（如实记录）**：该 14 项并非"只含账本文档"——`docs/synova/product-lines/evidence/**`
   实际覆盖 3 个**源码类**文件（`D592-run-e2e.sh` 231 行 + fixtures `fixture-green`/`fixture-red` 的
   `detect.ts` 6 / 5 行，均实测）。故本豁免的准确口径是"domain-neutral 路径豁免"，不是"账本豁免"。
3. **另两条"读不到/不判定却打绿"路径收口**（CTO 裁定⑥⑦，均实测复现）：
   - ⑦ 裸 `python`：本机 `command -v python` 无（rc=127），`:1187` 的 `python -c ... 2>/dev/null || true`
     把失败吞成空 → CRITERIA_GLOBS 空 → 走「无映射区域(跳过)」soft_pass → **仍打 `✅ 全部 13 组通过`**。
     修法 = 复用本文件既有两范式（PYBIN 三级探测 `:1592-1596` + 显式降级 `:869-876`）：探测 python3→python→py，
     三者皆无则打印 ⚠️ 并写 `.codex/control-tower/logs/degraded-events.log`，**本项不可判定（不打 ✅ 也不打 ❌）**。
     map 解析非 0 退出同样走降级（不再退化成绿勾）。
   - `#CRITERIA` 多行匹配：`grep -oE` 抽到多行（实测 3 处 ⇒ `CRITERIA='D\nD\nD'`）→ 插进 python 单引号字面量
     即 SyntaxError → 被吞 → 打绿勾。修法：抽取加 `head -1`；夹具侧仍按"每个 brief 只留一处声明"写（双防线）。
   - ⑥ 判据数据自相矛盾：`.codex/criteria-code-map.json` 的 D.description 写「所有源文件(兜底)」，
     但其 glob 不含 `tests/**` ⇒ **任何带条件区域声明的 PR 只要触及 tests/** 必红**（本卡第④件的夹具自身即
     实测受害者；`tests/control-tower/x.test.sh`、`tests/foo/y.test.ts`、`tests/a.ts` 四区全零命中）。
     修法（CTO 批准，只加一项）：D.glob 增 `tests/**`。
4. **判别性反例**（tests/control-tower/precommit-groups-injection.test.sh，已登记 ci.yml:596）：
   场景 a：domain-neutral 路径文件（.claude/bypass.log）⇒ 期望绿；场景 b：区域外真代码
