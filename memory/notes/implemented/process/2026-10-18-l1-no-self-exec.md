# L1 多任务时不得自己执行（须写 dev doc 由创始人转执行小队）

状态: implemented
日期: 2026-10-18

## 一句话

10 份包守则补「多任务 ⇒ 不自己执行 ⇒ 写 dev doc ＋ 四行开场包 ⇒ 交创始人 ⇒ 创始人用 squad-lead 开会话」，
并明确三条禁止：不许用 subagent 代替小队、不许自己 spawn 组队、不许下场写码。

## 问题

创始人 2026-10-18：「多任务的情况下，各线负责人（P1-P10）不要自己执行，要写 dev doc，
然后由创始人负责转发给执行小队。而不是自己创建子代理或者团队去执行，避免上下文污染。」

实测 10 份包守则：**「转发」0 处、「上下文污染」0 处、「不要自己」0 处** ⇒ 规则缺失。

## 决定

按创始人令写入 §八 末尾，含触发条件（待办 ≥2 件或单件 >300 行/>5 文件）、四步动作、三条禁止、理由（上下文污染 = 失去验收能力）。

## 依据

- 裁定 191/192（spawn_teammate 无 preset ⇒ L1 spawn 出来的是"另一个自己"）
- 裁定 195（Team 机制：每会话天生是 Lead、扁平不可嵌套）
- 创始人 2026-10-18 原话（见上）
