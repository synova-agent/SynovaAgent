# 同一件内数字打架 3 处

- **现象**: 三处都是我写的数字与表体或事实不符，均靠事后复算发现
- **根因**: 写头条时按印象汇总，没有回表逐项相加；复算命令未写明排除规则（本窗口件、F9/F12 类编号）
- **已做的补救**: 三处均当场勘误并在件内留勘误行，不抹痕迹
- **固化（可机械化与否）**: 可机械化：凡含 N 项/N 条/N 个 的行，要求同件存在可复跑命令（与 K3 报告门禁 R5 同款思路，可移植到 docs 检查）
- **归属**: X30 工程线自我改善；如需机器执法，落点属控制塔域（另立卡）。
