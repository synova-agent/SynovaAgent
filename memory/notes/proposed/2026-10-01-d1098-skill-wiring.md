# 预设 skill 永不挂载（缺一行接线）

- **现象**: `shanhe-researcher` 的 `skill-filesystem` 行**无 config** ⇒ `customSkillDirs` 默认 `[]`
  ⇒ 即便把 SKILL 放进 bundle 的 `skills/`，**也不会被发现**。
- **根因**: 落位时只做了"形状对齐"（照抄了 skill-filesystem 行），**漏了 config**——
  与 D1088「建包只做形状对齐」**同一族**（这次是漏配置，上次是漏 runtime 行）。
- **为什么没暴露**: T9 实战表现正确（五段式/六项/反例齐），但那是因为**会话自己按注释里的源路径读了文件**，
  不是 skill 被挂载 ⇒ **脆弱性**：路径一变/注释一删，研究员就真不知道该交什么形状。
- **修法**: 照 `shanhe-tech:115-116` 逐字补 `customSkillDirs`；SKILL.md/门禁条目.md/PERSONA.md 落位。
- **固化**: ★ 判据「grep customSkillDirs <活载体> 命中且指向本预设 skills/」应进建包验收（与 D1088 的行集差集并列）。
- **归属**: 工程线（本卡 D1098）；研究院任务书原缺此步，已回执。
