# D1112 · 治理线一窗：门禁专项吸收 + 文档治理范围修正

- **状态**: proposed
- **日期**: 2026-10-02
- **背景**: 创始人 2026-10-01 设治理线（"专门治理门禁／治理主仓文档泛滥；HTML 之前被忽略了，要纳入"）；
  CTO 出方向锚（A1–A8 + 附一吸收台账 + 附二文档治理边界），本窗受锚执行。
  实测三条结构缺陷：① 必需 context 与 job 名之间**无任何机器一致性检查**（改一个字符 ⇒ PR 永久 blocked，
  PR #931 现场：上游失败 ⇒ 3 个必需 context 消失、`mergeStateStatus=BLOCKED`）；
  ② docs-only 判据 10 处**无路径锚** ⇒ 全仓 981 个 `.json`（含 `package.json`/`tsconfig.json`）被判"纯文档"、
  10 个 job 内步骤空转；③ `.html` 257 件在**三闸之外**（#931 执行体对非 `.md` 直接放行、登记门禁不扫）。
- **决定**:
  1. **D1 吸收件**：A1–A8 逐条处置（本窗落地 A5 锚点 + A3 缺陷 B + E5 fail-safe + A1-① 一致性门禁）；
     改"哪条检查阻断合并"的语义变更（A1-②/A2/S-1/S-2/S-3）**只送审不自判**。
  2. **D2 范围件**：`.html` 与 `.md`/`.yaml` **同批**定 —— 6 类闭集（判据可判、覆盖 257/257、
     算术闭合 12+4+6+87+11+137）、E/F 层归属（**新增 F 层 = 在库但已出役，只读 + 可出库**）、
     四态出口、三闸覆盖面（**闸 1/2 对 .html 显式不适用**；闸 3 需先扩扫描面再扩白名单）。
  3. **判定面误伤**（CTO 附一要求）5 类同批处置：M-1/M-2 已闭合；M-3 另卡；M-4 并入 D2；
     **M-5（`DOCS-REGISTRY` id 跨分支撞号）本窗实测复现**（main=42 条/最大 0123；四个未合并分支
     各占 0124–0136）⇒ 判据：单文件唯一 + 取号参考 = 全局最大（同 D# 取号器做法）+ 撞号拒绝点名。
- **考虑过的其他方案**:
  1. **A7 先给 CI 加插桩步骤**（研究院原口径）⇒ 否决：GitHub check-runs **自带**
     `started_at/completed_at`，实测即得逐 job 耗时（`Control Tower(windows)`=2142s 占绝大部分）。
     插桩 = 12 个 job 各加步骤 = 重复建设 + 增加维护面。改为「只读取数脚本」。
  2. **A5 只加锚点、不动夹具** ⇒ 否决：既有夹具 6 用例**在旧正则下同样全绿**（零判别力），
     正是研究院说的「把 bug 断言成正确」；不修夹具 = 根因无守护。
  3. **`.html` 一刀切归档/删除** ⇒ 否决（CTO 附二 3）：`app/**` 11 件是**产品 UI 页**
     （`express.static('/app')` 服务）、`docs/index.html` 是 **Pages 站入口** ⇒ 删了即 404。
  4. **在 #931 上直接把 `endswith(".md")` 扩成收 `.html`** ⇒ 否决（本窗新证）：#931 白名单是
     **硬编码** `WHITELIST_PREFIX`（docstring 自称"从契约解析"与实现不符），含 `"docs/"` 前缀
     ⇒ 一扩即让 `docs/**` 下任何新增 html（含生成物、含 `coordination/`）蒙混过关，
     与契约 §3「coordination/ 一律阻断」矛盾。**W2 前置：白名单先真从契约解析，或把
     `BLOCKED_HINTS` 判红提到白名单之前。**
  5. **缺陷 B 用 `if: always()`** ⇒ 改为 `if: ${{ !cancelled() }}`：上游失败时同语义，
     但手动取消 workflow 时不空烧 CI（`Control Tower(windows)` 单 job 实测 2142s ≈ 36min）。
- **后果**:
  - 好：必需 context 不再"消失"（红是红、可修复）；docs-only 判据回到"只有文档才早退"；
    名与名一致可核（改 job 名会红而不是静默 blocked）；`.html` 有层有主有出口。
  - 坏/要长期承担：① docs-only 早退面净收窄（`.json` −482、`.md` −406、`.html` +236 文件），
    **非文档 PR 会跑更多 CI**（有意的代价）；② `.claude/task-briefs/*.md` 由早退变全量；
    ③ 新增 1 个门禁脚本 + 1 个基线表（长期维护面：基线随 branch protection 变更同步，
    `--api-check` 双向对账防漂移）；④ 判据仍是 **ci.yml 内 10 处内联副本**（未收敛单一真值源，
    收敛属重构另卡）；⑤ "同型 `.json` 面"（`docs/**/*.json` 早退）仍在，本窗未收口（另卡）。
- **取代**: 无（新增）。本件不取代任何既有决策；与 `decisions/process/2026-09-26-doc-contract.md`
  的关系 = 承接其"三闸机器可核"目标，补执行面与 `.html` 覆盖面（不改其决定）。
