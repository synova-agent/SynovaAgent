# D1157 · bypass 对账「记录判定」锚到 COMMITTED 记录行的 HASH= 字段（P0 假绿根修，待 K3/CTO 裁）

- **状态**: proposed
- **日期**: 2026-10-05
- **背景**: K3 门禁治理波次审计（报告 `2026-10-05-k3-审计报告-门禁治理波次-D1145-D1149.md` §二 提案 1）
  物理复现并裁为 **P0**：`scripts/control-tower/check-bypass-log.sh` 判断"某提交在账本里有记录"用的是
  `grep -q "$h" $LEDGER_SOURCES`（**无锚**）⇒ 该 sha 出现在账本**任何位置**都算有记录。于是
  `detected-bypass head-mismatch marker=<sha> parent=<sha>` 这类**关于别的提交的字段**也构成"记录"，
  一个从无自身 COMMITTED 记录的提交可据此过闸（**假绿**）；K3 判词点明它使"连续两次 `--no-verify`
  互相洗白"的链闭合 —— 执行证据链门禁被绕过检测行自身洗白。CTO 亲手验过同形最小例。
- **决定**（判据变更，**本件为送审提案，非已生效决策**）:
  1. 记录判定 = 「**COMMITTED 记录行**的 `HASH=` 字段值」是该提交 sha 的**前缀**；非记录行一律不算。
  2. 锚的三处取值**全部来自真实语料普查**（140 份账本 / 118,077 行 / 2,501 distinct，命令见 task brief §二）:
     ① **行首** = ISO 时间戳（2002/2003 条记录行满足；唯一例外是 `LEDGER-RETRACT` 散文行，须排除）；
     ② **分隔符** = ` | `（唯一生产写入器 `post-commit.sh:117`）或空格（1 条历史变体），两者都认；
     ③ **字段位置** = 行内 `HASH=<hex>` 的值，且长度**有界 7–40**（实测 8 位 ×10 短 sha 必须认；
     40 位 ×1992；44 位 ×1 是"两记录挤一行"的过捕，须设上界才能认回该条真记录）。
  3. 与 K3 提案字面（`grep -q "COMMITTED.*HASH=$sha"`）的三处偏差 = **精确等值改前缀**（否则 700 条短 sha
     记录变新假红）、**加行首锚**（否则散文行带 `HASH=` 即回归假绿）、**加长度上界**（否则过捕漏认真记录）。
  4. 三态退出码（0/1/2）与两条 fail-closed 路径**原样保留**；D1152 三条语义**不放宽**（fresh clone 0 /
     本机待推 1 / 首推 ref 缺失不免检，均为既有断言实跑通过）。
- **考虑过的其他方案**:
  - **`^$h`（行首就是该 sha）**：不选 —— 行首是时间戳，真实语料 **0 命中**，该锚永不成立（CTO 已提醒、
    普查已证实）。
  - **K3 字面式精确等值**：不选 —— 会把 700 条 8 位短 sha 的历史记录判红（新假红 ⇒ `--no-verify` 泛滥，
    正是 V4.5.1/V3.9 教训的成因）。
  - **只按"含 COMMITTED 子串"宽松抽取**：不选 —— 散文行（`LEDGER-RETRACT`）带 `HASH=` 即回归假绿；
    夹具⑤钉此格。
  - **顺手把写入侧 `post-commit.sh:44 _ledger_has_hash` 一起对齐**：**不选（本卡不做）**——
    那是写入侧换锚、扩大爆炸半径；实测可达性极低（新 commit sha 由内容/父/时间戳决定，提交前不可能
    已出现在账本）。已在 task brief §八.5 点名，建议 CTO 另立小卡。
- **影响**:
  - 真实语料实测**假绿面 = 76 个 OID**（只出现在 `detected-bypass … marker=/parent=` 行、无自身记录），
    旧判据对这 76 个全判绿、新判据全判红 —— 修复效果可量化、可复跑，不是理论推演。
  - 反向修正两类**既存假红**：记录值为 8 位短 sha 的 700 条、以及"两记录挤一行"被过捕吞掉的 1 条。
  - 执行方与调用点不变（`tag-bypass-wiring` 26/26、`bypass-ledger` 22/22 实跑通过）。
- **回滚**: 单一 `git revert`（1 处判据 + 夹具，无接口/schema 面）；回滚后 D1157 六条夹具转红属预期。
