# #1296 — D734 出库豁免契约化：文档治理按 DOC-CONTRACT 出血口（S2.4）

状态: proposed
日期: 2026-10-07
决策: 出库豁免的判据源从「门禁内写死的路径前缀」改为「文档契约执行体判定」；不调高文件数上限。
理由: D1028 豁免要求纯删除 + 白名单，而 PR 必带 brief（新增件）⇒ 豁免对任何真实出库 PR 永不生效；白名单前缀必随目录增长而腐（D860 已自证）。

## 一句话

创始人 2026-10-07 裁决「门禁应该按照文档契约给你的文档治理提供豁免」⇒ 新增 S2.4：
契约判为出库域（闸 3 违规）的路径，纯删除时不占 PR 预算；判据源唯一为 docs/synova/DOC-CONTRACT.md（经执行体）。

## 问题（实测，--diff-status 注入缝）

| 输入 | 结果 |
|---|---|
| 白名单内纯删除 99 件 | 豁免生效 |
| 同 99 件 + 1 件 brief 新增 | 99 > 上限 12（a' 不满足） |
| 白名单外删除 11 件 | 11 ≤ 12 |
| 白名单外删除 13 件 | 13 > 12 |

⇒ 契约 §7 存量出库（实测 719 件）在一次大 PR 下必红；历史 D1044-B1（294 件）/D1050-B2（275 件）能过，
是因为当时 D734 仍是旁路只打印，D1171 转 CI 硬阻断后第一次出库就撞墙。

## 决定

- a' 剔除 D860 治理产物（GOV_PREFIX_RE 且 GOV_EXT_RE）后，剩余变更全部为 D/R；
- b' 每个剩余路径都被契约执行体判为闸 3 违规（= 契约 §7 出库域）；
- 二者同时满足 ⇒ 豁免生效（N_FILES=0），不改 --max-files；
- fail-closed：执行体缺失 / 契约不可读（exit 2）/ 输出不可解析 ⇒ 不豁免，且逐条显式说明（不静默）。
