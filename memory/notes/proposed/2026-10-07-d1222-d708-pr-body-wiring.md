# D1222 — D708 写集豁免 `--pr-body` 真接线（卡 #1284）

- 状态: proposed（2026-10-07，治理线 B）
- 半接线族: `claim_store.py --count`（死码）· docs-only fail-OPEN · **本卡**（从不被喂正文）

## 一、现象与实证
- `grep -c 'pr-body' ci.yml` = **0**（历史）；`merge_writeset_gate.py` 只能读 `GITHUB_EVENT_PATH`。
- #1273 实证：正文 13:45:56 加 `## 写集豁免`，重跑 attempt 2 读到的仍是 13:31 旧正文；日志 3 处「豁免」全是模板文案。

## 二、修法（① 推荐路径 + ③ 文档）
- ci.yml D708 step：`gh pr view <PR> --json body --jq .body > $RUNNER_TEMP/d708-pr-body.md` ⇒ 传 `--pr-body`；
  取到 ⇒ 打印「正文来源 + 逐条解析到的豁免行」；取不到 ⇒ `::warning`（显式降级，回退快照）；
  无 PR 号（merge_group/push）⇒ `::notice` 显式说明该路径不适用。
- 契约（D708 设计稿补记）：三源表中标注各源「重跑是否刷新」；结论 = 正文豁免**必须**配合新 commit 或 `--pr-body`。

## 三、判据
「机制存在」**不得**以「代码里有该分支」证明 —— 夹具从 ci.yml 提取**真 step 正文**执行，
以 `gh`/`python3` 双桩**录制 argv**，证明 `--pr-body` 真被喂到 gate 调用；并含**去掉接线的变异体**（必红）。

## 四、回滚
- 回滚 ci.yml 的 D708 step ⇒ 退回事件体快照路径（首次运行仍有效，重跑不刷新 —— 即回到 #1284 现象）。
- 文档补记与夹具可保留（描述现状），不影响回滚正确性。
