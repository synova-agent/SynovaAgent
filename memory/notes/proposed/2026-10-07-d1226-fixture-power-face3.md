# D1226 — 面 3「夹具判别力」（卡 #1295）

## 一、缺陷类与判据
| 形态 | 特征 | 判定 |
|---|---|---|
| **2（硬红）** | `… \| grep -qv pat`、`grep -qv pat <<< "$V"`、`grep -qv pat "$FILE"` | 逐行取反 + 多行 ⇒ 任一行不匹配即 rc=0 ⇒ **判别力为假** |
| 合规 | `grep -qv pat ./literal-path` | 单文件、语义明确（整体是否缺某模式） |
| **3（仅告警）** | 行内含 `MUT`/`CLONE`/`COPY`（对变异体输出取反） | 与合法正向断言**同形** ⇒ 硬判必误报 ⇒ 只出清单 |

## 二、落点选择（line E 侦察结论，本卡实施）
- 宿主 = `check-gate-integrity.sh`（**已是 CI 必需 context**）⇒ **零 `ci.yml` 改动**、不碰 `pre-commit-check.sh`（他线在飞）。
- 与既有两面（PATTERN-SENTINEL / CI-REGISTRY）**同宿主、同扫描根、同退出码约定** ⇒ 是同一器的第三面，不是第二副本。
- 判据器自证落在**已在册**的既有夹具 `tests/control-tower/check-gate-integrity.test.sh` ⇒ **不新增测试文件**（避开密封面登记面）。

## 三、实施教训（line E 两次失败 → 本卡绕开）
| 坑 | 本卡做法 |
|---|---|
| 字符串锚点落在 `case` 分支内 ⇒ 语法错 | **行索引**：`case "$1" in` 之前插函数块；`--registry-only)` 行后插旗标 |
| 「上溯到最近 ═ 行」算错块边界（抽出 716 行） | 块首/块尾 **BEGIN/END 成对标记**，禁模糊上溯 |
| 插桩破坏默认路径 | 每次插入后 **`bash -n` + 跑既有 64 项夹具**（立即暴露"面 3 在默认路径下 degrade"） |

## 四、白名单为什么独立成文件（实测坑）
并入 `gate-integrity-baseline.txt` 后，该条目被同文件内的 **REGISTRY-BASELINE 解析器**读成隔离台账条目 ⇒
产出 3 处伪违规（「隔离台账条目失效」/「文件不存在」/「隔离条目 > 上界」）。
⇒ 白名单 = **同格式、独立载体**（`scripts/control-tower/fixture-power-baseline.txt`），并保留 `SYNO_FIXTURE_POWER_BASELINE` 覆写缝（沙箱）。

## 五、形态 0（自指防线）
面 3 首次全跑即**判了自家夹具两行红**（M10 用 `printf '…| grep -qv …' > 样本` **生成**样本 ⇒ grep 只是文本）。
⇒ 增形态 0：`grep` 前单引号个数为奇数 ⇒ 跳过（否则面 3 会误伤所有"写样本"的夹具，含它自己）。夹具 M10-5 锁死。

## 六、夹具（M10 六例，改坏即红）
1. 红：`printf 'a\nb\n' | grep -qv a` ⇒ 违规 + 点名；
2. 绿：`grep -qv nevermatch ./literal-file.txt` ⇒ 不判违规（防误伤）；
3. 白名单：同红样本 + 显式豁免 ⇒ 不判违规（豁免可见）；
4. 白名单过期（`expires=2000-01-01`）⇒ 判违规（防拔牙）；
5. **变异体**：`form2=1 → form2=0` ⇒ red 样本**不再被抓** ⇒ 证明夹具能分辨「判据退化」，而非只证"补丁生效"（防自指坑）；
6. **形态 0**：单引号串内的样本生成行 ⇒ 不计违规（自指防线）。
