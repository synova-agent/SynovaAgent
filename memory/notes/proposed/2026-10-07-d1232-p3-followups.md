# D1232 — P3 跟进（卡 #1309）

- 原文：`#   …；基线见 scan-fullwidth-vars-baseline.txt（只减不增）。`
- 实测：该文件**不存在**（本分支与 main 均无）⇒ 悬空；且与 D1228「扫描器无基线机制 / 棘轮登记在配对夹具（禁双源）」矛盾。
- 改法：指向**真实注册处** `scan-fullwidth-vars.test.sh §12d`（`--paths tests` 违规 = 0），并显式写「本扫描器无独立基线文件」。

## 二、P3-②：形态 0 引号奇偶漏判（确定性假阴性）
| 探针（生产 `--fixture-power-only` 实跑） | 旧判据结果 | 期望 |
|---|---|---|
| ① `if ls \| grep -qv sample; then echo A; fi` | 违规 1 ✅ | 违规 |
| ② `echo "it's fine"; if ls \| grep -qv sample; then echo A; fi` | 违规 0 ❌（撇号在**双引号串**内，同为奇数） | **违规** |
| 真生成器 `printf '…\| grep -qv …' > 样本` | 豁免 ✅ | 豁免 |

**改法（卡面推荐 ①，一行级）**：豁免条件从「奇数引号」收紧为
「奇数引号 **∧** 本行含 `>[[:space:]]*[^&[:space:]]`（**文件重定向**）」——
样本生成器都要写文件；纯"含撇号的普通行"无重定向 ⇒ 照常判违规（**不放宽成一律跳过**）。
