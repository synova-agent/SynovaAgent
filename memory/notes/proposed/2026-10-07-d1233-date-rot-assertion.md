# 日期腐化类：断言不再写死日期（D1233 · 卡 #1302）

- 状态: implemented · 编号 **D1233** · 卡 **#1302**（Lead 派单，verifier 最小定位）
- **台账分离声明**：本类（**日期腐化**）与括号类（`$VAR（`，卡 #1288 / #1301 / 分片 D9204）是
  **不同台账**：括号类是「**语法崩溃掩盖失败信息**」，本类是「**判据本身随日期过期**」。
  两者唯一共同点是「测试存量红 ⇒ 失败信息不可信」。

## 一、现象与机制（我实跑复现，非转述）

`tests/control-tower/session-worktree-isolation.test.sh:63`
```bash
grep -q '2026-08-27' "$SB1/.claude/current-brief.D539" && ok "参数优先: 含最新 brief 名" || no "参数优先: brief 名异常"
```
复现：`bash tests/control-tower/session-worktree-isolation.test.sh` ⇒ **rc=1，`25 通过, 1 失败`**。

**机制（亲手验证）**：沙箱跑 `task-start.sh "参数优先" --session-id D539` 后，
```
$ cat <沙箱>/.claude/current-brief.D539
2026-10-07-auto.md        ← **当天**日期（今日 2026-10-07）
```
而被测断言 grep `2026-08-27`（写死的历史值）⇒ **恒红**，与代码正确性无关。
即：**判据自带过期时间**，写下它的那天起就开始腐烂。

## 二、修法（不写死日期 + 比旧断言更强）

```bash
# 契约: @input 任意字符串 / @output 0=形如 YYYY-MM-DD-<slug>.md，否则 1
_is_brief_name() { printf '%s' "$1" | grep -qE '^[0-9]{4}-[0-9]{2}-[0-9]{2}-.+\.md$'; }
```
`:_63` 改为**两条**断言：
1. **形态合法**（与运行日解耦，不再写死）；
2. **可解析到沙箱里真实存在的 brief 文件**（`[ -f "$SB1/.claude/task-briefs/$_bn1" ]`）——
   比旧断言**更强**：旧断言只 grep 一个日期子串，新断言要求「指向的 brief 真的在」。

**刻意不做**：不查「日期是否=今天」（形态判据不该依赖运行日，否则又是一种隐形写死）。

## 三、判别性（卡 #1302 ③）

§9 新增 5 条：4 条**必错**输入必须被拒 + 1 条**正对照**（真名必须被接受，证明不是「一律拒绝」的假判别）。
- 错形：`2026-8-7-auto.md`（非零填充）· `2026-08-27`（**旧写死值的形态**：裸日期无 slug/后缀）·
  `auto.md`（无日期）· `2026-10-07-`（空 slug / 无 `.md`）。
- **变异体实证**：把判据放宽为 `^[0-9]+-[0-9]+-[0-9]+` ⇒ 夹具 **3 条转红、测试 rc=1**（已跑）。
  恢复后 `32 通过, 0 失败`。

## 四、同类扫描（② 要求：先报不改）—— 结论：**该类没有第二例**

| 口径 | 命令 | 实测 |
|---|---|---|
| 宽（一切硬编码 `YYYY-MM-DD` 字面量） | `git grep -nE "'20[0-9]{2}-[0-9]{2}-[0-9]{2}'" origin/main -- tests/` | 26 文件 / **59 行** |
| **窄（腐化形状：硬编码日期出现在匹配位）** | `git grep -nE "(grep +(-[a-zA-Z]+ +)*'20…'\|toContain\('20…'\)\|=~ *'20…')" origin/main -- tests/` | **恰好 1 条 = 本卡修的那一行** |

**为什么窄口径才是判据**：腐化的充要条件是「硬编码日期被用来**匹配一个按当天生成的值**」。
宽口径的其余 58 行是**确定性用例**（纯函数映射 / 夹具输入 / 事件时间戳），与运行日无关。
抽验 2 个高风险候选（同时含硬编码日期与运行时取当日的文件）确认合法：
- `tests/l4/graph-bridge.test.ts:243` — `expect(deriveValidFrom('2026-Q1')).toBe('2026-01-01')`：纯函数映射 ✓（同文件 `Date.now()` 仅用于随机 ID）
- `tests/growth/goal-lifecycle.test.ts:18` — `deadline: '2026-12-31'`：夹具**输入** ✓（`createdAt: new Date()` 是无关观测字段）

⇒ **不扩大改动面**（避免把 58 行合法用例改坏）；日后若要机械化防复发，
判据应是「硬编码日期是否出现在**匹配位**」，而不是「是否出现日期」。

## 五、判据（可复跑）

```bash
bash tests/control-tower/session-worktree-isolation.test.sh   # rc=1 → 0；25·1 → 32·0
# 正确判据: 不再有「硬编码日期当匹配器」的断言（**不是**字面量计数=0）
grep -cE "grep +-[a-zA-Z]* *'20[0-9]{2}-[0-9]{2}-[0-9]{2}'" tests/control-tower/session-worktree-isolation.test.sh   # = 0
# 字面量 2026-08-27 保留 3 处（1 注释 + 2 负向夹具）——把判据写成「计数=0」是坏判据，会禁掉判别性输入
# 判别性: 放宽 _is_brief_name 为 '^[0-9]+-[0-9]+-[0-9]+' ⇒ 3 条夹具转红、rc=1
```
