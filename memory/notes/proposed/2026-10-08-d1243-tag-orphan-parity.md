# D331 第二段补孤儿豁免：判定改读共享真值（D1243 · 卡 #1312）

- 性质：**判据变更** ⇒ 提案 → K3 过审 → CTO 裁（作者不自行合并）。
- 定位：CTO 发现 + Lead 逐行核实 = **一个缺陷两半**；本卡 = **B 半**（`pre-push-check.sh`），A 半在 `synova-commit`。

## 一、病灶（**两段不对称**，同一个 D520 只治了一半）

```bash
# 第一段: 遍历所有 V*.*.* tag
for t in $(git tag -l 'V[0-9]*.[0-9]*.[0-9]*'); do
  git merge-base --is-ancestor "$t" HEAD 2>/dev/null || continue   # ← **孤儿豁免**
# 第二段: VERSION.md 最新版本
elif ! git merge-base --is-ancestor "$ver" HEAD; then
  TAG_FAIL += "$ver 非 HEAD 祖先（VERSION.md 最新版本锚点断裂）"   # ← **孤儿在此被拦**
```
⇒ `VERSION.md` 最新版本号**全局唯一** ⇒ **本机任一同名孤儿 tag ⇒ 全机、全分支、任何 push 全红**。
**全队实痛**：D520 实证 ×3；line B / line F / line E / Lead **各自删过本地 tag** 才能继续。
⇒ 现场代价还包括：**报错不告诉你是"本机残留"** ⇒ 执行方**合理地不敢删别人的 tag**。

## 二、上位根因（CTO 类级洞察）

**「判定面混入本机私有状态」**（R26 mock id / R28 探针写进真配置 / R32 本机孤儿 tag）
⇒ 共同根因 = **没划清「共享真值 vs 本机残留」**。
本处的划法：
| 事实 | 性质 |
|---|---|
| 本地有该 tag | **本机私有状态**（不能作为对**他人**的阻断理由） |
| tag 是 HEAD 祖先 | **共享真值**（分支谱系，客观） |
| 远端有该 tag | **共享真值**（`ls-remote` 权威查询，范式同 D1219） |

## 三、修法

1. **第二段补孤儿豁免**：tag 存在但非 HEAD 祖先 ⇒ feature 侧**黄色中间态（不阻断）**；**main 侧仍硬阻断**（锚点断裂是客观事实）；
2. **判定读共享真值**：`git ls-remote --exit-code --tags origin refs/tags/$ver`，**显式捕获 rc** 分三态
   （0=远端存在／2=远端确无／其余=**不可查** ⇒ 显式降级，**不把「空」与「失败」混为一谈**）；
3. **报文自证四项** + **解除命令**：feature 与 main 两侧都给「① `git tag -d` ② 在真实提交上重指」；
4. **成功文案名副其实**：见 §五。

## 四、本卡自己踩的坑（被夹具抓住，留痕）

**隐藏顺序依赖**：远端态查询初版放在 `ver` 赋值**之前** —— 本函数开头 `local … ver=` 会清空同名外层变量
⇒ 查询变成空 pattern（`refs/tags/`）⇒ `ls-remote --exit-code` **恒返 2** ⇒ **永远误判「本机独有」**。
⇒ 被**我自己写的夹具 G′ 用例**（「远端**有**该 tag」）当场抓住，已移到 `ver` 赋值之后 + 注释留痕。
（另：本卡夹具里我又踩了一次**全角标点吞变量名**（`EC=$EC（…`）——**第 5 次**；棘轮 tests/ 面当场转红，已修。）

## 五、文案：既要名副其实，又要**零跨线改动**

旧成功行 `✅ …（孤儿 tag 已豁免）` 在**修好前是自相矛盾的**（第二段并未豁免）——Lead 现场正是被它误导
（"撞了 4 次都当副作用，没去读第二段"）。但该**字面量**被**他线夹具** `tag-bypass-wiring.test.sh` 断言
（「输出明示豁免（不静默放过）」）⇒ 直接改掉会打破他线夹具（我首版即撞红）。
⇒ 正解：**改真行为 + 保留该子串 + 补"豁免范围/清单"** ⇒ 修好后该措辞**才名副其实**，且**零跨线改动**两边全绿；
并在本卡夹具里加**兼容锁**断言钉住该子串，防后人再改坏他线夹具。
