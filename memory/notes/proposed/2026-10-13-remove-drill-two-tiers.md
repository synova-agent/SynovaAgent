```

   exclude: ["…/_extinct/**"] ⇒ 错误数仍 29（与基线完全相同）
   模板字面形态 exclude: [X, "**/*"] ⇒ error TS18003: No inputs were found（探针恒报自身错）
② 派单件的字面锚 3-8→3-5 **该红不红**

③ 第二档底座**全仓零命中**：provides / capabilities.min / capability.yaml / host.adapter
   ⇒ 造 MockHost = **造产品语义**（越界）；红队3 攻③ 预言的"永远绿"必然发生
```

## 决策

### 第一档（类型层）
- **主路** `probe-exile-compile.ts`：`ts.createProgram` ＋ 自造 `CompilerHost`，
  对落在 `PATHS(X)` 下的文件 `fileExists/readFile/getSourceFile` 一律回答"不存在" ⇒ 依赖方得 `TS2307`。
  **零文件系统改动**、可逐包批量。
- **复核路** `exile-tree.sh`：`git worktree` 隔离树里**真搬走** X 的文件，跑**真 `tsc`**。
- 🔴 **两路必须逐行一致**；不一致 ⇒ 该行判"判不了"（**不取多数**，禁"以谁为准"的裁量）。
- **判据取差集**：锚 `918f2adea` 上 `tsc --noEmit -p tsconfig.json` **本来就是红的**
  （33 条；其中 25 条在 `extensions/sentinels/_extinct/**`，经 `src/sentinel/types.ts` 的 `import type` 进编译域）
  ⇒ **不能**用"是否出现 error TS"当判据。

### 第二档（交付期）
- **不造 MockHost**：宿主 = **隔离宿主树**；`provides` 退化为"**该包的文件在不在树里**"；
  `min` 用**真源已有的** `blockAcceptance[].run` / `items[].acceptance[].run`（并按它自己的 `expect*` 判过不过）。
- **摘除面用项级 `paths`**（块级有 **43 对字面包含**／107 条覆盖 ⇒ 摘 X 必连带摘掉 Y 自己 ⇒ 红因不指向依赖）。
- **步骤 0 闸门**（先验演练器本身）：0a 摘 `extensions/ontology/edge-types/*.json` ⇒ `check-ontology-fields.sh` **必红**；
  0b 全量 ⇒ **必绿**。不过 ⇒ **演练器判废、exit 2、全部输出作废**。
- **摘除灵敏度筛选**（防"永远绿"）：先自摘 **Y 自己的项级写集**（**减去判据命令自身引用的文件**，
  否则"自摘必红"是同义反复）⇒ 判据必红；**仍绿 ⇒ 该判据不在摘除面上 ⇒ 它的"绿"不算数**。
- 判据基线不绿（如 `sqlite3 data/synova.db` 在真源库无 `metric_readings` 表）⇒ 判不了，**不是**判据通过。

## 三态口径（写死）

```
0 = 成了 / 全部可判且无假声明
1 = 真红（假声明 / 存在"判不了"行 / 两路不一致）
2 = 判不了（环境 / 真源 / 树 / 步骤 0 不过=演练器判废）
```
🔴 **"判不了"永远不许并进"绿"** —— 三类判不了都**逐行点名**：
`X 编译域无文件` / `Y 编译域无文件` / `paths 字面包含`。

## 新增教训（写给下一个改壳的人）

- **macOS `/bin/bash` 是 3.2，没有 `globstar`** ⇒ `src/l4/**` 在壳里退化成单层 `*`（**少摘且静默**）。
  ⇒ 遍历/搬运一律 Node（`exile-tree-core.ts`），壳只做编排。
- **`$dir` 紧跟全角字符时，bash 3.2 会把多字节字节并入变量名** ⇒ `unbound variable`。
  ⇒ 壳里**所有变量引用加花括号** `${dir}`。
- `git worktree` **共用 `.git` 但不共用 `node_modules`** ⇒ 建树时必须补软链（缺了必 127）。
