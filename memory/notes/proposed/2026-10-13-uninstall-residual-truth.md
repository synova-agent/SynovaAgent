# Note: 可卸载性真值实测（CTO 裁定 074 步 4）

## 触发场景

裁定 074 四步的最后一步。**与前两步是不同维度**：

```
步 2/3 判「缺了 X，Y 还能不能跑」  ⇒ 功能（依赖）   → 已做：双路 182/182 一致
步 4   判「把 X 拿掉之后，残留是什么」⇒ 痕迹（清理）  → 本件
判据：卸 X ⇒ 残留集 = ∅（或已声明保留）
```

## 复用而非重建（派单件 §二）

隔离树用 `exile-tree-core.ts`，摘除用 `check-customer-deps.ts --tree`，
**只在原件上加 `--phase uninstall`，不新开文件**（两份实现必然漂移）。

## 决策（口径，写死）

- **卸除面** = 块级 `paths`（= 该块 items 的 `paths` 并集，已被对账门禁验过）。
- **七类残留**各给一条**可跑命令**（回执直接贴）：目录 / 配置 / 表 / 索引 / 引用 / 缓存 / 登记。
- **五个态**：`干净` / `不干净`（逐条列）/ `判不了`（说明为什么）/ `声明保留`（**必须点名依据**）/ `不适用`（**测不到 ≠ 干净**）。
- 🔴 **三类"弱标记"口径**（本件实测得出，防假红）：
  1. **块 id 一律弱标记**（只认被引号包住的形态）—— 本仓 `K3` **同时是审计角色名**，
     裸 `grep -w K3` 实测命中 **269 行**，绝大多数是"K3 审计 / K3 P0 事故"而**不是包引用**。
     弱化后 **269 → 4**。**不弱化 = 把干净的包判成重度不干净**。
  2. **纯数字项 id 也弱标记** —— 实测 `2-4` 命中正文 `每季度 3-5 个 O,每个 O 配 2-4 个 KR`。
  3. **本件自带夹具**（`customer-deps-candidates.json`，步 2/3 落的候选值表）**单列一个数**，
     既不混进"产品残留"，也**不隐藏**（原始/历史留痕/夹具/产品残留四数并给）。
- 🔴 **两条"不算残留"**（否则必然假红）：
  - `.dsh/` **不是缓存**（那是受版本控制的 DSH 插件源码）；
  - `.exile-quarantine/` **不计入**（那是**本件自己的摘除机制**，此刻正装着刚卸下来的东西）。
- **声明保留必须点名依据**（没依据的保留**不算保留**，判"不干净"）：
  - 登记面 → `docs/synova/coordination/施工项登记.ts:41`「本件是**施工项账**，不是卡账」
  - `_extinct/` 归档 → `AGENTS.md §5.1`「卸 = 移 `_extinct/` ＋ 重扫」

## 实测（锚 a3f09467e，隔离树 `/tmp/exile-tree-u`）

```
干净 20 ｜ 不干净 26 ｜ 判不了 0 ｜ 声明保留 14 ｜ 不适用 38
卸除面顶层条目合计 254 条 ｜ 🔴 与他包共用 16 条
```

**三类主要残留**（逐条证据见回执）：
1. **引用**：12/14 包不干净（命中多为注释里的 id、门禁冻结名单 `LEGACY_FROZEN`、原始脚本）
2. **索引**：9/14 包不干净（content-registry ＋ `extensions/**` 里指向"已移除落点"的**悬空字符串**）
3. **目录**：4/14 包不干净（**空目录残留** —— 按字面量卸 `cycles/industry/*/*.cycle.json` 会留下空目录）

**"表"类的"干净"要打折说**：真源只有 K3 声明 `createsTable: metric_readings`，
而该表**在生产库里本来就不存在** ⇒ 本类的"干净"是"**无表可残留**"，**不是"卸载把表删了"**。

## `_extinct/` 够不够：**两半面分判**（结论：运行期够，编译期不够）

- ✅ **运行期够**：生产 loader 显式跳过 `_` 前缀目录
  （`src/sentinel/sentinel-loader.ts:82: if (entry.name.startsWith('_')) continue;`）⇒ 归档件**不会被装回**。
- ❌ **编译期不够**：`src/sentinel/types.ts` 仍有 **12 处** `import type` 指向 `_extinct/`，
  这些归档件**仍进编译域**，且**已经坏了**（本机 `tsc --noEmit` 命中 `_extinct` **25 条**，是基线 29 条的主体）。
- ❌ **无归档规约、无回归判据**：`extensions/sentinels/_extinct/` 下**无 README/规约文件**；
  `tests/` 下**无** `extinct` 相关判据 ⇒ "移进去了"这件事**没有任何门禁校验**。
