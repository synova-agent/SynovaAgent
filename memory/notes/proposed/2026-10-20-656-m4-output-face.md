## 决定

1. **loader（M4-A，`electron-renderer/src/lib/measurement-trends.ts`）**：真 fetch `GET {base ?? getApiBase()}/api/sentinel/metrics/readings?view=trends`；`base` 可注入（验收件注入真 express）。降级（铁律 11/31）覆盖 `!res.ok`／非合法 JSON／形状非法（根非对象、缺 summary 数组、summary 项缺字段）／网络异常 ⇒ `{ok:false, degraded:true, summary:[], errors:['<CODE>: <原因>']}` 且 `console.warn` 留痕，**永不抛**；服务端 `ok:false` ⇒ 原样透传 degraded＋errors、summary 置空（不确定的数据不交给渲染层）。**本任务不写该文件**（写集属 M4-A）。
2. **纯展示（M4-A，`MeasurementTrendSection.tsx`）**：零 hook/effect/fetch/store；根 `data-testid="measurement-trend-section"`、标题字面量 `测量值＋趋势`；ready 每指标一条 `measurement-trend-item`（metricId＋值＋unit＋`data-trend` 方向符号＋latestAt）；empty/degraded/loading 各有显式标记；一页纸入口 `data-testid="measurement-to-onepager"` **任何 state 都渲染**、回调缺失不崩。方向由 `deriveTrendDirection(changeRatio)` 推导（`null ⇒ 未知`，**禁 flat 恒值兜底**）。
3. **容器（M4-A，`MeasurementTrendContainer.tsx`）**：`useEffect` 调 `loadMeasurementTrends(base)`；状态映射唯一收口 `deriveState`（首渲染 loading；`!ok||degraded ⇒ degraded`；`ok 且 summary 空 ⇒ empty`；否则 ready）；渲染 `<MeasurementTrendSection …/>`。
4. **挂载（本任务，`RightPanel.tsx:24` import ＋ `:460` 挂载）**：在 `GAWorkspaceTabs` 的 `<>` 内、tabs 条（`:462`）**之前**挂 `<MeasurementTrendContainer onOpenOnePager={() => setTab('report')} />` ⇒ 区块与入口在任何 tab 下可见；**不新增 tab、不改既有 tab 语义/文案、不动 `DiagnosisReportTab`**；「一页纸接回」= 导航入口（切既有 report tab），非把测量值写进报告内容。
5. **验收件（本任务，`tests/acceptance/mvp1-m4-output-face.test.ts`）**：T1 真 express＋真文件库（`mkdtemp`＋`SYNOVA_DB_PATH`）＋真 fetch（正例断言 latestValue/previousValue/changeRatio/unit/count；反例内建断连端口/HTTP 500/形状非法/坏 JSON/服务端 degraded）｜T2 render 桥（ready/真 API 数据/empty/degraded/loading/边界）｜T3 wiring 源码断言（RightPanel import＋挂载＋`setTab('report')`；容器调 loader；loader 真 URL＋降级留痕）。T2「真数据」用例复用 T1 结果 ⇒ 摘 API/fetch 时两处同红（判据③抓手）。反例变异（摘入口/摘挂载/方向恒 flat）由独立自验员执行，本件不含变异代码。
6. **不做**：不重建 one-pager、不新建报告组件/UI 框架/路由/独立看板；不引新依赖（`package.json` 不在写集）；不改 `src/**`、`tests/electron/**`、`app/**`（裁 149 裁4：同一界面 = 桌面端）。

## Known Limitations（做不到什么 —— 每条都是「做不到」，不得改写成「已核过」）

1. **render 桥不证像素/交互**：`renderToStaticMarkup` 零依赖等价实现只证「渲染树含什么」，不证 Electron/浏览器像素、布局与点击行为；一页纸「点击可传出」由「元素在场」＋ T3 源码断言（`onClick={onOpenOnePager}`）共同证明，真机行为未验。
2. **容器不在桥覆盖内**：`useEffect` 取数路径不做 render 测试，只证源码接线（调 `loadMeasurementTrends`）；运行期取数由 loader（T1 真调）覆盖。
3. **`app/**` Web UI 未动**：同一界面 = 桌面端（裁 149 裁4）；同源 Web 入口未提供，若产品改判 Web 为同一界面须另开批。
4. **一页纸是导航入口，不是内容扩展**：只切到既有 `report` tab（`DiagnosisReportTab`），不把测量值/趋势写进报告正文；报告内容扩展另议。
5. **loader 无超时/取消**：上游挂死时容器停在 loading（不白屏，但不自动降级）；无 days/limit/metricId 查询参数（M4 只取默认窗口）；无轮询/缓存/重试。
6. **只做 dev/source 形态**：客户形态（bundle/桌面安装包/容器）在 C4 阶段 2 前不成立（裁 161/225）；CI `--changed` 可能跳过新 acceptance 件（裁 223）⇒ 以本地原始输出＋PR 为准。
7. **门禁配套件只覆盖本任务写集**：brief Q2 写集 = 本任务 4 文件（按 L2 派单逐字），M4-A 三文件在「不做什么」中排除；批次提交时的 Q2 认领覆盖由队长/L1 收口处理（未擅自扩写集）。
