# #953 自动化工作流一期（裁 367）

## 做了什么
- `scripts/control-tower/ledger-sync.sh`：把 `local-main` 的 merge 提交自动同步进 #918 §G（幂等，state 文件 gitignored）
- `scripts/control-tower/auto-merge.sh`：对 open PR 逐个判「四条件 can ＋ 变更集不触受保护路径」，满足才允许自动合；**默认 dry-run**
- `tests/control-tower/automation-scripts.test.sh`：配对测试 11 例（无 token／非法参数／dry-run 生成／apply 无网 fail-closed）

## 为什么
去掉「合并／记账」环节的人工往返（裁 367 一期）；红线不变：**受保护路径与 A 类一律人合**。

## 已知限制
1. `ledger-sync` 的行内"验收要点"无法自动生成，统一写"自动同步（详见 #N）"；
2. `auto-merge` 只判路径与四条件，**不做语义裁决**；
3. state 文件不跨机（gitignored）；多机并行需各自 state。
