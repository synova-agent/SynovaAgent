# #953 自动化工作流一期（裁 367）

## 做了什么
- `scripts/control-tower/ledger-sync.sh`：把 `local-main` 的 merge 提交自动同步进 #918 §G（幂等）
- `scripts/control-tower/auto-merge.sh`：对 open PR 逐个判「四条件 can ＋ 变更集不触受保护路径」，满足才允许自动合；**默认 dry-run**
- 配对测试三件：`tests/control-tower/ledger-sync.test.sh`（14 例）＋ `tests/control-tower/auto-merge.test.sh`（7 例）＋ `auto_merge_mock_test.py`（mock 行为：分页／改名绕过／负对照）

## 复核退回后修的三条（#954 round 1）
- **B1 fail-open**：`auto-merge` 取变更文件失败时，`$(... || exit 2)` 只退出子 shell ⇒ 父脚本继续用空列表判定并合并。现改为：命令替换后检查 `$?`，失败/空 ⇒ **exit 2**；`files` 端点补分页（防 >100 文件挤出受保护路径）。
- **B2 假绿**：open PR 列表 API 失败被吞成"无 open PR" + exit 0。现为 **exit 2**（与 header `E_NET` 契约一致）。
- **B3 state 不落盘**：`mapfile` 在 macOS bash 3.2 不存在 ⇒ 改为 `git log --merges … | head -n 1` 取水位；补 `SYNO_LEDGER_SYNC_MOCK_WRITE=1` 测试接缝与"state 落盘＋重跑幂等"用例。
- **F-NEW-1 D520**：两脚本裸 `python3` ⇒ 改 **PYBIN 三级探测**（`python3→python→py`，含 PYBIN 标记供平台扫描）。
- **F-NEW-2 state 假绿**：state 起点非法 ⇒ **exit 2 `E_STATE`**（不再吞成"无新增"）；`--limit 0/缺值` ⇒ `E_USAGE`。
- **F-NEW-3 改名绕过**：`files` 收集**并入 `previous_filename`**（受保护文件被改名挪走也拦得住）。
- **F-NEW-4 行为用例**：加 `SYNO_GITEA_BASE` 接缝；配对测试补"API 不可达 ⇒ exit 2"（B1/B2 的回归网）。
- 另修：`--limit` 非整数 ⇒ exit 2；`@exit 1` 与实现对齐（API 写失败 = 1，环境失败 = 2）；`SYNO_AUTO_MERGE_BASE` 真接线；`urlopen` 全加 timeout；受保护匹配大小写不敏感。

## 为什么
去掉「合并／记账」环节的人工往返（裁 367 一期）；红线不变：**受保护路径与 A 类一律人合**。

## 已知限制
1. `ledger-sync` 行内"验收要点"无法自动生成，统一写"自动同步（详见 #N）"；
2. `auto-merge` 只判路径与四条件，**不做语义裁决**；TOCTOU（取 head 后到合并前的新 push）未防，靠四条件的 ③ 回执指纹兜；
3. state 文件本机、不跨机；
4. 两个 `.sh` 配对测试**尚未接 CI**（无消费者；`auto_merge_mock_test.py` 由 `auto-merge.test.sh` 调用）——属已知缺口。
