# 2026-10-24 · #942 DOCS-REGISTRY 重号无断言（补「id 唯一」硬判据）

## 现状（实测，锚 `local-main = ac41ae13c`）

1. **体系无重号断言**：#934 的零上下文验收把 `DOC-0255` 手改成 `DOC-0256` 制造重号，四道门禁
   （`doc-registry-gate`／`check-doc-truth`／`check-doc-contract`／`sync-dsh-skills --check`）**全绿**；
   全仓 `grep -rn "uniq -d" scripts/ tests/` = 0 命中 ⇒ 唯一性只靠人眼。
2. 后果：#934 的清理（4 对历史重号）只有一次性价值，复发无人拦。

## 决定

- 在**一处**加硬判据（选 `scripts/doc-system/doc-registry-gate.sh`，`#942` 优先项）：
  `- id: DOC-<n>` 重号 ⇒ 逐条 `❌ 重号: DOC-<n>（出现 k 次）`＋汇总行报重号数＋**exit 1**。
- **不许只告警**：唯一性是硬判据（不是风格问题）；`doc-registry-gate` 原本只有"未登记"一条硬判据，
  本次补第二条，**不新增门禁组号**（并入现有 doc 闸）。
- 配对测试补 I1（注入重号 ⇒ exit 1＋点名）／I2（还原 ⇒ exit 0）／I3（存量真实仓 ⇒ exit 0）。
- 同 PR 校正 K3 预设文案：`合完等 GitHub 重算` → `合完等 Gitea gates 绿（pending=0）`（裁 328 口径）；
  bundle 随 persona-block 重生成并落位，`--consistency` 复核。

## 已知限制

- 判据只查 **`- id: DOC-<n>` 形式**；其它注册表（`GATE-INVENTORY`／`WIRING-REGISTRY`）的唯一性由
  `check-registry-invariants.ts` 的 ① 唯一性承担，不在本 PR 扩面（避免两处重复判据）。
- 重号检测是**文本层**（同一文件内 id 重复），不校验 `path` 重复或指向不存在文件（那是 C1/C2 既有面）。
