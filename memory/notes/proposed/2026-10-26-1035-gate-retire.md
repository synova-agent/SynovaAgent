# #1035 裁 409 收口：组级降级（5/6/9/10/13）+ CI ④ report-only

## 机制
- **子 shell 包裹**：组 5/6、组 9/10、组 13 整段在 `( … )` 内执行 ⇒ 段内计数/`exit` 不污染父 shell。
- **段末回传**：段内 `[ "$HARD_FAIL" -gt 0 ] && exit 1 || exit 0`；父层 `_seg_rc=$?`；
  `SYNO_GATE_STRICT_LEGACY=1` 时 `_seg_rc≠0 ⇒ HARD_FAIL++`（恢复硬阻断）。
- **确定性自检缝**：`SYNO_DOWN_SELFTEST=<组号>` 在段内注入失败并 `exit 1`。
- 删掉无效的「按检查名子串匹配」降级（实测为 no-op）。
- CI ④ 复现器自检改 **report-only**，`SYNO_REPRO_STRICT=1` 回滚。

## 两态证据（现场）
```
组5/6：SYNO_DOWN_SELFTEST=5             → rc=0（降级）
        + SYNO_GATE_STRICT_LEGACY=1     → rc=1（仍红）
组9/10：同上 → 0 / 1
组13：  同上 → 0 / 1
干净树（无注入）                        → rc=0、✅ 全部 12 组通过
负对照（非降级组，抽样夹具）            → g1/g2/g7/g12 仍 RED_CONFIRMED
```
