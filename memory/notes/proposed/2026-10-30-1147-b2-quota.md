# Note — B2 配额双闸（proposed · #1147 余项）

> 任务: #1147（Issue 号身份；本 Note 不写 D# 形态，避免 check-notes-lifecycle 误判僵尸）

## 现状

- `#1147 T2.5` 已产出 `gate_meta` 六字段（117 行，`scripts/control-tower/gen-gate-meta.sh --check` 一致），但**配额双闸未实现**：`quota:true` 无硬上限，`gate_meta` 数字无人判。
- `scripts/control-tower/verify-governance.sh` 现行三道判据（G2/G6/G10），无 G11；`gen-gate-meta.sh --emit` 失败路径未映射 exit 2（假绿入口①）。
- 真树实测口径（T2.5 生成物）：`quota_true=39 / doc=2 / non_doc=37 / total=39 / bypass=0` ⇒ non_doc 超编 7（>30），total 未超（39≤45），bypass 未超（0≤8）。

## 决定

1. `gen-gate-meta.sh` 新增 `--quota` 子命令（与 `--emit`/`--check` 同级）：
   - 只读 `--inv` 文件的 `gate_meta:` 段（生成物），不重算、不写文件；
   - 计三桶：`non_doc`（scope=non-doc）、`doc`、`bypass`；`total = non_doc + doc`（bypass 不占 total）；
   - 超编（non_doc>30 / total>45 / bypass>8）⇒ 逐条打印 `QUOTA-OVER` 并 exit 1；未超 ⇒ exit 0；段缺失/行非法/quota_scope 非法 ⇒ degraded 并 exit 2。
2. `gen-gate-meta.sh --emit` 失败 ⇒ 一律 exit 2（E_EMIT_TMP / E_EMIT_EMPTY / E_EMIT_SHAPE / E_INTERNAL），成功态输出字节不变。
3. `verify-governance.sh` 新增 G11（旁路项，不进 pre-commit 主路径）：调 `gen-gate-meta.sh --quota`，rc=0 ⇒ PASS；rc=1 ⇒ FAIL 并原样转印 `QUOTA:` / `QUOTA-OVER:` 证据行；rc=2 或生成器缺失（E_GEN_MISSING）⇒ DEGRADED，整体 exit 2。汇总 3→4 项，末行 `GOVERNANCE: x/4 PASS`。

## 依据

- 创始人 D761-C4（配额制）与 §4.1（判不了 ≠ 通过，fail-closed）；
- 同卡 T2.5 已把双闸（≤30/≤45）显式留作 `#1147` 剩余部分，本批为该项收口；
- 三态退出码既有约定（`scripts/control-tower/AGENTS.md`）：0 通过 / 1 真红 / 2 判不了，信号量==0 不许当绿。

## 已知限制

- **bypass 桶无标记源**：当前生成器尚无「旁路登记」字段来源，bypass 恒为 0，属前向能力；本批不造假数据。
- **G11 只报生成物数字**：`--quota` 的输入是 `gate_meta` 段（artifact），手改 artifact 的防伪由 `gen-gate-meta.sh --check`（B3 同源比对）与 `check-gate-inventory.sh` 的 R10 承担，非本命令。
- G11 不进 pre-commit 主路径（避免门禁链耗时与重复判），只在 verify-governance 总闸内。

## 未决

- 真实 bypass 标记源的落地（需要先在 `gate_meta` 六字段之外增加来源字段，属 schema 变更，需另裁）；
- 收口动作（退役/降级超编的 7 条 non-doc）不在本批范围，归 L1 收件闸之后的配额收敛批次。
