# Note — #1210 W0 附：sealed-tests 扩面 ＋ 耗时机检（proposed）

## 现状
`sealed-tests.sh` 的发现面只 glob `*.test.sh` / `*.test.py`，而全仓多数测试是 `.test.ts`（tests/control-tower 11 个、tests/security 19 个）⇒ 发现制对 .ts 恒 0 发现（GATE-STANDARD v3.1 §六 O2 已证不可达），退 `canary-drift` 的前置判据无法出具。另一面 `gate-stats.sh` / `gate-telemetry.sh` 只出中位耗时，无墙钟、无阈值、无数据也 exit 0（§七）⇒ 耗时预算无判据（§十二 判据 9 不可判）。

## 决定
1. `sealed-tests.sh` 发现面扩为 `tests/control-tower tests/doc-system tests/security`，`scan_face` 支持 `.test.ts`（含 `.integration.test.ts` / `.e2e.test.ts`）；`--face-total` 改为逐面一行（count ＋ runner），某面 0 ⇒ exit 1、面目录缺失 ⇒ exit 2；新增 `--list-ts`（runner=vitest，缺 runner ⇒ exit 2 ＋ degraded）。
2. `--list`（CI bash 执行集）**保持只出 .sh/.py**，.ts 存在时 stderr 明示「未进 bash 执行集，runner=vitest 待接线」——不改 workflow 行为。
3. 棘轮 `# FACE-TOTAL=` / `--slack` / `scan_face_at` 仍按**执行集口径（.sh/.py）**计数：台账 204 不在本卡写集，若把 .ts 计入则余量 8→35 撞 SLACK-CAP=10（假红）。.ts 可见性由逐面行承担。
4. 新建 `scripts/control-tower/check-gate-budget.sh`：默认读 `wall_ms=<n>` 日志 / `--cmd` 用 `time.monotonic` 实测，阈值默认 90000ms，三态 0/1/2，无数据或无法计时 ⇒ exit 2（禁 exit 0）；**旁路，不接 pre-commit 主路径**（接线归 W6/A3）。
5. 登记三件（L1 批准写集 +3，全部纯追加）：`WIRING-REGISTRY.yaml` 加 `check-gate-budget` 行（declared-only，consumer 空，R1.2 显式豁免）；`DOCS-REGISTRY.yaml` 加 `DOC-1210`；`GATE-INVENTORY.yaml` 加 classification/run_by/run_by_candidates 各 1 条并按 **main 版** `gen-gate-meta.sh --emit` 重生成 `gate_meta:` 段（不含 A 通道改动；A 合入后由 B 重跑 `--emit`）。

## 依据
GATE-STANDARD v3.1 §六 O2（扩面 ＋ `scan_face` 支持 `.test.ts` ＋ 指定 runner）与 §七「耗时预算须新建 check-gate-budget.sh」、§十一 W0 出口判据「`--face-total` 各面非零」。配对测试含改坏必红两态（删 .test.ts glob ⇒ tests/security 归零 ⇒ exit 1；阈值比较改恒假 ⇒ 超限夹具变 PASS）。

## 生效时点
本批合入 main 起。已知限制：.ts 尚无 CI 执行（runner 未接线）；FACE-TOTAL 不覆盖 .ts；`--face-total` 输出形状由单整数改为逐面行（消费方 `check-gate-integrity.sh` 的展示字段会变多行，不影响退出码）。
