# Note — W1 退役批 18 项 ＋ 配额降旁路 7 项（#1219，proposed）

## 现状
`docs/authority/GATE-INVENTORY.yaml` 的 `run_by:` 与 `workflows:` 记账与真实门禁面已经分层：一部分是**真门禁**（pre-commit / pre-push / Gitea CI 实际调用、能真阻断），另一部分**不可观测或不可阻断**——批A 12 条脚本在四条运行腿（pre-commit、pre-push、`.gitea/workflows`、`.github/workflows`）里**零引用**（含路径归一后仍 0），`all-checks-passed` 是 GitHub `ci.yml` 的聚合 job（参与集判定已可由 `check-gate-integrity.sh` 的 ci-reds 单源承担），批B 4 条有的末行恒为 `exit 0`、有的只在注释里出现、有的同义件已在 workflow 侧在账。同时 `scripts/control-tower/check-acceptance-matrix.py`（第 26 件）的三态机制已由总闸 `verify-governance.sh` 承接。
另有一处口径缺口：配额三桶（non_doc / total / bypass）此前把上述不可阻断项计入 non_doc，导致 `non_doc=35/30` 长期超编，真门禁的可信度被稀释。

## 决定
1. `GATE-INVENTORY.yaml` 的 `retired:` 段**纯追加 18 条**（批A 12 ＋ 聚合 job 1 ＋ 批B 4 ＋ 第 26 件 1），总 `retired` 由 8 条变 **26 条**；每条含 `id/path/batch/reason/date/replacement|none/absorbed_by/evidence/observation_until`，`replacement: none` 的条目必须带 `na_cmd`（可复跑的反证命令）；退役不删文件，观察期至 2026-11-30。
2. `run_by:` 段把 7 条 `quota: true` 改为 `quota: false`（4 条退役 + 3 条降旁路：`check-pr-budget.sh`／`check-hardcoded.sh`／`check-acceptance-ci.sh`，只降配额、不退役），出口为 `non_doc=28/30（超编 0）`、`total=30/45`、`bypass=2/8`、`quota_true=32`。
3. `check-gate-integrity.sh` 的参与集生产默认源改为单源 `scripts/control-tower/required-checks-baseline.txt`（9 条），`ci.yml`／`all-checks-passed.needs` 解析**只保留给测试注入缝**（`SYNO_CI_YML`／`SYNO_CT_SCOPE_CIYML`），文件缺失或解析到 0 名仍走既有 `C_SCOPE_UNRESOLVED` 降级（exit 2，fail-closed）。
4. `gate-inventory.invariant.sh` 的 ① 配额恒等式常量与三份配对测试（`gate-retirement-batch1.test.sh`／`gate-inventory.invariant.test.sh`／`gen-gate-meta.test.sh`）改为**随出口动态或机械交叉核对**，删掉硬编码数字，保留「改坏必红」判别力。
5. `WIRING-REGISTRY.yaml` 的 `control-tower.acceptanceMatrix` 标 `status: retired` 并写 `retired_reason`（absorbed_by = `scripts/control-tower/verify-governance.sh`）；`checkpoint-runtime.sh` **只加头注释**标明转运维资产不记退役（线上 cron 监控，非门禁）。
6. 受保护路径变更走 `gate-exemptions/2026-10-31-w1-1219.md`（首行复核件指针 `# review: #1219`，8 条三段式含自覆盖行），并在 `DOCS-REGISTRY.yaml` 追加 `DOC-1219` 使登记闭合。
