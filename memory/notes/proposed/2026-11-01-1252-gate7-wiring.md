# #1252 ⑦ 门禁完整性：Windows 盘符冒号解析 ＋ base 注入缺失（T2）

- **状态**: proposed
- **日期**: 2026-11-01
- **批次**: P4 门禁自身可靠性批次 **T2**（#1255）｜分支 `ct/1252-gate7`
- **授权**: CTO 会话（创始人外出前口令「长时任务」）｜判据源：GATE-STANDARD v3.1 §二（两腿分工）＋ §十二 ⑨

## 一、现状（两条独立缺陷，均实测）

### (1) Windows 盘符冒号 ⇒ 本机恒红 / CI 绿（两腿结论相反）
- `run_fixture_power` 用 `grep -nHE` 取 `path:line:text`，再用 `${_ln%%:*}` 按**首个**冒号切。
- Windows 路径含**盘符冒号**（`D:/…`）⇒ 路径被切成 `D`、key 变 `D:` ⇒ `_fixture_whitelist_status` 永不命中。
- 实测（同 commit）：本机 `FIXTURE-POWER: 违规 2；豁免 0`、`GATE-INTEGRITY: VIOLATION(2)`、rc=1；
  CI（mac）`违规 0；豁免 2`、`OK`、rc=0。⇒ **本机无法用 ⑦ 自证**，自证链断一环。

### (2) ⑦ 步未注入 `SYNO_BASE_REF`
- `sealed-tests.sh:307-320` 的「越线者付账」要求 `scan(base)` 与 `scan(PR)` 同次测量；
  空 ⇒ 显式打印「未给 base」并退化"现状语义"（余量 > 上限即红）。
- ⑦ 步只有 `bash scripts/control-tower/check-gate-integrity.sh || exit $?`（无 base 注入）⇒
  该判据**从未行使**，且每次 run 都出现"未给 base"提示（易被当成噪音忽略）。

## 二、决定

- (1) 行拆分改 `_fp_split_line()`：贪心 `^(.*):([0-9]+):(.*)$`，取**最后一个** `:<数字>:`；盘符与路径内冒号都不再打断。
  另加**只读单测缝** `--fixture-power-parse`（stdin 逐行 → `<rel>:<num>`），使该缺陷有**与平台无关**的判据
  （mac 上无盘符，走不到该分支；没有注入缝就只能空口声称"已修"）。
- (2) ⑦ 步补 `CHANGED_BASE="$(resolve-ci-base.sh)"` ＋ `SYNO_BASE_REF="$CHANGED_BASE"`（与 ①d/①e/⑨ 同法）。
- **判据阈值一字未动**：`MIN_REASON_CHARS`／`FACE-TOTAL`／`SLACK-CAP`／`QUARANTINE-TOTAL` 全不动。

## 三、依据与证据

| 场景 | 修前 | 修后 |
|---|---|---|
| 本机 ⑦（同 commit） | 违规 2 / 豁免 0 / VIOLATION(2) / rc=1 | **违规 0 / 豁免 2 / OK / rc=0**（与 CI 同结论） |
| 盘符冒号单测 | 无判据（mac 走不到） | `D:/x/tests/…/a.test.sh:59:…` ⇒ **`tests/…/a.test.sh:59`** |
| 配对测试 | 73 例 | **PASS=74 / FAIL=0**（新增 M10-6 与既有共存） |

## 四、边界与失效条件

- 单测缝只做字符串拆分：不读文件系统、不判违规、不改退出码（`--fixture-power-parse` 恒 exit 0）。
- 若将来 `grep` 输出格式改为 `-Z`（NUL 分隔）或路径含换行，本拆分需同步；本件不覆盖该形态。
- 本件不修 `check-gate-integrity.sh` 其它 Windows 差异（若有），只修本条实测缺陷。
