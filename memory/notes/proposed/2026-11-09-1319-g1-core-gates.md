# 决策: #1319 T1 建立可信的影子核心门

状态: proposed
日期: 2026-11-09

## 现状

旧 `local-gates` 同时承担工程检查与治理检查，且仍有固定工作区和个人路径。新核心门需要在不改变旧 required contexts 的前提下，验证真实 SHA、按 lock 安装、类型、构建、Secrets、基础契约与受影响测试，并防止零测试、空断言和 PR 自改核心判据产生假绿。

## 决定

仅实施 revision 4 DEV DOC 的 T1 九文件：新增 `core-gates / core`、统一测试 runner 和两个配对 harness；安装前检查受信输入，安装后核对精确工具版本；用真实 Vitest JSON、collection 和运行时断言计数判定结果。同步更新 claim、registry、限定豁免与本 Note。不执行 T2/T3，不修改分支保护、旧门或 GitHub。

## 依据

CTO 对 revision 4 的最终放行授权要求以可信工作流和命令为判据来源，所有无法判定的情况 fail-closed 为 `2`，确定性业务失败为 `1`。真实测试必须证明 passed 数大于零且每个已执行测试有运行时断言；合法 SKIP 必须由事件、变更集和实际 collection 支持。

## 生效时点

本 Note 随 T1 草案 PR 提交即记录实现决定；核心门仅在真实 PR 中影子运行。旧 required contexts 与新门的权威切换须待 T1 合并后的平台可信来源验证及后续 T2 放行，本批不生效任何合并阻断切换。
