# fixture-toolchain.txt — 夹具工具链 **单一来源**（卡 #739 ④ · 裁 223）
#
# 所有跑夹具的 CI job / 本地入口都读本文件：kind=npm 的项由 CI 安装（spec=包规格），
# kind=runner 的项由 runner 预装（只核对不安装）。夹具用 `# @requires <bin>…` 声明依赖。
#
# 格式（竖线分隔，行首 # 为注释）：
#   bin | kind | spec | note
#     bin  — 可执行名（command -v 检查）
#     kind — npm（CI 安装）｜runner（runner 预装）
#     spec — kind=npm 时的安装规格；kind=runner 时写 *
#     note — 说明（可空）
#
# 新增依赖只改这里（一处定义、多处引用）；夹具不写安装命令。
# ═══════════════════════════════════════════════════════════════════════════════
